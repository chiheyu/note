## 一、本节核心框架：数理统计的基石——“从局部推断总体”

### 1.1 数理统计与概率论的逻辑关联
* **概率论（演绎）**：已知总体分布（上帝视角），研究样本或随机变量的概率特征。方向：**总体 $\to$ 样本**。
* **数理统计（归纳）**：总体分布或参数未知（凡人视角），通过抽取样本，利用样本的信息去推断总体的真实情况。方向：**样本 $\to$ 总体**。
* 核心链条：**总体 $\to$ 抽样 $\to$ 样本 $\to$ 构造统计量 $\to$ 推断总体**。

### 1.2 核心目标
通过样本构造合理的**统计量**（不含任何未知参数的样本函数），利用统计量的抽样分布特性，实现对总体分布及其数字特征的推断（如第七章的参数估计、第八章的假设检验）。

## 二、总体与样本

### 2.1 核心概念辨析

| 概念 | 严格定义 | 通俗理解 | 考研补充说明 |
| :--- | :--- | :--- | :--- |
| **总体** | 研究对象的某一数量指标的全体，对应一个**随机变量 $X$**（或多维随机向量），其分布称为总体分布。 | 所有研究对象的目标特征 | 考研中，总体就是一个分布（如“设总体 $X \sim N(\mu, \sigma^2)$”）。 |
| **个体** | 总体中的单个元素，对应随机变量 $X$ 的一次观测值。 | 单个研究对象的目标特征 | 个体的取值是具体数值，但其“随机性”受总体分布支配。 |
| **样本** | 从总体中抽取的 $n$ 个个体的数量指标，记为 $X_1, X_2, \cdots, X_n$，其中 $n$ 为**样本容量**。 | 抽出来的部分研究对象 | 样本具有**“两重性”**：<br>① 抽样前：它们是**随机变量**；<br>② 抽样后：得到具体数值 $x_1, x_2, \cdots, x_n$，称为**样本观测值**。 |
| **简单随机样本** | 满足两个核心条件：<br>① **独立性**：$X_1, X_2, \cdots, X_n$ 相互独立；<br>② **同分布**：每个 $X_i$ 与总体 $X$ 同分布 (i.i.d)。 | 随机且独立抽取的样本 | 考研中只要出现“设 $X_1, \cdots, X_n$ 为来自总体 $X$ 的样本”，**默认**就是简单随机样本。 |

### 2.2 样本空间
样本 $(X_1, X_2, \cdots, X_n)$ 的所有可能取值的集合称为样本空间。

### 2.3 简单随机样本的核心性质（极高频起点）
若 $X_1, X_2, \cdots, X_n$ 是总体 $X$ 的简单随机样本，且总体 $E(X)=\mu, D(X)=\sigma^2$，则：
* **边缘特征**：对任意 $i$，有 $E(X_i)=\mu, D(X_i)=\sigma^2$。
* **独立不相关**：对任意 $i \neq j$，有 $\operatorname{Cov}(X_i, X_j)=0$。
* **联合分布（推断基础）**：
    若总体 $X$ 的分布函数为 $F(x)$、密度函数为 $f(x)$（或分布律为 $p(x)$），则样本的**联合分布函数**为：
    $$F_n(x_1, x_2, \cdots, x_n) = \prod_{i=1}^n F(x_i)$$
    **联合概率密度/分布律**（极大似然估计的灵魂公式）：
    $$f_n(x_1, x_2, \cdots, x_n) = \prod_{i=1}^n f(x_i)$$

## 三、统计量（Statistic）

### 3.1 严格定义与判断铁律
设 $X_1, X_2, \cdots, X_n$ 是来自总体 $X$ 的样本，若样本的连续函数 $T = T(X_1, X_2, \cdots, X_n)$ **不含任何未知参数**，则称 $T$ 为统计量。
* **判断铁律**：看表达式中是否含有未知的总体参数（如未知的 $\mu, \sigma^2$）。
* *反例*：若总体 $N(\mu, \sigma^2)$ 中 $\mu$ 未知，则 $X_1 - \mu$ **不是**统计量；但 $X_1 - \bar{X}$ **是**统计量（因为 $\bar{X}$ 是样本算出来的，不是未知参数）。

### 3.2 考研六大核心统计量公式

| 统计量名称 | 定义式 | 核心意义与备注 |
| :--- | :--- | :--- |
| **样本均值** | $$\bar{X} = \frac{1}{n}\sum_{i=1}^n X_i$$ | 描述数据的“中心位置”。 |
| **样本方差** | $$S^2 = \frac{1}{n-1}\sum_{i=1}^n (X_i - \bar{X})^2$$ | 描述数据的“离散程度”。注意分母是 $n-1$，为了保证无偏性。 |
| **样本标准差** | $$S = \sqrt{\frac{1}{n-1}\sum_{i=1}^n (X_i - \bar{X})^2}$$ | 与原数据同量纲的离散程度指标。 |
| **样本 $k$ 阶原点矩** | $$A_k = \frac{1}{n}\sum_{i=1}^n X_i^k$$ | 对应总体 $E(X^k)$，是矩估计法的核心依据。当 $k=1$ 时，$A_1 = \bar{X}$。 |
| **样本 $k$ 阶中心矩** | $$B_k = \frac{1}{n}\sum_{i=1}^n (X_i - \bar{X})^k$$ | 对应总体 $E[(X-\mu)^k]$。注意：**中心矩的分母是 $n$，而不是 $n-1$**。样本二阶中心矩 $B_2 = \frac{n-1}{n}S^2$。 |
| **次序统计量** | $$X_{(1)} \le X_{(2)} \le \cdots \le X_{(n)}$$ | 将样本从小到大排序。$X_{(1)}$ 是样本最小值，$X_{(n)}$ 是样本最大值。 |

## 四、常用样本数字特征的推导（必考计算）

设总体 $X$ 满足 $E(X)=\mu, D(X)=\sigma^2$，样本量为 $n$。

### 4.1 样本均值 $\bar{X}$ 的期望与方差
$$E(\bar{X}) = E\left(\frac{1}{n}\sum_{i=1}^n X_i\right) = \frac{1}{n}\sum_{i=1}^n E(X_i) = \frac{1}{n} \cdot n\mu = \mu$$
$$D(\bar{X}) = D\left(\frac{1}{n}\sum_{i=1}^n X_i\right) = \frac{1}{n^2}\sum_{i=1}^n D(X_i) = \frac{1}{n^2} \cdot n\sigma^2 = \frac{\sigma^2}{n}$$
**超级高频拓展**：考研常考求 $E(\bar{X}^2)$。
利用公式 $E(\bar{X}^2) = D(\bar{X}) + [E(\bar{X})]^2$，可得：
$$E(\bar{X}^2) = \frac{\sigma^2}{n} + \mu^2$$

### 4.2 样本方差 $S^2$ 的期望（证明极其重要）
首先牢记恒等式（必须会推，做题常用来化简）：
$$\sum_{i=1}^n (X_i - \bar{X})^2 = \sum_{i=1}^n X_i^2 - n\bar{X}^2$$
推导期望：
$$E\left[\sum_{i=1}^n (X_i - \bar{X})^2\right] = \sum_{i=1}^n E(X_i^2) - nE(\bar{X}^2) = n(\mu^2 + \sigma^2) - n\left(\mu^2 + \frac{\sigma^2}{n}\right) = (n-1)\sigma^2$$
因此，除以 $n-1$ 后：
$$E(S^2) = E\left[\frac{1}{n-1}\sum_{i=1}^n (X_i - \bar{X})^2\right] = \sigma^2$$
**结论**：样本方差 $S^2$ 是总体方差 $\sigma^2$ 的无偏估计。若分母用 $n$（即 $B_2$），则 $E(B_2) = \frac{n-1}{n}\sigma^2$，是有偏的！

## 五、极重要拓展：次序统计量（最大值与最小值）

在考研第一轮复习中，经常遗漏最大值和最小值的分布，这是常考的大题考点。
设总体 $X$ 的分布函数为 $F(x)$，密度函数为 $f(x)$，样本为 $X_1, \cdots, X_n$。

### 1. 样本最大值 $X_{\max}$ （即 $X_{(n)}$）
* **分布函数**：只有当所有的 $X_i \le x$ 时，最大值才会 $\le x$。
    $$F_{\max}(x) = P(X_{\max} \le x) = P(X_1 \le x, \cdots, X_n \le x) = [F(x)]^n$$
* **密度函数**（求导）：
    $$f_{\max}(x) = n[F(x)]^{n-1} f(x)$$

### 2. 样本最小值 $X_{\min}$ （即 $X_{(1)}$）
* **分布函数**：利用对立事件，只有所有的 $X_i > x$ 时，最小值才会 $> x$。
    $$F_{\min}(x) = P(X_{\min} \le x) = 1 - P(X_{\min} > x) = 1 - P(X_1 > x, \cdots, X_n > x) = 1 - [1-F(x)]^n$$
* **密度函数**（求导）：
    $$f_{\min}(x) = n[1-F(x)]^{n-1} f(x)$$

## 六、高频易错点（一轮避坑指南）

1. **混淆样本方差 $S^2$ 与二阶中心矩 $B_2$**
   * 考研题目说“样本方差”，**绝对**是指分母为 $n-1$ 的 $S^2$。
   * 若让你求矩估计中的方差估计，得到的往往是 $B_2$（分母为 $n$），做题时一定要看清题目让求的是什么。
2. **滥用 $\bar{X}$ 与 $S^2$ 的独立性**
   * **费歇尔引理（Fisher's Lemma）**指出：**只有当总体服从正态分布 $N(\mu, \sigma^2)$ 时**，样本均值 $\bar{X}$ 与样本方差 $S^2$ 才相互独立。对于非正态总体（如均匀分布、指数分布），$\bar{X}$ 和 $S^2$ 通常是不独立的！
3. **样本观测值与随机变量的混淆**
   * 写大写字母 $X_i$ 时，它是随机变量，有期望、方差和分布；
   * 写小写字母 $x_i$ 时，它是确定的常数观测值，主要用于代入似然函数 $L(\theta) = \prod f(x_i; \theta)$ 中计算参数估计。
4. **统计量不能含未知参数**
   * 判断题常考：设 $\mu$ 未知，问 $\frac{X_1 + X_2}{\mu}$ 是不是统计量？**不是**！
   * 但如果题目明确说“已知总体服从 $N(0, \sigma^2)$，其中 $\sigma^2$ 未知”，此时 $\mu=0$ 是已知参数，那么 $\frac{1}{n}\sum X_i^2$ **是**统计量。

## 七、例题抓手与第一轮解题思路

1. **看到“求统计量的期望/方差”**
   * **核心思想**：将其拆解为单个样本 $X_i$ 的期望和方差。
   * **第一步**：确认总体分布，写出 $E(X_i)=\mu$, $D(X_i)=\sigma^2$。
   * **第二步**：利用期望的线性性质 $E(\sum c_i X_i) = \sum c_i E(X_i)$。
   * **第三步**：利用样本的**独立性**拆分方差 $D(\sum c_i X_i) = \sum c_i^2 D(X_i)$。*(注意：只要独立，就不需要考虑协方差项)*。
2. **看到“求 $X_{\max}$ 或 $X_{\min}$ 的概率或期望”**
   * **第一步**：直接默写出 $F_{\max}(x) = [F(x)]^n$ 或 $F_{\min}(x) = 1 - [1-F(x)]^n$ 的分布函数。
   * **第二步**：求导得到密度函数 $f_{\max}(x)$ 或 $f_{\min}(x)$。
   * **第三步**：利用密度函数通过积分求期望 $E(X_{\max}) = \int x f_{\max}(x) dx$。
3. **遇到求和式的化简运算**
   * 牢记公式交叉转化：$\sum_{i=1}^n (X_i - \bar{X})^2 = \sum_{i=1}^n X_i^2 - n\bar{X}^2 = (n-1)S^2$。很多题目给你 $\sum X_i^2$ 和 $\bar{X}$，就是让你暗中求 $S^2$。
