## 一、 本节核心框架：事件即集合，概念的等价映射
概率论中对事件的研究，在数学本质上完全等价于集合论中的运算。考研复习的第一步，必须建立“文字描述 $\to$ 集合符号”的条件反射。

* **样本空间 $\Omega$** $\iff$ **全集**（必然事件）
* **不可能事件 $\varnothing$** $\iff$ **空集**
* **基本事件 $\omega$** $\iff$ **集合中的元素**
* **随机事件 $A$** $\iff$ **样本空间 $\Omega$ 的子集**

## 二、 事件的五大基本运算
### 1. 并事件（和事件）
* **记法：** $A\cup B$ 或 $A+B$
* **含义：** 事件 $A$ 与事件 $B$ **至少有一个**发生。
* **推广：** $\bigcup_{i=1}^n A_i$ 表示 $A_1, A_2, \dots, A_n$ 中至少有一个发生。

### 2. 交事件（积事件）
* **记法：** $A\cap B$ 或 $AB$
* **含义：** 事件 $A$ 与事件 $B$ **同时**发生。
* **推广：** $\bigcap_{i=1}^n A_i$ 表示 $A_1, A_2, \dots, A_n$ 全部同时发生。

### 3. 差事件
* **记法：** $A-B$
* **含义：** 事件 $A$ 发生且事件 $B$ **不**发生。
* **核心化简公式（极高频）：** $$A-B = A\bar{B} = A - AB = A \cup B - B$$
    *(注：在概率计算和事件化简中，$A\bar{B}$ 是最常用的转化形式)*

### 4. 对立事件（逆事件）
* **记法：** $\bar{A}$
* **含义：** 事件 $A$ **不**发生。

## 三、 事件之间的四大关系
### 1. 包含关系
* **定义：** 若 $A\subset B$，则 $A$ 发生必然导致 $B$ 发生。
* **性质：** $A\cup B = B$， $AB = A$。
* **概率引申：** $P(A) \le P(B)$。

### 2. 相等关系
* **定义：** 若 $A\subset B$ 且 $B\subset A$，则 $A=B$。
* **考法：** 证明两个复杂事件相等时，常用“双向包含法”或“运算法”化简。

### 3. 互不相容（互斥关系）
* **定义：** 若 $AB=\varnothing$，则称 $A$ 与 $B$ 互不相容。
* **含义：** $A$ 与 $B$ **不能同时发生**。
* **多个事件互不相容：** 若 $A_1, A_2, \dots, A_n$ 任意两个事件交集为空（$A_i A_j = \varnothing, i \neq j$），称它们**两两互不相容**。

### 4. 对立关系
* **定义：** 满足 $AB=\varnothing$ 且 $A\cup B=\Omega$。此时称 $A$ 与 $B$ 互为对立事件，记为 $B=\bar{A}$。
* **核心辨析（互斥 vs 对立）：** * **对立一定互斥，但互斥不一定对立。**
    * 互斥只要求“不能同时发生”（可以都不发生）；对立要求“非此即彼，必居其一”。

## 四、 事件的运算定律（化简题的灵魂）
除了常规的交换律（$A\cup B=B\cup A$）和结合律，必须熟练掌握以下定律：

### 1. 分配律
* **交对并的分配：** $A(B\cup C) = AB \cup AC$ （最常用，类似乘法分配律）
* **并对交的分配：** $A\cup(BC) = (A\cup B)(A\cup C)$ （易忘，常用于拆解复杂式子）

### 2. 德·摩根定律（对偶律）
* **公式：**
    $$\overline{A\cup B} = \bar{A}\cap\bar{B}$$
    $$\overline{A\cap B} = \bar{A}\cup\bar{B}$$
* **记忆口诀：** “长杠断开，变号（交变并，并变交）”。
* **推广至 n 项：** $\overline{\bigcup_{i=1}^n A_i} = \bigcap_{i=1}^n \bar{A}_i$。

### 3. 吸收律（辅助化简）
* $A\cup(AB) = A$
* $A(A\cup B) = A$

## 五、 语言描述与事件运算的“翻译字典”
设 $A, B, C$ 为三个随机事件，考研大题第一步经常需要进行准确的数学翻译：

| 文字描述（日常语言） | 集合运算表示（代数语言） | 备注与理解 |
| :--- | :--- | :--- |
| $A, B$ **都**发生 | $AB$ | 交集 |
| $A, B$ **都不**发生 | $\bar{A}\bar{B}$ 或 $\overline{A\cup B}$ | “至少一个发生”的对立面 |
| $A, B$ **不都**发生 | $\overline{AB}$ 或 $\bar{A}\cup \bar{B}$ | 德摩根定律的应用 |
| $A, B$ **至少有一个**发生 | $A\cup B$ | 包含 $A$发生$B$不发生、$B$发生$A$不发生、都发生三种情况 |
| $A, B$ **至多有一个**发生 | $\overline{AB}$ 或 $\bar{A}\cup \bar{B} \cup \bar{A}\bar{B}$ | 即“不能同时发生” |
| $A, B$ **恰有一个**发生 | $A\bar{B} \cup \bar{A}B$ | 相当于 $(A\cup B) - AB$ |
| $A, B, C$ **至少有两个**发生 | $AB \cup BC \cup AC$ | 任意两两相交再求并集 |
| $A, B, C$ **恰有两个**发生 | $AB\bar{C} \cup A\bar{B}C \cup \bar{A}BC$ | 必须且只能有两个发生 |

## 六、 高频易错点与避坑指南
1.  **“互不相容”与“相互独立”的混淆：**
    * **互不相容**是集合关系（不能同时发生，$AB=\varnothing$）。
    * **相互独立**是概率性质（发生与否互不影响，$P(AB)=P(A)P(B)$）。
    * 两者绝对不能混用！若 $A, B$ 互不相容且 $P(A)>0, P(B)>0$，则它们**必定不独立**。
2.  **差事件的概率计算误区：**
    * 事件运算有 $A-B$。
    * 但概率计算中，**$P(A-B) \neq P(A) - P(B)$**（除非 $B\subset A$）。
    * 永远使用通用公式：$P(A-B) = P(A) - P(AB)$。
3.  **正难则反的思想缺乏：**
    * 看到“至少有 $1$ 个”、“至多有 $n$ 个”，如果直接分类讨论很麻烦，**必须第一时间想到对立事件**。
    * “至少有 $1$ 个”的对立是“一个都没有”。

## 七、 例题抓手与实战套路
* **题型一：事件化简题**
    * **解题口诀：** 见到差号化为交（$A-B \to A\bar{B}$），见到长杠用德摩根，利用分配律提公因式，最后用吸收律或互斥性消项。
    * *示例：* 化简 $(A\cup B)(A\cup \bar{B})$ 
        * 解：$(A\cup B)(A\cup \bar{B}) = A \cup (B\bar{B}) = A \cup \varnothing = A$
* **题型二：文字翻译题**
    * **解题口诀：** 找准主语和条件，先翻译成单事件的交并补，再整体检查是否漏情况。尤其注意“不都”和“都不”的语感区别。
