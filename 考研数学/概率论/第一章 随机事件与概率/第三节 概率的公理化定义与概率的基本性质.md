## 一、 本节核心框架：概率的公理化定义 (柯尔莫哥洛夫公理体系)

在公理化定义下，概率被严格定义为满足特定条件的**集合函数**（即将样本空间的子集映射到实数）。这使得概率论具备了现代数学的严密性。设 $\Omega$ 为样本空间，$P(A)$ 为定义在事件 $A$ 上的实值函数，若满足以下三条公理，则称 $P(A)$ 为事件 $A$ 的概率：

* **公理 1 (非负性)：** 对任意事件 $A$，有 $P(A) \ge 0$。
* **公理 2 (规范性)：** 对必然事件 $\Omega$，有 $P(\Omega) = 1$。
* **公理 3 (可列可加性)：** 若事件序列 $A_1, A_2, \cdots, A_n, \cdots$ 两两互不相容（即当 $i \ne j$ 时，$A_i A_j = \varnothing$），则有：
    $$P\left(\bigcup_{i=1}^{\infty}A_i\right) = \sum_{i=1}^{\infty}P(A_i)$$
    *(注：这是概率论能处理极限和无穷过程的基石。)*

## 二、 概率的六大基本性质与重要推论

公理化定义只有三条，所有的计算公式都由这三条公理推导而来。

### 1. 不可能事件的概率
* **公式：** $P(\varnothing) = 0$。
* **深刻理解：** 这是公理 3 的推论。但**其逆命题不成立**。即 $P(A)=0$ **推不出** $A = \varnothing$。在连续型随机变量中，取某个特定点的概率总是 0，但该事件并非不可能发生。

### 2. 有限可加性
* **公式：** 若 $A_1, A_2, \cdots, A_n$ 两两互不相容，则
    $$P\left(\bigcup_{i=1}^{n}A_i\right) = \sum_{i=1}^{n}P(A_i)$$
* **应用：** 计算复杂事件概率时，最核心的思路之一就是把事件**拆解**为若干个互不相容的基本事件的和。

### 3. 补事件 (逆事件) 公式
* **公式：** $P(\bar{A}) = 1 - P(A)$。
* **深刻理解：** 推论 $P(\Omega)=1$ 及 $P(A \cup \bar{A}) = P(A) + P(\bar{A})$。同时注意，若 $P(A)=1$，**推不出** $A = \Omega$。

### 4. 差事件公式 (极其高频)
* **通用公式：** 对任意事件 $A$ 和 $B$：
    $$P(A - B) = P(A\bar{B}) = P(A) - P(AB)$$
* **特殊化 (若有包含关系)：** 若 $B \subset A$，则 $P(AB)=P(B)$，此时才有：
    $$P(A - B) = P(A) - P(B)$$
* **考点提示：** 考研中千万不要一上来就写 $P(A-B) = P(A)-P(B)$，必须先检查有没有包含关系，没有的话老老实实减去交集 $P(AB)$。

### 5. 单调性
* **公式：** 若 $A \subset B$，则：
    $$P(B - A) = P(B) - P(A) \ge 0$$
    进而有 $P(A) \le P(B)$。

### 6. 加法公式 (容斥原理)
* **任意两个事件：** $$P(A \cup B) = P(A) + P(B) - P(AB)$$
* **任意三个事件 (容斥原理)：**
    $$P(A \cup B \cup C) = P(A) + P(B) + P(C) - P(AB) - P(AC) - P(BC) + P(ABC)$$
* **推导思路：** 容斥原理的本质是“先全加，多算的减去，多减的再加回来”。

## 三、 概率的极限性质 (连续性定理) (冷门但在大题中常作支撑)

这是公理 3 的直接体现，连接了概率论与微积分。
* **单调递增事件序列：** 若 $A_1 \subset A_2 \subset \cdots \subset A_n \subset \cdots$，设 $A = \bigcup_{n=1}^{\infty} A_n = \lim_{n\to\infty} A_n$，则：
    $$P(A) = \lim_{n\to\infty} P(A_n)$$
* **单调递减事件序列：** 若 $A_1 \supset A_2 \supset \cdots \supset A_n \supset \cdots$，设 $A = \bigcap_{n=1}^{\infty} A_n = \lim_{n\to\infty} A_n$，则：
    $$P(A) = \lim_{n\to\infty} P(A_n)$$

## 四、 常用概率不等式体系

在选择题、填空题甚至大题的证明环节经常用到。

### 1. 范围限制
* $$0 \le P(A) \le 1$$

### 2. 布尔不等式 (次可加性 / 半可加性)
* **两个事件：** $$P(A \cup B) \le P(A) + P(B)$$
* **一般推广：** 即使事件不互斥，也有
    $$P\left(\bigcup_{i=1}^{n}A_i\right) \le \sum_{i=1}^{n}P(A_i)$$

### 3. 邦费罗尼 (Bonferroni) 不等式
* **公式：**
    $$P(AB) \ge P(A) + P(B) - 1$$
* **推导：** 由加法公式 $P(A \cup B) = P(A) + P(B) - P(AB)$，因为 $P(A \cup B) \le 1$，所以 $P(A) + P(B) - P(AB) \le 1$，移项即得。常用于已知 $P(A)$ 和 $P(B)$ 都很大时，估计它们同时发生的概率的下界。

## 五、 高频易错点与避坑指南

1.  **概率值为 0 或 1 的误区：**
    * $P(A)=0 \nRightarrow A=\varnothing$ （例如：连续分布在某一点取值的概率）。
    * $P(A)=1 \nRightarrow A=\Omega$。
    * **正确表述：** 称概率为 0 的事件为**零测事件**，概率为 1 的为**几乎必然事件**。
2.  **“互不相容”不能乱用：**
    * 只有明确说了 $AB=\varnothing$，才能用 $P(A \cup B) = P(A) + P(B)$。否则必须带上 $-P(AB)$。
3.  **盲目减法：**
    * 求 $P(A-B)$ 时，如果直接写 $P(A)-P(B)$ 就掉进了陷阱。必须写 $P(A)-P(AB)$。
4.  **两两互不相容与相互独立：**
    * 互斥能直接加概率，独立能直接乘概率。在复习前期极容易搞混这两者的公式应用场景。

## 六、 题型与例题抓手

* **抓手 1：“至少一个”的破局法 (正难则反)**
    * 当题目出现“至少发生一个”、“至少出现一次”等字眼，正面分类讨论情况太多时，直接转向对立事件：
    $$P(\text{至少一个}) = 1 - P(\text{一个都没有})$$
* **抓手 2：公式化简的底层逻辑**
    * 所有关于并集、交集、差集概率的计算，最终都要想办法转化为已知概率的积或者和。
    * 遇到 $P(A \cup B)$ 就默写加法公式。
    * 遇到 $P(A\bar{B})$ 就默写差事件公式 $P(A)-P(AB)$。
    * 遇到带上划线的长式子（如 $P(\bar{A}\bar{B})$），立马用德·摩根定律转换为 $P(\overline{A\cup B}) = 1 - P(A\cup B)$。
