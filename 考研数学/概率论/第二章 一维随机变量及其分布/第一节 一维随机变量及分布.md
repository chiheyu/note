## 一、 本节核心框架：随机变量——随机结果的数学抽象

这一节是概率论从“古典语言”跨越到“现代分析语言”的关键。在随机试验中，结果往往不是数字（例如：抛硬币的正反、射击的命中与否）。**随机变量的核心作用，就是把样本空间 $\Omega$ 中的每一个随机结果 $\omega$，映射为实数轴上的一个确定的点 $x$。** 这样，我们就可以用微积分、函数等强大的数学工具来研究概率了。

* **随机变量 (记为 $X$)：** 定义在样本空间 $\Omega$ 上的实值函数，即 $X=X(\omega)$。
* **分布函数 (记为 $F(x)$)：** 描述随机变量宏观规律的总开关。定义为：
  $$F(x)=P\{X\le x\}$$
  它是将“事件的概率”转化为“实变量的函数”的桥梁。* **第一轮复习核心任务：** 1. 会由分布律/密度函数求出分布函数 $F(x)$；
  2. 会由分布函数 $F(x)$ 反推概率密度或特定区间的概率；
  3. 熟练掌握分段函数积分的技巧。

## 二、 分布函数 $F(x)$ 的四大核心性质 (必考判定定理)

考研经常在选择题中让你判断“下列哪个函数是分布函数”。必须同时满足以下四个性质，缺一不可：

### 1. 单调不减性
* **定义：** 若 $x_1<x_2$，则 $F(x_1)\le F(x_2)$。
* **本质：** 随着 $x$ 增大，区间 $(-\infty, x]$ 变大，包含的样本点变多，积累的概率自然变大。因此，只要看到导数小于 0 的函数，立刻排除。

### 2. 规范性 (两端极限)
* **左极限：** $F(-\infty)=\lim_{x\to -\infty}F(x)=0$。
* **右极限：** $F(+\infty)=\lim_{x\to +\infty}F(x)=1$。
* **有界性：** $0\le F(x)\le 1$ 对任意实数恒成立。

### 3. 右连续性
* **定义：** 无论函数在何处发生跳跃，总有
  $$F(x+0)=F(x)$$
  即右极限等于函数值。

### 4. 区间概率的万能公式 (重中之重)
利用 $F(x)$ 求任意区间的概率，必须死记以下四个变式，注意开闭区间的微小差别：
1. $P\{a<X\le b\}=F(b)-F(a)$ (这是最基础的公式，因为 $F(x)$ 定义域自带左开右闭)
2. $P\{X<a\}=F(a-0)$ (即左极限)
3. $P\{X=a\}=F(a)-F(a-0)$ (即函数在该点的**跳跃高度**)
4. $P\{a\le X\le b\}=F(b)-F(a-0)$

* **注意：** 如果 $X$ 是连续型随机变量，则 $F(x)$ 处处连续，即 $F(a)=F(a-0)$，此时端点的开闭不影响概率。

## 三、 离散型随机变量及其分布律

### 1. 核心定义
随机变量的取值是**有限个**或**可列无限多个**（可以一个一个数出来，如 0, 1, 2...）。

### 2. 概率分布律
用一个表格或公式把所有取值 $x_k$ 以及对应的概率 $p_k$ 列出来：
$$P\{X=x_k\}=p_k \quad (k=1,2,\dots)$$
* **两大必备性质：** * 非负性：$p_k\ge 0$
  * 归一性：$\sum p_k=1$ (常用于大题中求解未知参数)

### 3. 离散型的分布函数 $F(x)$
它是阶梯函数，表现为一段一段的平线，在取值点 $x_k$ 处发生向上的跳跃，跳跃高度刚好是 $p_k$。$$F(x)=\sum_{x_k\le x} p_k$$
* **实战套路：** 离散型求分布函数，就是“把 $x$ 左侧所有的概率加起来”。写分段函数时，注意左侧必须是开区间，右侧必须是闭区间（例如 $0\le x < 1$ 这种写法是错误的，必须写成 $0 \le x < 1$？不对，右连续要求是 $a \le x < b$ 的形式，包含左端点，但不包含右端点... 等等，分布函数是右连续的，所以分段时等号应该在下限，即 $a \le x < b$。在 $x=a$ 时，极限等于函数值）。

## 四、 连续型随机变量及其概率密度

### 1. 核心定义
如果存在一个**非负**可积函数 $f(x)$，使得对于任意实数 $x$，都有
$$F(x)=\int_{-\infty}^x f(t)dt$$
则称 $X$ 为连续型随机变量，$f(x)$ 为概率密度函数 (PDF)。
### 2. 概率密度的三大性质
* **非负性：** $f(x)\ge 0$。**注意：** $f(x)$ 可以大于 1，甚至可以在某点趋于无穷，它只代表概率的“密集程度”，不代表概率本身！
* **归一性：**
  $$\int_{-\infty}^{+\infty} f(x)dx=1$$
  (这是所有连续型大题求未知参数 $A$ 的总开关)。
* **微积分关系：** 若 $f(x)$ 在点 $x$ 处连续，则有
  $$F'(x)=f(x)$$

### 3. 区间概率的计算
落在任意区间 $(a,b)$ 内的概率，就是密度函数在区间上的**定积分 (面积)**：
$$P\{a<X<b\}=\int_a^b f(x)dx=F(b)-F(a)$$

## 五、 连续型与离散型的核心辨析 (防坑指南)

| 特性 | 离散型随机变量 | 连续型随机变量 |
| :--- | :--- | :--- |
| **单点概率** $P\{X=a\}$ | 可能大于 0，取决于分布律 | **恒等于 0** |
| **单点概率为 0 的含义** | 事件可能是不可能事件 | $P\{X=a\}=0$ 绝对推不出 $X=a$ 是不可能事件 (例如飞镖扎中几何线上的特定一点，概率为 0，但真实存在) |
| **区间概率的端点** | $P\{X<a\} \neq P\{X\le a\}$，多一个等号多算一个概率 | $P\{X<a\} = P\{X\le a\}$，端点开闭随便写，不影响定积分结果 |
| **分布函数** $F(x)$ | 阶梯跳跃，仅右连续 | 处处绝对连续，没有断点 |

## 六、 综合解题模板与例题抓手

### 题型 1：判别函数性质与求未知参数
* **题型特征：** 给出含有未知参数 $A$ 的 $f(x)$ 或 $F(x)$，或者判断某个给出的函数能否作为 $f(x)$ 或 $F(x)$。
* **解题模板：**
  * 对于 $f(x)$：死盯两点，一是 $\int_{-\infty}^{+\infty}f(x)dx=1$，二是检查 $f(x)\ge 0$ 是否恒成立。
  * 对于 $F(x)$：死盯极限 $F(+\infty)=1, F(-\infty)=0$，再顺便看看导数是不是大于等于 0。

### 题型 2：由概率密度 $f(x)$ 求分布函数 $F(x)$ (考研必考大题基本功)
* **题型特征：** 给你一个分段的密度函数 $f(x)$，让你写出完整的 $F(x)$。
* **致命易错点：** 直接对每段积分，忘记了“积分下限是 $-\infty$”，导致概率累计断裂。
* **解题模板 (分段积分法)：**
  $$F(x)=\int_{-\infty}^x f(t)dt$$
  * **必须把被积变量换成 $t$，把积分上限写成 $x$！**
  * 若 $x$ 落在第 2 段区间，积分必须拆成两段：第 1 段的满额积分 + 第 2 段从下限积到 $x$。
  * *例如 $f(x)$ 在 $x<0$ 时为 0，在 $0\le x <2$ 时为某函数。当 $0\le x <2$ 时：*
    $$F(x)=\int_{-\infty}^0 0 dt + \int_0^x f(t)dt$$
  * 最后必须写出包含 $x<0, x\ge 2$ 等所有范围的分段函数。

### 题型 3：求复合事件或条件概率
* **遇到** $P\{X>a \mid X>b\}$ **这类题：**
  * 立马转化为公式：$\frac{P\{X>a \text{ 且 } X>b\}}{P\{X>b\}}$。
  * 画数轴求交集，化简分子。千万不要想当然瞎算。
