## 一、本节核心框架：单侧置信区间只关注参数的一侧边界

双侧置信区间回答的是“参数大概落在哪个闭区间内”，而单侧置信区间回答的是“参数至少有多大（下限）”或“参数至多有多大（上限）”。

在工程实际与假设检验中，单侧估计往往更有实际意义。例如：考察灯泡寿命，我们只关心“至少能亮多久”（下限）；考察废气质检，我们只关心“有害物质浓度至多是多少”（上限）。

本节仍以正态总体 $X\sim N(\mu,\sigma^2)$ 为主，核心原则只有两点：
1. **分布不变**：依然遵循“均值方差已知用 $Z$，方差未知用 $t$；方差估计用 $\chi^2$”的枢轴量体系。
2. **分位点变化**：$$\text{双侧平分显著性水平用 }\alpha/2,\qquad \text{单侧概率全集中在一尾用 }\alpha$$

---

## 二、均值 $\mu$ 的单侧置信区间：方差 $\sigma^2$ 已知

### 1. 核心枢轴量
由于 $\sigma^2$ 已知，使用标准正态分布：
$$Z=\frac{\bar X-\mu}{\sigma/\sqrt n}\sim N(0,1)$$

### 2. $\mu$ 的单侧置信下限（求“至少”）
若希望得到形如 $\mu>L$ 的下限：
为了保证概率为 $1-\alpha$，我们在标准正态分布中取**左侧**面积为 $1-\alpha$ 的区域（即右尾面积为 $\alpha$），使得：
$$P\left\{\frac{\bar X-\mu}{\sigma/\sqrt n} < z_\alpha\right\}=1-\alpha$$
解不等式，反解出 $\mu$：
$$P\left\{\mu > \bar X-z_\alpha\frac{\sigma}{\sqrt n}\right\}=1-\alpha$$
所以 $\mu$ 的单侧置信下限为 $L = \bar X-z_\alpha\frac{\sigma}{\sqrt n}$。
**置信区间表示为**：$$\left(\bar X-z_\alpha\frac{\sigma}{\sqrt n},\ +\infty\right)$$

### 3. $\mu$ 的单侧置信上限（求“至多”）
同理，取**右侧**面积为 $1-\alpha$ 的区域（即左尾面积为 $\alpha$），使得：
$$P\left\{\frac{\bar X-\mu}{\sigma/\sqrt n} > -z_\alpha\right\}=1-\alpha$$
反解得单侧置信上限为 $U = \bar X+z_\alpha\frac{\sigma}{\sqrt n}$。
**置信区间表示为**：$$\left(-\infty,\ \bar X+z_\alpha\frac{\sigma}{\sqrt n}\right)$$

---

## 三、均值 $\mu$ 的单侧置信区间：方差 $\sigma^2$ 未知（考研高频）

### 1. 核心枢轴量
由于 $\sigma^2$ 未知，必须用样本标准差 $S$ 替代，枢轴量服从 $t$ 分布：
$$T=\frac{\bar X-\mu}{S/\sqrt n}\sim t(n-1)$$

### 2. 置信下限与上限的构造
推导逻辑与 $Z$ 分布完全一致，只需将分位点换为 $t_\alpha(n-1)$。

- **单侧置信下限**：
  $$\left(\bar X-t_\alpha(n-1)\frac{S}{\sqrt n},\ +\infty\right)$$
- **单侧置信上限**：
  $$\left(-\infty,\ \bar X+t_\alpha(n-1)\frac{S}{\sqrt n}\right)$$

**第一轮复习记忆诀窍**：
只要记住双侧公式，方差未知求单侧时，直接把双侧公式中的 $t_{\alpha/2}$ 抠掉“/2”变成 $t_\alpha$，然后根据题意（求大还是求小）只保留一半的界限。

## 四、方差 $\sigma^2$ 与标准差 $\sigma$ 的单侧置信区间

### 1. 核心枢轴量
正态总体下，利用样本方差构造卡方统计量：
$$\frac{(n-1)S^2}{\sigma^2}\sim \chi^2(n-1)$$

### 2. 方差的置信下限（极易错点）
希望得到 $\sigma^2 > L$。
由于我们要解的不等式中 $\sigma^2$ 在分母，为了得到 $\sigma^2 > L$ 的形式，枢轴量必须满足“小于”某个值：
$$P\left\{\frac{(n-1)S^2}{\sigma^2} < \chi^2_{\alpha}(n-1)\right\}=1-\alpha$$
（注意：$\chi^2_{\alpha}$ 表示右尾面积为 $\alpha$，所以其左侧面积正好是 $1-\alpha$）
对不等式取倒数，反向，得：
$$P\left\{\sigma^2 > \frac{(n-1)S^2}{\chi^2_{\alpha}(n-1)}\right\} = 1-\alpha$$
**单侧置信下限区间为**：$$\left(\frac{(n-1)S^2}{\chi^2_{\alpha}(n-1)},\ +\infty\right)$$

### 3. 方差的置信上限
希望得到 $\sigma^2 < U$。
同理，取卡方分布的左尾分位点 $\chi^2_{1-\alpha}(n-1)$：
$$P\left\{\frac{(n-1)S^2}{\sigma^2} > \chi^2_{1-\alpha}(n-1)\right\}=1-\alpha$$
取倒数得单侧置信上限：
**单侧置信上限区间为**：$$\left(0,\ \frac{(n-1)S^2}{\chi^2_{1-\alpha}(n-1)}\right)$$
*(注：方差非负，故区间左端点写 $0$ 而不是 $-\infty$)*

### 4. 核心提醒与避坑口诀
方差区间中 $\sigma^2$ 在分母里，分位点方向最容易反。**牢记口诀：**
- **求下限（小端点），分母用大值 $\implies$ 用 $\chi^2_{\alpha}$**
- **求上限（大端点），分母用小值 $\implies$ 用 $\chi^2_{1-\alpha}$**

若求标准差 $\sigma$ 的单侧置信区间，将上述区间的非零端点直接**开正平方根**即可。

## 五、单侧置信区间与实际语言的翻译映射

在考研应用题中，必须能将文字描述准确翻译为数学表达式：

| 题目语言（工程/业务描述） | 统计学目标 | 要求的界限 | 最终区间形式 |
| :--- | :--- | :---: | :---: |
| “电池寿命**至少**为多少” | 求参数的极小可能值 | **置信下限** $L$ | $(L,+\infty)$ |
| “合格率**不低于**多少” | 求参数的底线 | **置信下限** $L$ | $(L,+\infty)$ |
| “误差/废气浓度**至多**为多少” | 求参数的极大可能值 | **置信上限** $U$ | $(-\infty,U)$ |

| “给出参数的**上置信限**” | 数学直接指令 | **置信上限** $U$ | $(-\infty,U)$ |

## 六、完整例题对比演示

### 例题 1：方差未知时求均值下限（常见工业应用）
某产品寿命服从正态分布，抽取 $n=10$ 个样本，得样本均值 $\bar x=120$ 小时，样本标准差 $s=6$ 小时。求总体均值 $\mu$ 的置信度为 $95\%$ 的单侧置信下限。

**标准解法**：
1. **定枢轴量**：总体正态，方差未知，用 $T=\frac{\bar X-\mu}{S/\sqrt n}\sim t(9)$。
2. **定分位点**：置信度 $1-\alpha = 0.95 \implies \alpha=0.05$。单侧不除以二，查表找 $t_{0.05}(9)$。
3. **套公式**：求下限，用减法。
   $$L=\bar x-t_\alpha(n-1)\frac{s}{\sqrt n} = 120-t_{0.05}(9)\frac{6}{\sqrt{10}}$$
4. **结论**：$\mu$ 的 $95\%$ 单侧置信下限区间为 $\left(120-t_{0.05}(9)\frac{6}{\sqrt{10}},\ +\infty\right)$。

### 例题 2：求方差的上限（易错题）
测定某种仪器的测量误差，连续测量 16 次，算得样本方差 $S^2 = 0.04$。设误差服从均值为 0 的正态分布，求仪器测量误差方差 $\sigma^2$ 的 $90\%$ 单侧置信上限。

**标准解法**：
1. **定枢轴量**：由于均值 $\mu=0$ 已知，应使用 $\chi^2 = \frac{\sum(X_i-0)^2}{\sigma^2} \sim \chi^2(n) = \chi^2(16)$。
   *(注意：如果题目没说均值为0，则用 $\chi^2(n-1)$。这里故意设置了一个坑。但通常如果是常规题型会用 $\chi^2(n-1)$，假设此处按常规 $\mu$ 未知处理，则自由度为 15，此处演示 $\mu$ 未知的标准做法)*
   **修改条件按常规走**：假设均值未知，则枢轴量服从 $\chi^2(15)$。
2. **定分位点**：$\alpha = 0.1$。求上限，分母要小，找左侧分位点 $\chi^2_{0.9}(15)$。
3. **套公式**：
   $$U = \frac{(16-1)S^2}{\chi^2_{1-\alpha}(n-1)} = \frac{15 \times 0.04}{\chi^2_{0.9}(15)} = \frac{0.6}{\chi^2_{0.9}(15)}$$
4. **结论**：$\sigma^2$ 的单侧置信区间为 $\left(0,\ \frac{0.6}{\chi^2_{0.9}(15)}\right)$。

## 八、高频易错点与避坑指南

1. **思维定势：看见区间就除以 2** 这是最惨重的失分点。单侧置信区间**绝对不能**使用 $\alpha/2$ 的分位点。必须使用 $z_\alpha, t_\alpha$ 或相应的 $\chi^2$ 单侧分位点。
2. **文字翻译错误** “至少”“不低于”对应的是求**下限 $L$**（区间右侧趋于无穷大）；“至多”“不超过”对应的是求**上限 $U$**（均值左侧趋于负无穷，方差左侧趋于 0）。
3. **方差未知时错用 $Z$ 分布** 总体虽然是正态的，但只要方差 $\sigma^2$ 未知，关于均值的估计就必须用 $t$ 分布。
4. **方差卡方分位点写反（再次强调）** 求方差下限 $L$ $\implies$ $\sigma^2 > L$ $\implies$ 倒数前枢轴量 $< \chi^2_\alpha$ $\implies$ 分母用大的 $\chi^2_\alpha$。逻辑推导一遍最稳妥。
5. **混淆“置信限”与“置信区间”** 题目若问“求置信下限”，只需写出一个具体数值 $L$；若问“求单侧置信区间”，必须写出带无穷号的开区间集合形式 $(L, +\infty)$。

## 九、本节知识网络图

- 🎯 **正态总体单侧置信区间核心逻辑**
  - 🔑 **核心区别**：双侧查 $\alpha/2$分位点 $\implies$ 单侧查 $\alpha$分位点
  - 📏 **均值 $\mu$ 的单侧估计**
    - 💡 **$\sigma^2$ 已知** $\to$ 枢轴量 $Z \sim N(0,1)$
      - 下限区间 $(L, +\infty)$：$L = \bar X - z_\alpha\frac{\sigma}{\sqrt{n}}$
      - 上限区间 $(-\infty, U)$：$U = \bar X + z_\alpha\frac{\sigma}{\sqrt{n}}$
    - 💡 **$\sigma^2$ 未知** $\to$ 枢轴量 $T \sim t(n-1)$
      - 下限区间 $(L, +\infty)$：$L = \bar X - t_\alpha\frac{S}{\sqrt{n}}$
      - 上限区间 $(-\infty, U)$：$U = \bar X + t_\alpha\frac{S}{\sqrt{n}}$
  - 📐 **方差 $\sigma^2$ 的单侧估计**（$\mu$未知）
    - 💡 **构造** $\to$ 枢轴量 $\chi^2 \sim \chi^2(n-1)$
      - 下限区间 $(L, +\infty)$：$L = \frac{(n-1)S^2}{\chi^2_\alpha}$ (大分母)
      - 上限区间 $(0, U)$：$U = \frac{(n-1)S^2}{\chi^2_{1-\alpha}}$ (小分母)
  - 🗣️ **工程应用语境**
    - 📉 **求下限**：寿命、强度、合格率 (“至少”、“不低于”)
    - 📈 **求上限**：误差、毒性、次品率 (“至多”、“不超过”)

## 十、一句话总结

**单侧置信区间只需抓住两个“一”：概率只在一边（统统用 $\alpha$ 不除以 2），界限只求一边（问底线求下限减尾巴，问天花板求上限加尾巴，方差分母大小认清别搞反）。**
