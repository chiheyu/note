## 一、本节核心框架：点估计就是构造参数的“替身”

点估计的目标，是在总体分布形式已知、但含有未知参数 $\theta$ 时，根据已知的样本观测值 $X_1,X_2,\cdots,X_n$ 构造一个统计量 $\hat\theta(X_1,X_2,\cdots,X_n)$，用它来作为总体未知参数 $\theta$ 的估计值。

考研数学中，点估计是每年必考的计算大题（尤其是数一、数三），核心掌握两种方法：
$$\text{矩估计法 (Method of Moments)}\qquad\text{最大似然估计法 (Maximum Likelihood Estimation, MLE)}$$

前者的思想是**“用样本特征（表象）替代理论特征（实质）”**，后者的思想是**“让已经发生的样本出现概率最大（存在即合理）”**。

---

## 二、矩估计法 (MOM)

### 1. 核心思想与基本原理
根据大数定律，当样本量 $n$ 足够大时，样本的 $k$ 阶原点矩依概率收敛于总体的 $k$ 阶原点矩。因此，我们可以用可以通过数据直接算出的**样本矩**，去替代含有未知参数的**总体矩**，从而列出方程解出参数。

- 总体 $k$ 阶原点矩：$\mu_k = E(X^k)$ （是未知参数的函数）
- 样本 $k$ 阶原点矩：$A_k = \frac{1}{n}\sum_{i=1}^n X_i^k$ （是具体数值）
- **核心动作**：令 $\mu_k = A_k$

### 2. 具体计算步骤（单参数与多参数）
- **单参数情况**（如 $\lambda, p$）：
  通常只需一阶矩。令 $E(X) = \bar X$，从中反解出参数 $\theta = g(\bar X)$，即得矩估计量 $\hat\theta_M = g(\bar X)$。
- **双参数情况**（如 $\mu, \sigma^2$）：
  需要用到一阶矩和二阶矩。列方程组：
  $$\begin{cases} E(X) = \frac{1}{n}\sum_{i=1}^n X_i = \bar X \\ E(X^2) = \frac{1}{n}\sum_{i=1}^n X_i^2 \end{cases}$$
  联立解出两个参数。

### 3. 典型例子：正态分布 $N(\mu, \sigma^2)$ 的矩估计
已知 $E(X) = \mu$, $E(X^2) = D(X) + [E(X)]^2 = \sigma^2 + \mu^2$。
列矩估计方程：
$$\begin{cases} \mu = \bar X \\ \sigma^2 + \mu^2 = \frac{1}{n}\sum_{i=1}^n X_i^2 \end{cases}$$
解得：
$$\hat\mu_M = \bar X$$
$$\hat\sigma^2_M = \frac{1}{n}\sum_{i=1}^n X_i^2 - \bar X^2 = \frac{1}{n}\sum_{i=1}^n (X_i - \bar X)^2$$
*(注：正态分布方差的矩估计量是不修正的样本方差，分母是 $n$ 而不是 $n-1$)*

## 三、最大似然估计法 (MLE)

### 1. 核心思想
逻辑基础：“既然这组样本 $x_1,x_2,\cdots,x_n$ 已经在一次抽样中真实发生了，那么合理的参数 $\theta$ 应该是让这组样本作为一个整体出现的联合概率（或联合密度）达到最大的那个值”。

### 2. 似然函数 $L(\theta)$ 的构造
- **离散型总体**（分布律为 $P\{X=x\}=p(x;\theta)$）：
  似然函数为联合概率：
  $$L(\theta)=\prod_{i=1}^n p(x_i;\theta)$$
- **连续型总体**（密度函数为 $f(x;\theta)$）：
  似然函数为联合密度：
  $$L(\theta)=\prod_{i=1}^n f(x_i;\theta)$$
  *(极其重要的提醒：连续型中使用的是密度函数值，必须注意定义域，可以引入指示函数 $I$ 辅助判断)*

### 3. 最大似然估计的重要性质：不变性（考研常考）
若 $\hat\theta$ 是 $\theta$ 的最大似然估计量，且 $g(\theta)$ 是一元函数，则 $g(\theta)$ 的最大似然估计量就是 $g(\hat\theta)$。
*例如：求出了参数 $\lambda$ 的 MLE 为 $\bar X$，若让你求 $e^{-\lambda}$ 的 MLE，直接就是 $e^{-\bar X}$，无需重新求导计算。*

## 四、最大似然估计的两种“求解流派”

考研大题中，求最大似然估计必定属于以下两种情况之一，必须精准判断：

### 1. 内部极值法（求导法）
**适用场景**：参数 $\theta$ 不在总体的定义域边界上（如正态分布、泊松分布、指数分布）。
**标准流程**：
1. **写似然**：$L(\theta)=\prod_{i=1}^n f(x_i;\theta)$
2. **取对数**：$\ln L(\theta)=\sum_{i=1}^n \ln f(x_i;\theta)$（化乘积为求和，极大化 $L$ 等价于极大化 $\ln L$）
3. **求导数**：令 $\frac{d}{d\theta}\ln L(\theta)=0$
4. **解方程**：解出的 $\theta$ 即为估计值，改写成大写字母得估计量 $\hat\theta_L$。

### 2. 边界最值法（单调性法/定义法）
**适用场景**：未知参数 $\theta$ 出现在随机变量 $X$ 的取值范围（定义域）中（如均匀分布 $U(0,\theta)$、$U(\theta, \theta+1)$，指数位移分布）。
**标准流程**：
1. **写似然**：写出 $L(\theta)$，并严格写出由样本引发的关于 $\theta$ 的不等式条件。
2. **看单调**：观察 $L(\theta)$ 随 $\theta$ 的单调性（求导会发现导数恒大于或恒小于0，无法令其为0）。
3. **找边界**：根据单调性，在允许的范围内取最边界的值（通常是样本的最大值 $X_{(n)}$ 或最小值 $X_{(1)}$）。

## 五、考研经典例题对比剖析

### 例 1（求导法）：泊松分布 $X\sim P(\lambda)$
分布律：$P\{X=x_i\}=e^{-\lambda}\frac{\lambda^{x_i}}{x_i!}$
似然函数：
$$L(\lambda)=\prod_{i=1}^n e^{-\lambda}\frac{\lambda^{x_i}}{x_i!} = e^{-n\lambda}\frac{\lambda^{\sum x_i}}{\prod x_i!}$$
取对数：
$$\ln L(\lambda)=-n\lambda+\left(\sum_{i=1}^n x_i\right)\ln\lambda-\ln\left(\prod_{i=1}^n x_i!\right)$$
求导并令为零：
$$\frac{d \ln L}{d\lambda}=-n+\frac{\sum x_i}{\lambda} = 0$$
解得 $\hat\lambda=\frac{1}{n}\sum x_i = \bar X$。故最大似然估计量为 $\bar X$。

### 例 2（边界法）：均匀分布 $X\sim U(0,\theta)$
密度函数：$f(x;\theta)=\frac1\theta \cdot I(0<x<\theta)$
似然函数：
$$L(\theta) = \prod_{i=1}^n \frac{1}{\theta} = \frac{1}{\theta^n}$$
**核心约束**：因为对于所有的 $i$，都必须满足 $0 \le x_i \le \theta$，所以 $\theta$ 必须大于等于样本中的最大值，即 $\theta \ge \max(x_1,\cdots,x_n)$。
**单调性分析**：$L(\theta) = \theta^{-n}$ 在 $\theta > 0$ 时是严格单调递减的。要想让 $L(\theta)$ 最大，$\theta$ 必须取在允许范围内的**最小值**。
结论：$\hat\theta_L = \max(X_1,X_2,\cdots,X_n) = X_{(n)}$。

## 六、矩估计与最大似然估计的全面比较

| 维度 | 矩估计法 (MOM) | 最大似然估计法 (MLE) |
| :--- | :--- | :--- |
| **理论基石** | 大数定律（样本矩依概率收敛于总体矩） | 极大似然原理（小概率事件在一次试验中不发生） |
| **计算复杂度** | 通常较低，解代数方程组即可 | 计算量大，需对数求导或分析次序统计量 |
| **对分布信息的依赖** | 只需知道总体的期望和方差，无需知道具体分布 | **必须**完全知道总体的概率分布（分布律/密度函数） |
| **常见易错点** | 总体含有高阶参数时，积分求期望容易算错 | 参数位于边界时盲目求导导致“无解” |
| **结果一致性** | 两种方法求出的估计量可能相同，也可能不同 | 具备不变性法则 $g(\hat\theta)$，统计性质往往更优（如有效性） |

## 七、高频易错点与避坑指南（第一轮复习重中之重）

1. **估计量与估计值的大小写严格区分** 答题卡上，如果题目问“求估计量”，最终结果里的 $x_i$ 和 $\bar x$ 必须换成大写的 $X_i$ 和 $\bar X$。如果写错大小写，极大概率会扣分，因为随机变量和常数有着本质区别。
2. **正态分布方差的最大似然估计陷阱** 计算推导后你会发现，正态总体方差 $\sigma^2$ 的最大似然估计量是 $S_n^2 = \frac{1}{n}\sum(X_i-\bar X)^2$，它的分母是 $n$。而我们在抽样分布中常说的样本方差 $S^2$ 分母是 $n-1$。千万不要混淆直接写 $S^2$。
3. **连续型似然函数的写法** 千万不要在试卷上写 $P(X=x_i) = f(x_i)$。连续型随机变量在某一点的概率恒为 $0$。似然函数是联合密度函数，直接写 $L(\theta) = \prod f(x_i)$ 即可。
4. **带有绝对值的分布** 遇到拉普拉斯分布（密度含 $e^{-|x-\mu|}$）求 $\mu$ 的 MLE 时，取对数后求导会遇到符号函数，此时极大值通常在样本中位数处取得，这是偏难考点。

## 八、本节知识网络图

- 🎯 **点估计核心任务**：找一个样本函数 $\hat\theta(X_1,\dots,X_n)$ 去替代未知真值 $\theta$
  - ⚖️ **矩估计法 (MOM: Method of Moments)**
    - 💡 **核心思想**：“用现实替代理论” ($A_k \approx \mu_k$)
    - 🛠️ **操作步骤**
      - 算理论：求总体期望 $E(X)$, $E(X^2)$
      - 列方程：令 $E(X)=\bar X$, $E(X^2)=\frac{1}{n}\sum X_i^2$
      - 解参数：用样本均值和二阶矩表示 $\theta$
  - 📈 **最大似然估计法 (MLE: Maximum Likelihood Estimation)**
    - 💡 **核心思想**：“存在即合理，让发生的概率最大”
    - 🌟 **核心性质**：MLE的不变性定理（$g(\hat\theta)$ 是 $g(\theta)$ 的估计）
    - 🛠️ **两大求解流派**
      - 📝 **内部极值法（求导法）**
        - 适用：定义域不含 $\theta$（如正态、泊松）
        - 流程：连乘写 $L(\theta) \to$ 取对数 $\ln L(\theta) \to$ 求导令为 $0$
      - 🚧 **边界最值法（定义法）**
        - 适用：定义域包含 $\theta$（如均匀分布）
        - 流程：写 $L(\theta) \to$ 找不等式边界条件 $\to$ 利用单调性取极值（常用 $\max X_i$ 或 $\min X_i$）

---

## 九、一句话总结

**点估计就是一场“猜心游戏”：矩估计通过“特征对齐”解方程快速给出答案，最大似然估计通过“概率溯源”严谨求极值；无论哪条路径，最终的替身（估计量）都必须且只能是样本的纯粹函数。**
