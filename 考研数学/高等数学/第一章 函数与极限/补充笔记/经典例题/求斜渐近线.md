# 综合分析：函数 $y = (x-1)e^{\frac{\pi}{2} + \arctan x}$ 的全性状分析

---

## 一、 单调性与极值分析

**1. 导数计算**
利用乘积法则与复合函数求导法则：
$$y' = 1 \cdot e^{\frac{\pi}{2} + \arctan x} + (x-1) \cdot e^{\frac{\pi}{2} + \arctan x} \cdot \frac{1}{1+x^2}$$
提取公因式并化简：
$$y' = e^{\frac{\pi}{2} + \arctan x} \left( 1 + \frac{x-1}{1+x^2} \right) = e^{\frac{\pi}{2} + \arctan x} \cdot \frac{x^2+x}{1+x^2}$$

**2. 驻点与单调区间**
令 $y' = 0$，由于 $e^u > 0$ 且 $1+x^2 > 0$ 恒成立，导数的符号仅由分子 $x(x+1)$ 决定：
- **驻点**：$x = -1$ 和 $x = 0$。
- **单调性判定**：
    - 当 $x \in (-\infty, -1)$ 时，$y' > 0$，函数**单调增加**；
    - 当 $x \in (-1, 0)$ 时，$y' < 0$，函数**单调减少**；
    - 当 $x \in (0, +\infty)$ 时，$y' > 0$，函数**单调增加**。



**3. 极值计算**
- **极大值**：在 $x = -1$ 处取得。
    $$y_{max} = (-1-1)e^{\frac{\pi}{2} + \arctan(-1)} = -2e^{\frac{\pi}{2} - \frac{\pi}{4}} = \mathbf{-2e^{\pi/4}}$$
- **极小值**：在 $x = 0$ 处取得。
    $$y_{min} = (0-1)e^{\frac{\pi}{2} + \arctan 0} = -1 \cdot e^{\pi/2} = \mathbf{-e^{\pi/2}}$$

---

## 二、 渐近线分析

该函数在 $(-\infty, +\infty)$ 内连续，无垂直渐近线。由于 $x \to \pm\infty$ 时 $\arctan x$ 的极限不同，需分两侧讨论斜渐近线 $y = ax + b$。

### 1. 右侧斜渐近线 ($x \to +\infty$)
- **斜率 $a_1$**：
    $$a_1 = \lim_{x \to +\infty} \frac{y}{x} = \lim_{x \to +\infty} \frac{x-1}{x} e^{\frac{\pi}{2} + \arctan x} = 1 \cdot e^{\frac{\pi}{2} + \frac{\pi}{2}} = e^{\pi}$$
- **截距 $b_1$**：
    利用 $\arctan x = \frac{\pi}{2} - \arctan(1/x)$ 及 $e^u \approx 1+u$ 进行泰勒展开：
    $$b_1 = \lim_{x \to +\infty} [ (x-1)e^{\pi - \arctan(1/x)} - e^{\pi}x ] = \mathbf{-2e^{\pi}}$$
    **结论**：右侧斜渐近线为 $y = e^{\pi}x - 2e^{\pi}$。

### 2. 左侧斜渐近线 ($x \to -\infty$)
- **斜率 $a_2$**：
    $$a_2 = \lim_{x \to -\infty} \frac{y}{x} = \lim_{x \to -\infty} \frac{x-1}{x} e^{\frac{\pi}{2} + \arctan x} = 1 \cdot e^{\frac{\pi}{2} - \frac{\pi}{2}} = e^0 = 1$$
- **截距 $b_2$**：
    利用 $\arctan x = -\frac{\pi}{2} - \arctan(1/x)$（注：此处利用性质 $\arctan x + \arctan(1/x) = -\frac{\pi}{2}$ 对于 $x < 0$ 成立）：
    $$b_2 = \lim_{x \to -\infty} [ (x-1)e^{-\arctan(1/x)} - x ] = \mathbf{-2}$$
    **结论**：左侧斜渐近线为 $y = x - 2$。



---

## 三、 核心结论汇总表

| 分析维度 | 结论内容 |
| :--- | :--- |
| **单调区间** | 增：$(-\infty, -1) \cup (0, +\infty)$；减：$(-1, 0)$ |
| **极值点** | 极大值点 $x = -1$ ($y = -2e^{\pi/4}$)；极小值点 $x = 0$ ($y = -e^{\pi/2}$) |
| **右侧渐近线** | $y = e^{\pi}(x - 2)$ |
| **左侧渐近线** | $y = x - 2$ |

**💡 备考建议：**
处理此类带有反三角函数的渐近线题目时，**“化无穷大为无穷小”**是核心技巧。通过 $\arctan x + \arctan(1/x) = \pm \frac{\pi}{2}$ 的转换，可以将指数位置的复杂项转化为泰勒公式可处理的标准型，从而大幅降低计算量。
