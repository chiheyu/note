# 题目：

$y=ax^2+bx+c$ 在点$M(1,2)$处的曲率圆的方程为:$$(x - \frac{1}{2})^2 + (y - \frac{5}{2})^2 = \frac{1}{2}$$
求常数$a,b,c$.

## 考点解析：基于曲率圆匹配性质求解待定系数 

这道题是高等数学中关于**曲率圆（密切圆）**的经典综合题。核心逻辑在于利用曲率圆与曲线在切点处“三阶一致”的物理本质，即：**坐标相同、一阶导数相同（斜率）、二阶导数相同（弯曲度）**。

---

## 一、 核心逻辑：DNA 匹配原则
若曲线 $y=f(x)$ 与圆在点 $M$ 处互为曲率圆，则在该点满足：
1.  **位置匹配**：$y_{曲线} = y_{圆}$
2.  **切线匹配**：$y'_{曲线} = y'_{圆}$
3.  **曲率匹配**：$y''_{曲线} = y''_{圆}$

---

## 二、 步骤详解

### 1. 从圆方程提取导数信息 (隐函数求导法)
已知圆方程：$$(x - \frac{1}{2})^2 + (y - \frac{5}{2})^2 = \frac{1}{2}$$
在点 $M(1, 2)$ 处：

- **求一阶导 $y'$**：
  两边对 $x$ 求导：$2(x - \frac{1}{2}) + 2(y - \frac{5}{2})y' = 0$
  代入 $x=1, y=2$：
  $$2(1 - \frac{1}{2}) + 2(2 - \frac{5}{2})y' = 0 \implies 1 - y' = 0 \implies \mathbf{y' = 1}$$

- **求二阶导 $y''$**：
  对导数式 $(x - \frac{1}{2}) + (y - \frac{5}{2})y' = 0$ 继续求导：
  $$1 + (y')^2 + (y - \frac{5}{2})y'' = 0$$
  代入 $y' = 1$ 及坐标：
  $$1 + 1^2 + (2 - \frac{5}{2})y'' = 0 \implies 2 - \frac{1}{2}y'' = 0 \implies \mathbf{y'' = 4}$$

### 2. 参数匹配与方程组求解
抛物线方程：$y = ax^2 + bx + c$
各阶导数：$y' = 2ax + b$，$y'' = 2a$

- **由二阶导匹配**：
  $$2a = 4 \implies \mathbf{a = 2}$$
- **由一阶导匹配 ($x=1$)**：
  $$2(2)(1) + b = 1 \implies 4 + b = 1 \implies \mathbf{b = -3}$$
- **由坐标点匹配 ($x=1, y=2$)**：
  $$2(1)^2 - 3(1) + c = 2 \implies -1 + c = 2 \implies \mathbf{c = 3}$$

---

## 三、 结论汇总

- **待定系数结果**：$a = 2, \ b = -3, \ c = 3$
- **抛物线方程**：$y = 2x^2 - 3x + 3$

> 虽然课本提供了曲率半径 $\rho$ 和圆心 $(\alpha, \beta)$ 的公式，但在给出圆方程的情况下，直接使用**隐函数求导**现推 $y'$ 和 $y''$ 往往比套公式更不容易出错，且逻辑更闭环。
>
