# 考研数学一：不等式应用全景知识图谱与解题范式

> [!tip] 
> **复习导引**
> 不等式是考研数学一贯穿始终的“底层操作系统”。它不仅是求解数列极限（夹逼准则）、反常积分审敛、级数敛散性判定的直接工具，更是高等数学微分/积分中值定理证明题、概率论大数定律与协方差估计的必考核心。

---

## 一、 经典不等式工具箱

### 1. 绝对值三角不等式
对任意 $a, b \in \mathbb{R}$（可推广至复数域与赋范线性空间）：
$$||a| - |b|| \le |a \pm b| \le |a| + |b|$$

$n$ 元推广形式：
$$\left| \sum_{i=1}^n a_i \right| \le \sum_{i=1}^n |a_i|$$

* **极限审敛核心操作**：$\varepsilon-N$ 或 $\varepsilon-\delta$ 证明中用于三角拆分误差：
  $$|f(x) - A| = |(f(x) - g(x)) + (g(x) - A)| \le |f(x) - g(x)| + |g(x) - A|$$
* **连续模与积分估计**：
  $$\left| \int_a^b f(x) dx \right| \le \int_a^b |f(x)| dx \quad (a < b)$$

---

### 2. 均值不等式链（Power Means Inequality）
设 $a, b > 0$，定义调和均值（$H$）、几何均值（$G$）、算术均值（$A$）、平方均值（$Q$）：
$$\frac{2}{\frac{1}{a} + \frac{1}{b}} \le \sqrt{ab} \le \frac{a+b}{2} \le \sqrt{\frac{a^2+b^2}{2}}$$
等号成立条件：当且仅当 $a = b$。

$n$ 元正数推广（$x_i > 0, i=1,2,\dots,n$）：
$$\frac{n}{\sum_{i=1}^n \frac{1}{x_i}} \le \left(\prod_{i=1}^n x_i\right)^{\frac{1}{n}} \le \frac{1}{n}\sum_{i=1}^n x_i \le \sqrt{\frac{1}{n}\sum_{i=1}^n x_i^2}$$

> [!tip] 
> **极值构造“一正二定三相等”**
> 1. **正**：各项变量必须严格为正；
> 2. **定**：和式求最小值时乘积必须为定值；乘积求最大值时和式必须为定值（常通过配凑系数消除变量）；
> 3. **等**：取等条件所确定的变量值必须落在题目给定的定义域内部。

---

### 3. 柯西-施瓦茨不等式（Cauchy-Schwarz）

| 表现维度 | 代数形式 / 积分形式 | 等号成立条件 |
| :--- | :--- | :--- |
| **代数向量** | $\left(\sum_{i=1}^n a_i b_i\right)^2 \le \left(\sum_{i=1}^n a_i^2\right)\left(\sum_{i=1}^n b_i^2\right)$ | 向量共线：$\frac{a_1}{b_1} = \frac{a_2}{b_2} = \dots = \frac{a_n}{b_n}$ |
| **平方可积函数** | $\left( \int_a^b f(x)g(x) dx \right)^2 \le \left( \int_a^b f^2(x) dx \right) \left( \int_a^b g^2(x) dx \right)$ | 函数线性相关：$f(x) = k g(x)$（几乎处处） |

**考研特化降维公式**（常令 $g(x) \equiv 1$）：
$$\left( \int_a^b f(x) dx \right)^2 \le (b - a) \int_a^b f^2(x) dx$$
*应用场景*：题干或待证式中出现 $\int_a^b [f'(x)]^2 dx$ 或已知导数平方的定积分求界。

---

### 4. 琴生不等式（Jensen's Inequality / 凸性定理）
若函数 $f(x)$ 在区间 $I$ 上为严格下凸函数（即 $f''(x) > 0$），则对任意 $x_1, x_2, \dots, x_n \in I$ 且 $\lambda_i > 0, \sum_{i=1}^n \lambda_i = 1$：
$$f\left(\sum_{i=1}^n \lambda_i x_i\right) \le \sum_{i=1}^n \lambda_i f(x_i)$$
*积分形式（割线高于切线）*：
$$f\left(\frac{1}{b-a}\int_a^b x(t) dt\right) \le \frac{1}{b-a}\int_a^b f(x(t)) dt$$

## 二、 微积分基础初等不等式链（泰勒展开透视）

高数中几乎所有初等放缩，本质均为一阶或二阶**拉格朗日余项泰勒展开**的特化：
$$f(x) = f(x_0) + f'(x_0)(x - x_0) + \frac{f''(\xi)}{2!}(x - x_0)^2$$

```
   切线支撑放缩 (f''(x) > 0)
        ▲
        │          /  曲线 y = f(x)
        │         / 
        │        /  切线 y = f(x0) + f'(x0)(x - x0)
        │       / 
────────┼──────/──────►
        │     x0
```

1. **切线与指数放缩**：
   $$e^x \ge 1 + x \quad (\forall x \in \mathbb{R} \text{，当且仅当 } x=0 \text{ 取等})$$
2. **对数放缩链**：
   $$\frac{x}{1+x} \le \ln(1+x) \le x \quad (x > -1)$$
3. **三角函数阶梯放缩**：
   $$x - \frac{x^3}{6} < \sin x < x < \tan x \quad \left(0 < x < \frac{\pi}{2}\right)$$
4. **若当（Jordan）不等式**：
   $$\frac{2}{\pi}x \le \sin x \le x \quad \left(0 \le x \le \frac{\pi}{2}\right)$$

## 三、 考研四大核心应用场景与解题范式

### 场景 1：数列极限的夹逼准则（Squeeze Theorem）
* **题型特征**：求 $n$ 项和极限 $\lim_{n \to \infty} \sum_{k=1}^n u_k(n)$，且无法化为定积分定义（次数或通项非 $k/n$ 齐次）。
* **操作步骤**：
  1. 识别通项最大项 $M$ 与最小项 $m$；
  2. 构造双侧不等式：$n \cdot m \le \sum_{k=1}^n u_k \le n \cdot M$；
  3. 验证 $\lim_{n\to\infty} (n \cdot m) = \lim_{n\to\infty} (n \cdot M) = A$。

---

### 场景 2：函数不等式证明（导数体系）
证明 $f(x) \ge g(x)$（$x \in [a, b]$）的标准三级阶梯：

1. **单调性法（一阶导数）**：
   * 构造辅助函数 $F(x) = f(x) - g(x)$；
   * 计算 $F'(x)$，若 $F'(x) \ge 0$ 且 $F(a) = 0$，则 $F(x) \ge 0$ 获证。
2. **极值与最值法（高阶导数）**：
   * 若 $F'(a) = 0$，继续求 $F''(x)$；
   * 若 $F''(x) > 0$，则 $F'(x)$ 单调递增 $\implies F'(x) > F'(a) = 0 \implies F(x) > F(a) = 0$。
3. **拉格朗日中值法（差商结构）**：
   * 形式特征：待证式包含 $f(b) - f(a)$ 或 $f(x_2) - f(x_1)$；
   * 变形为 $\frac{f(b) - f(a)}{b - a} = f'(\xi)$，将问题转换为估计导数 $f'(\xi)$ 的值域。

---

### 场景 3：积分不等式证明
* **方法 A：变上限积分导数法**
  * 设待证式含定积分 $\int_a^b f(t) dt$；
  * 令上限为自变量 $x$，构造函数 $\Phi(x) = \int_a^x f(t) dt - G(x)$；
  * 计算导数 $\Phi'(x) = f(x) - G'(x)$，退化为微分不等式判定。
* **方法 B：对称性积分变换（区间再现）**
  * 利用 $\int_a^b f(x) dx = \int_a^b f(a + b - x) dx$，将复杂项配对求和后再行放缩。
* **方法 C：柯西积分不等式直接配凑**
  * 遇到导数平方项 $\int_a^b [f'(t)]^2 dt$ 时，构造 $\int_a^x f'(t) \cdot 1 dt$，利用：
    $$|f(x) - f(a)|^2 = \left( \int_a^x f'(t) dt \right)^2 \le (x - a) \int_a^x [f'(t)]^2 dt$$

### 场景 4：概率论与数理统计估算（数一专属）

#### 1. 马尔可夫（Markov）不等式
设 $Y$ 为非负随机变量，对任意 $\varepsilon > 0$：
$$P(Y \ge \varepsilon) \le \frac{E(Y)}{\varepsilon}$$

#### 2. 切比雪夫（Chebyshev）不等式
设 $X$ 的期望 $E(X) = \mu$，方差 $D(X) = \sigma^2$，对任意 $\varepsilon > 0$：
$$P(|X - \mu| \ge \varepsilon) \le \frac{\sigma^2}{\varepsilon^2} \iff P(|X - \mu| < \varepsilon) \ge 1 - \frac{\sigma^2}{\varepsilon^2}$$
*作用*：大数定律弱收敛的证明理论支柱；用于无具体分布信息时的概率下界保守估计。

#### 3. 协方差与相关系数有界性
由向量柯西-施瓦茨不等式的随机变量内积定义（$\langle X, Y \rangle = E(XY)$）：
$$[\text{Cov}(X, Y)]^2 \le D(X) D(Y) \implies |\rho_{XY}| = \left| \frac{\text{Cov}(X, Y)}{\sqrt{D(X)}\sqrt{D(Y)}} \right| \le 1$$

## 四、 不等式证明核心解法横向对比表

| 解题方法 | 适用表达式特征 | 核心解题动作 | 潜在局限与缺陷 |
| :--- | :--- | :--- | :--- |
| **单调性分析法** | 单变量、零点明确的代数函数 | 构造差式 $F(x) = f - g$，求导定符号 | 多元混合变量或震荡导数无法直接处理 |
| **拉格朗日中值法** | 含有 $f(b) - f(a)$ 结构，形式对称 | 转化为差商与中值导数 $f'(\xi)$ | 中值 $\xi$ 具体位置未知，高阶信息容易丢失 |
| **泰勒展开法** | 含有高阶导数条件（$f''(x)$、$f'''(x)$） | 展开至已知导数的最高阶，余项写为拉格朗日型 | 展开点 $x_0$ 选取极度依赖经验 |
| **柯西-施瓦茨法** | 含有未知函数平方的定积分 $\int [f']^2$ | 将一次项乘 $1$ 后利用积分柯西公式拆分 | 仅能提供粗糙的上界估计，无法做精细逼近 |

## 五、 高频易错点与避坑指南

> [!warning] 
> **三大致命放缩陷阱**
> 1. **放缩尺度失衡（放过头）**：
>    在夹逼准则中，若将 $\sum_{k=1}^n \frac{1}{n^2 + k}$ 放缩为 $\sum_{k=1}^n \frac{1}{n^2} = \frac{1}{n} \to 0$ 与 $\sum_{k=1}^n \frac{1}{n^2+n} \to 0$ 成立；但若错误扔掉主部（如直接放大分母为常数项），会导致上下界极限不相等，夹逼失效。
> 2. **无界区间乱套局部结论**：
>    不等式 $\sin x < x$ 仅在 $x > 0$ 局部成立；反常积分中 $x \to +\infty$ 时，$\sin x$ 有界而 $x$ 趋于无穷，切勿做反向放大。
> 3. **绝对值差式下界的非负性缺失**：
>    使用 $|a - b| \ge |a| - |b|$ 时，只有当 $|a| > |b|$ 时该不等式才有定界价值；若 $|a| < |b|$，右边为负值，对非负模长无任何下界限制作用。
