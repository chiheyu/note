## 题目背景
设 $f(x)$ 在 $[a, b]$ 上连续，在 $(a, b)$ 内可导，且 $f(a) = f(b) = 0$。证明以下结论。

---

## 结论 (1)：证明存在 $\xi \in (a, b)$，使 $f(\xi) + \xi f'(\xi) = 0$

### 1. 构造辅助函数
观察结论形式，由于 $(x \cdot f(x))' = f(x) + x f'(x)$，构造：
$$F(x) = x f(x)$$

### 2. 验证条件
* **连续性与可导性**：$F(x)$ 在 $[a, b]$ 上连续，在 $(a, b)$ 内可导。
* **端点值**：
    * $F(a) = a \cdot f(a) = a \cdot 0 = 0$
    * $F(b) = b \cdot f(b) = b \cdot 0 = 0$
    * 即 $F(a) = F(b)$。

### 3. 应用定理
根据 **罗尔定理 (Rolle's Theorem)**，在 $(a, b)$ 内至少存在一点 $\xi$，使得：
$$F'(\xi) = 0$$
即：
$$f(\xi) + \xi f'(\xi) = 0$$

---

## 结论 (2)：证明存在 $\eta \in (a, b)$，使 $n f(\eta) + f'(\eta) = 0$（$n$ 为常数）

### 1. 构造辅助函数
观察结论 $f'(\eta) + n f(\eta) = 0$，这符合一阶线性微分方程的结构，利用指数函数构造：
$$G(x) = e^{nx} f(x)$$

### 2. 验证条件
* **连续性与可导性**：$G(x)$ 在 $[a, b]$ 上连续，在 $(a, b)$ 内可导。
* **端点值**：
    * $G(a) = e^{na} f(a) = 0$
    * $G(b) = e^{nb} f(b) = 0$
    * 即 $G(a) = G(b)$。

### 3. 应用定理
根据 **罗尔定理**，在 $(a, b)$ 内至少存在一点 $\eta$，使得 $G'(\eta) = 0$。
计算导数：
$$G'(x) = n e^{nx} f(x) + e^{nx} f'(x) = e^{nx} [n f(x) + f'(x)]$$
由于 $e^{n\eta} \neq 0$，故必有：
$$n f(\eta) + f'(\eta) = 0$$

---

## 💡 技巧总结：辅助函数构造“模版”

| 目标结论形式 | 推荐辅助函数 $F(x)$ | 原理/备注 |
| :--- | :--- | :--- |
| $f'(\xi) = 0$ | $f(x)$ | 最基础的罗尔定理 |
| $f(\xi) + \xi f'(\xi) = 0$ | $x f(x)$ | 乘积求导法则的逆运用 |
| $f'(\xi) + n f(\xi) = 0$ | $e^{nx} f(x)$ | 微分方程 $y' + ny = 0$ 的特征 |
| $f'(\xi) - n f(\xi) = 0$ | $e^{-nx} f(x)$ | 同上，注意正负号 |
| $x f'(\xi) - n f(\xi) = 0$ | $\frac{f(x)}{x^n}$ | 商求导法则的逆运用 |

> **核心思路**：观察结论左侧是否是某个已知函数 $F(x)$ 的导数分子部分。
