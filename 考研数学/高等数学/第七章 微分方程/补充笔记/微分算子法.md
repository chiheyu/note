**涉及知识点**

* **微分算子 $D$ 的概念与代数性质**：求导映射记为 $D = \frac{\text{d}}{\text{d}x}$，积分映射记为逆算子 $D^{-1} = \frac{1}{D} = \int (\cdot)\,\text{d}x$。
* **特征多项式算子化**：将常系数非齐次线性微分方程 $y'' + py' + qy = f(x)$ 写成算子形式 $L(D)y = f(x)$，其特解形式化表示为 $y^* = \frac{1}{L(D)} f(x)$。
* **指数代入与指数移位法则**：
* 代入法则：$P(D)\text{e}^{kx} = P(k)\text{e}^{kx}$；
* 逆代入法则：$\frac{1}{P(D)}\text{e}^{kx} = \frac{1}{P(k)}\text{e}^{kx}$（$P(k) \neq 0$）；
* 移位法则：$\frac{1}{P(D)}[\text{e}^{kx}v(x)] = \text{e}^{kx} \frac{1}{P(D+k)} v(x)$。

* **逆算子的泰勒展开（幂级数展开法）**：当右端项为多项式时，利用 $\frac{1}{1-z} = 1 + z + z^2 + \cdots$ 展开算子并截断计算。
* **复数指数法（欧拉公式结合）**：处理 $\cos\beta x$ 与 $\sin\beta x$ 自由项时，转化为 $\text{e}^{\text{i}\beta x}$ 取实部/虚部计算。

**常规方法（算子法的核心体系与运算规则）**

微分算子法（Operator Method）是将求导运算代数化的一套强力解题工具。把微分方程中的待定系数和繁琐求导，简化为像多项式除法一样的代数运算。

### 1. 基础概念与记号

* **算子符号**：

$$D = \frac{\text{d}}{\text{d}x}, \quad D^2 = \frac{\text{d}^2}{\text{d}x^2}, \quad \dots, \quad D^n = \frac{\text{d}^n}{\text{d}x^n}$$

* **逆算子符号**：

$$\frac{1}{D} f(x) = \int f(x)\,\text{d}x, \quad \frac{1}{D^2} f(x) = \iint f(x)\,\text{d}x\text{d}x$$

*(因为仅需找一个特解，所以积分常数统一取 0)*
* **方程的算子形式**：

$$y'' + py' + qy = f(x) \implies (D^2 + pD + q)y = f(x)$$

令算子多项式为 $L(D) = D^2 + pD + q$，则特解直接记为：

$$y^* = \frac{1}{L(D)} f(x)$$

---

### 2. 四大核心运算法则

#### 规则一：指数代入法则（$f(x) = \text{e}^{kx}$）

* **公式**：

$$\frac{1}{L(D)}\text{e}^{kx} = \frac{1}{L(k)}\text{e}^{kx} \quad (L(k) \neq 0)$$


* **原理**：因为 $D(\text{e}^{kx}) = k\text{e}^{kx}$，每作用一次 $D$ 就相当于乘一个常数 $k$。

#### 规则二：指数移位法则（核心法则，解一切共振和混合型）

* **公式**：

$$\frac{1}{L(D)}\left[\text{e}^{kx} v(x)\right] = \text{e}^{kx} \frac{1}{L(D+k)} v(x)$$

* **口诀**：$\text{e}^{kx}$ 从算子右边“穿”到左边，算子里所有的 $D$ 都要换成 $D+k$。
* **物理/数学意义**：
* 若 $k$ 不是特征根，代入后直接化为多项式型计算；
* 若 $k$ 是单特征根，则 $L(D+k)$ 必不含常数项，可提公因式 $D$：

$$\frac{1}{L(D+k)} = \frac{1}{D \cdot M(D)} = \frac{1}{D}\left[\frac{1}{M(D)}\right]$$

最外面的 $\frac{1}{D}$ 代表对后面的结果做一次积分，这正是书上“补乘一个 $x$”的本质来源！
* 若 $k$ 是二重特征根，则提公因式 $D^2$：

$$\frac{1}{L(D+k)} = \frac{1}{D^2}$$

连续积分两次，正好产生 $\frac{1}{2}x^2$（即书上的“补乘 $x^2$”）。

#### 规则三：多项式展开法则（$f(x) = P_m(x)$）

* **公式**：将 $\frac{1}{L(D)}$ 按照升幂展开为 $D$ 的麦克劳林级数：

$$\frac{1}{1 - D} = 1 + D + D^2 + D^3 + \cdots$$


$$\frac{1}{1 + D} = 1 - D + D^2 - D^3 + \cdots$$


* **截断原则**：多项式为 $m$ 次，求导超过 $m$ 次后全为 0，因此只需展开到 $D^m$ 项，后面全部舍弃。

#### 规则四：三角代换法则（$f(x) = \cos\beta x$ 或 $\sin\beta x$）

* **公式**：

$$\frac{1}{L(D^2)}\cos\beta x = \frac{1}{L(-\beta^2)}\cos\beta x \quad (L(-\beta^2) \neq 0)$$


* **口诀**：**只把 $D^2$ 换成 $-\beta^2$**，切勿把 $D$ 换成 $-\beta$。如果分母剩下一次项 $aD+b$，通过分子分母同乘共轭项 $(aD-b)$ 重新构造出 $D^2$ 再次代换。

### 3. 典型例题逐题实战

#### 场景一：单重特征根共振（验证书上情形二）

* **题目**：求 $y'' - y' - 2y = (x+1)\text{e}^{2x}$ 的特解。
* **解法（算子法）**：
1. 写出算子多项式：$L(D) = D^2 - D - 2 = (D-2)(D+1)$。
2. 特解式：

$$y^* = \frac{1}{(D-2)(D+1)}\left[(x+1)\text{e}^{2x}\right]$$

3. 利用**指数移位法则**，把 $\text{e}^{2x}$ 移到最左侧，算子中的 $D$ 换为 $D+2$：

$$y^* = \text{e}^{2x} \frac{1}{((D+2)-2)((D+2)+1)} (x+1) = \text{e}^{2x} \frac{1}{D(D+3)} (x+1)$$

4. 将 $\frac{1}{D+3}$ 展开（因为被作用项 $x+1$ 是一次式，展开到 $D$ 即可）：

$$\frac{1}{D+3} = \frac{1}{3}\frac{1}{1 + \frac{D}{3}} = \frac{1}{3}\left(1 - \frac{D}{3}\right)$$

5. 算子依次作用于 $(x+1)$：

$$\frac{1}{D+3}(x+1) = \frac{1}{3}\left(1 - \frac{D}{3}\right)(x+1) = \frac{1}{3}\left((x+1) - \frac{1}{3}(1)\right) = \frac{1}{3}x + \frac{2}{9}$$

6. 最后作用 $\frac{1}{D}$（代表积分）：

$$y^* = \text{e}^{2x} \frac{1}{D}\left(\frac{1}{3}x + \frac{2}{9}\right) = \text{e}^{2x} \left(\frac{1}{6}x^2 + \frac{2}{9}x\right) = x\left(\frac{1}{6}x + \frac{2}{9}\right)\text{e}^{2x}$$

整个过程完全是机械化代数运算，无需联立二元一次方程组解 $a$ 和 $b$。

---

#### 场景二：二重特征根共振（验证书上情形三）

* **题目**：求 $y'' - 4y' + 4y = (2x-1)\text{e}^{2x}$ 的特解。
* **解法（算子法）**：
1. 算子因式分解：$L(D) = (D-2)^2$。
2. 特解式：

$$y^* = \frac{1}{(D-2)^2}\left[(2x-1)\text{e}^{2x}\right]$$

3. 指数移位（$D \to D+2$）：

$$y^* = \text{e}^{2x} \frac{1}{((D+2)-2)^2}(2x-1) = \text{e}^{2x} \frac{1}{D^2}(2x-1)$$

4. $\frac{1}{D^2}$ 就是连续两次积分：
* 第一次积分：$\frac{1}{D}(2x-1) = x^2 - x$
* 第二次积分：$\frac{1}{D}(x^2 - x) = \frac{1}{3}x^3 - \frac{1}{2}x^2$

4. 得特解：

$$y^* = x^2\left(\frac{1}{3}x - \frac{1}{2}\right)\text{e}^{2x}$$

三行直接出结果，完美解释了书上为何设 $x^2(ax+b)\text{e}^{2x}$。

**特殊方法（复数统一法解三角函数型）**

对于含 $\cos\beta x$ 或 $\sin\beta x$ 的方程，待定系数法通常需要设 $A\cos\beta x + B\sin\beta x$ 代入求导数页纸。利用**欧拉公式配合微分算子法**可以秒杀。

* **题目**：求 $y'' + y = \cos x$ 的特解（此处 $\alpha+\text{i}\beta = 0 + 1\text{i}$ 是特征根 $\pm\text{i}$，属于共振情形）。
* **解法**：
1. 欧拉公式把余弦看作实部：$\cos x = \operatorname{Re}(\text{e}^{\text{i}x})$。
2. 特解表示为：

$$y^* = \operatorname{Re}\left(\frac{1}{D^2 + 1} \text{e}^{\text{i}x}\right)$$

3. 因式分解算子：$D^2+1 = (D-\text{i})(D+\text{i})$：

$$y^* = \operatorname{Re}\left(\frac{1}{D+\text{i}} \cdot \frac{1}{D-\text{i}} \text{e}^{\text{i}x}\right)$$

4. 对非零项 $D+\text{i}$ 直接代入 $D=\text{i}$：

$$\frac{1}{D+\text{i}} \to \frac{1}{2\text{i}}$$

5. 剩余项用指数移位（$\text{e}^{\text{i}x}$ 移出，后接 $\frac{1}{D}(1)$）：

$$\frac{1}{D-\text{i}}\text{e}^{\text{i}x} = \text{e}^{\text{i}x} \frac{1}{(D+\text{i})-\text{i}}(1) = \text{e}^{\text{i}x}\frac{1}{D}(1) = x\text{e}^{\text{i}x}$$

6. 综合运算并取实部：

$$y^* = \operatorname{Re}\left(\frac{1}{2\text{i}} x \text{e}^{\text{i}x}\right) = \operatorname{Re}\left(-\frac{\text{i}}{2} x (\cos x + \text{i}\sin x)\right) = \frac{1}{2}x\sin x$$

完全不需要设复杂的待定系数，直接化简即可完成求解。
