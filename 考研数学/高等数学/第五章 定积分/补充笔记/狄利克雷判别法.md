**狄利克雷（Dirichlet）判别法的定义与本质**

狄利克雷判别法主要用于解决**非绝对收敛（即带变号震荡因子）的反常积分或级数的敛散性判定**。它有两套完全平行的形式：

* **反常积分形式**
设函数 $f(x)$ 和 $g(x)$ 在区间 $[a, +\infty)$ 上满足：
   1. **原函数（积分）有界**：存在常数 $M > 0$，对任意 $A \ge a$，均有 $\left\vert{}\int_a^A f(x) dx\right\vert{} \le M$；
   2. **单调趋于零**：当 $x \to +\infty$ 时，$g(x)$ 单调递减（或单调递增）且 $\lim_{x \to +\infty} g(x) = 0$。
   * **结论**：广义积分 $\int_a^{+\infty} f(x)g(x) dx$ **必收敛**。

* **数项级数形式**
设级数 $\sum_{n=1}^\infty a_n b_n$ 满足：
   1. **部分和有界**：数列 $\{a_n\}$ 的前 $n$ 项和 $S_n = \sum_{k=1}^n a_k$ 有界（即存在 $M > 0$，使得对任意 $n$ 都有 $\vert{}S_n\vert{} \le M$）；
   2. **单调趋于零**：数列 $\{b_n\}$ 单调趋于 0（即 $b_n \to 0$ 且单调）。
   * **结论**：数项级数 $\sum_{n=1}^\infty a_n b_n$ **必收敛**。

**题型应用与解题方法**

狄利克雷判别法最典型的应用是处理形如 $\int_1^{+\infty} \frac{\sin x}{x^p} dx$ 或 $\sum_{n=1}^\infty \frac{\sin n}{n^p}$这类**正负抵消、绝对值发散**的条件收敛问题。

**常规方法**

* **方法一：因子拆分直接套用法（标准判定流程）**
面对含震荡三角函数的分式反常积分（如判别 $\int_1^{+\infty} \frac{\sin x}{x} dx$ 的敛散性）：
   * **第一步（拆分）**：将其拆解为震荡部分 $f(x) = \sin x$ 与单调部分 $g(x) = \frac{1}{x}$；
   * **第二步（验证有界性）**：$\left\vert{} \int_1^A \sin x dx \right\vert{} = \vert{}-\cos A + \cos 1\vert{} \le 2$，积分在任何区间上均有界；
   * **第三步（验证单调趋零）**：$g(x) = \frac{1}{x}$ 在 $[1, +\infty)$ 上单调递减，且 $\lim_{x\to+\infty} \frac{1}{x} = 0$；
   * **第四步（得出结论）**：由狄利克雷判别法，该积分收敛（注：因 $\int_1^{+\infty} \frac{\vert{}\sin x\vert{}}{x} dx$ 发散，故为条件收敛）。

* **方法二：分部积分验证法（不背定理时的推导串联法）**
若记不清狄利克雷判别法的前提条件，直接用分部积分可自行推导出收敛性：
   * 记 $F(x) = \int_a^x f(t) dt$（由条件知 $\vert{}F(x)\vert{} \le M$）：
$$\int_a^{+\infty} f(x)g(x) dx = \int_a^{+\infty} g(x) dF(x) = \left. g(x)F(x) \right\vert{}_a^{+\infty} - \int_a^{+\infty} F(x)g'(x) dx$$
   * 前半部分：由于 $F(x)$ 有界且 $g(x) \to 0$，代入极限得 $\lim_{x\to+\infty} g(x)F(x) - g(a)F(a) = 0 - 0 = 0$（存在有限）；
   * 后半部分：对绝对值积分进行放缩，利用 $g'(x)$ 保持定号（单调性）：
$$\int_a^{+\infty} \vert{}F(x)g'(x)\vert{} dx \le M \int_a^{+\infty} \vert{}g'(x)\vert{} dx = M \vert{}g(+\infty) - g(a)\vert{} < +\infty$$
   根据绝对收敛必收敛，后半部分积分也收敛。两部分相加，原反常积分必然收敛。

**特殊方法**

* **方法一：退化降维法（秒退化为莱布尼茨判别法）**
   * 在数项级数中，若取 $a_n = (-1)^n$：
   * 其前 $n$ 项和序列为 $-1, 0, -1, 0, \dots$，界显然为 $M=1$；
   * 只要后续数列 $b_n$ 满足单调递减趋于 0，即可判收敛。
   * **结论**：考研中常用的**莱布尼茨判别法（交错级数审敛）本质上就是狄利克雷判别法的最低阶特例**。

* **方法二：三角积化和差裂项定界法（快速确定级数部分和有界）**
在判定级数 $\sum_{n=1}^\infty \frac{\sin nx}{n^p}$ 或 $\sum_{n=1}^\infty \frac{\cos nx}{n^p}$ ($x \ne 2k\pi, p > 0$) 时，常需要快速证明 $S_n = \sum_{k=1}^n \sin kx$ 的有界性：
   * 两边同乘 $2\sin\frac{x}{2}$ 并利用积化和差展开：
$$2\sin\frac{x}{2} S_n = \sum_{k=1}^n \left[ \cos\left(k-\frac{1}{2}\right)x - \cos\left(k+\frac{1}{2}\right)x \right] = \cos\frac{x}{2} - \cos\left(n+\frac{1}{2}\right)x$$
   * 得到部分和表达式：
$$\vert{}S_n\vert{} = \left\vert{} \frac{\cos\frac{x}{2} - \cos(n+\frac{1}{2})x}{2\sin\frac{x}{2}} \right\vert{} \le \frac{1 + 1}{2\vert{}\sin\frac{x}{2}\vert{}} = \frac{1}{\vert{}\sin\frac{x}{2}\vert{}}$$
   * 上界仅与固定的 $x$ 有关，与 $n$ 完全无关，直接证明了有界性，结合 $\frac{1}{n^p} \downarrow 0$，立刻得出该级数收敛。
