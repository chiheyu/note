## 一、本章核心框架：从区域积分走向场的积分

本章是多元函数积分学的综合与高潮，它不仅涉及三重积分在空间区域上的计算，更将积分概念推广到曲线与曲面上，并根据物理背景区分为“与方向无关”的第一类积分和“与方向有关”的第二类积分。格林公式、高斯公式与斯托克斯公式则揭示了边界积分与区域积分之间的深刻联系，是向量微积分的精华所在。

本章主线可以概括为：
$$\text{三重积分} \to \text{第一类曲线与曲面积分} \to \text{第二类曲线积分与格林公式} \to \text{第二类曲面积分与高斯公式} \to \text{斯托克斯公式}$$

掌握本章的关键在于：
- **三重积分**：根据区域形状和被积函数选择坐标系，准确写出累次积分限。
- **第一类积分**：将曲线或曲面的几何度量（弧长 $ds$、面积 $dS$）表达出来。
- **第二类积分**：注意方向（曲线的走向、曲面的侧向），灵活运用三大公式化难为易。
- **三大公式**：理解其物理意义（通量、环量、散度、旋度），并熟记使用条件与方向约定。

## 二、三重积分

### 1. 三重积分的定义与意义
设函数 $f(x,y,z)$ 在空间有界闭区域 $\Omega$ 上有定义。将 $\Omega$ 任意分割成 $n$ 个小空间区域 $\Delta v_i$（也表示其体积），在每个小区域上任取点 $(\xi_i, \eta_i, \zeta_i)$，作积分和 $\sum f(\xi_i, \eta_i, \zeta_i) \Delta v_i$。当最大直径趋于零时，若极限存在，则称此极限为 $f$ 在 $\Omega$ 上的**三重积分**，记作：
$$\iiint_\Omega f(x,y,z)\,dv$$
其中 $dv$ 称为**体积元素**。

**几何与物理意义**：
- 若 $f(x,y,z) \equiv 1$，则 $\iiint_\Omega 1\,dv = V_\Omega$（空间区域 $\Omega$ 的体积）。
- 若 $\rho(x,y,z)$ 为空间物体的体密度，则质量 $m = \iiint_\Omega \rho(x,y,z)\,dv$。
- 质心坐标、转动惯量等物理量也可通过三重积分计算。

### 2. 直角坐标下的三重积分计算
将三重积分化为**三次积分**（累次积分）。关键在于将积分区域 $\Omega$ 向坐标面投影，并确定积分次序。

**典型步骤**：
1. 将 $\Omega$ 投影到某一坐标面（如 $xOy$ 面），得到投影区域 $D_{xy}$。
2. 过 $D_{xy}$ 内任一点 $(x,y)$ 作平行于 $z$ 轴的直线，它与 $\Omega$ 的边界曲面相交于两点，设下曲面为 $z = z_1(x,y)$，上曲面为 $z = z_2(x,y)$。
3. 则三重积分可化为：
$$\iiint_\Omega f(x,y,z)\,dv = \iint_{D_{xy}} \left( \int_{z_1(x,y)}^{z_2(x,y)} f(x,y,z)\,dz \right) dx\,dy$$
4. 对 $D_{xy}$ 上的二重积分，再根据其形状选择 $X$ 型或 $Y$ 型化为二次积分。

**注意**：投影区域的选择至关重要。通常选择投影后形状规整、上下曲面表达式简单的坐标面。若区域在某个方向上的投影边界复杂，可考虑换向投影或分割区域。

### 3. 柱面坐标下的三重积分
当积分区域 $\Omega$ 在 $xOy$ 面上的投影为圆形、扇形、圆环形，或被积函数含有 $x^2+y^2$ 时，宜采用柱面坐标。

**坐标变换**：
$$x = r\cos\theta,\quad y = r\sin\theta,\quad z = z \qquad (r \ge 0,\ 0 \le \theta \le 2\pi)$$
**体积元素**：$dv = r\,dr\,d\theta\,dz$

**积分公式**：
$$\iiint_\Omega f(x,y,z)\,dv = \iiint_{\Omega_{r\theta z}} f(r\cos\theta, r\sin\theta, z)\, r\,dr\,d\theta\,dz$$

**积分次序**：通常先对 $z$ 积分（积分限由上下曲面给出），再对 $r$ 积分，最后对 $\theta$ 积分；或者根据区域特点调整为其他次序。关键在于将 $\Omega$ 用 $r, \theta, z$ 描述清楚。

**适用情形**：
- 区域边界含有圆柱面 $x^2+y^2=R^2$。
- 区域含有圆锥面 $z = k\sqrt{x^2+y^2}$。
- 被积函数形如 $f(x^2+y^2, z)$。

### 4. 球面坐标下的三重积分
当积分区域为球体、球壳、锥体与球面的组合，或被积函数含有 $x^2+y^2+z^2$ 时，宜采用球面坐标。

**坐标变换**：
$$\begin{cases}
x = \rho \sin\varphi \cos\theta \\
y = \rho \sin\varphi \sin\theta \\
z = \rho \cos\varphi
\end{cases}$$
其中 $\rho \ge 0$ 为点到原点的距离，$\varphi \in [0, \pi]$ 为有向线段与 $z$ 轴正向的夹角（余纬度），$\theta \in [0, 2\pi]$ 为在 $xOy$ 面投影的极角。

**体积元素**：$dv = \rho^2 \sin\varphi \, d\rho\, d\varphi\, d\theta$

**积分公式**：
$$\iiint_\Omega f(x,y,z)\,dv = \iiint_{\Omega_{\rho\varphi\theta}} f(\rho\sin\varphi\cos\theta, \rho\sin\varphi\sin\theta, \rho\cos\varphi) \, \rho^2\sin\varphi \, d\rho\, d\varphi\, d\theta$$

**区域描述**：通常先确定 $\varphi$ 的范围（由锥面或平面给出），再对固定的 $\varphi$ 确定 $\rho$ 的范围（由内、外球面或曲面给出），最后确定 $\theta$ 的范围（绕 $z$ 轴的旋转角）。

**常见区域的球面坐标描述**：
- 球体 $\rho \le R$：$0 \le \rho \le R,\ 0 \le \varphi \le \pi,\ 0 \le \theta \le 2\pi$。
- 上半球体 $z \ge 0$：$0 \le \rho \le R,\ 0 \le \varphi \le \frac{\pi}{2},\ 0 \le \theta \le 2\pi$。
- 圆锥面 $\varphi = \alpha$ 内部：$\varphi$ 从 $0$ 到 $\alpha$。

### 5. 一般换元法（了解）
三重积分也有类似二重积分的换元公式，雅可比行列式 $J = \frac{\partial(x,y,z)}{\partial(u,v,w)}$，体积元素 $dv = |J|\,du\,dv\,dw$。柱面坐标与球面坐标是其特例。考研中直接考一般换元的极少，但应知道有此方法。

### 6. 三重积分的对称性
与二重积分类似，若积分区域 $\Omega$ 关于某坐标面对称，且被积函数关于相应变量具有奇偶性，则可简化计算。
- 若 $\Omega$ 关于 $xOy$ 面对称，$f$ 关于 $z$ 为奇函数，则积分为 $0$；为偶函数，则等于上半区域积分的 $2$ 倍。
- 轮换对称性：若 $\Omega$ 关于 $x,y,z$ 具有轮换对称性，则 $\iiint_\Omega x^2\,dv = \iiint_\Omega y^2\,dv = \iiint_\Omega z^2\,dv$，可简化计算。

## 三、第一类曲线积分（对弧长的曲线积分）

### 1. 定义与意义
设 $L$ 为空间中的一条分段光滑曲线，$f(x,y,z)$ 在 $L$ 上有定义。第一类曲线积分记为 $\int_L f(x,y,z)\,ds$，其中 $ds$ 为**弧长元素**。

**物理意义**：
- 若 $f(x,y,z)$ 表示线密度，则积分为曲线构件的质量。
- 若 $f \equiv 1$，则 $\int_L 1\,ds = L$ 的长度。

**核心性质**：第一类曲线积分**与曲线的方向无关**，即 $\int_{L(AB)} f\,ds = \int_{L(BA)} f\,ds$。

### 2. 计算方法
将曲线参数化是计算第一类曲线积分的基本方法。设曲线 $L$ 的参数方程为：
$$x = x(t),\ y = y(t),\ z = z(t) \quad (\alpha \le t \le \beta)$$
其中 $x(t), y(t), z(t)$ 在 $[\alpha, \beta]$ 上具有一阶连续导数，且不同时为零。则弧长元素为：
$$ds = \sqrt{[x'(t)]^2 + [y'(t)]^2 + [z'(t)]^2}\,dt$$
积分化为定积分：
$$\int_L f(x,y,z)\,ds = \int_\alpha^\beta f(x(t), y(t), z(t)) \sqrt{[x'(t)]^2 + [y'(t)]^2 + [z'(t)]^2}\,dt$$

**特殊情形**：
- 平面曲线 $y = y(x)\ (a \le x \le b)$：$ds = \sqrt{1 + [y'(x)]^2}\,dx$。
- 平面曲线由极坐标给出 $r = r(\theta)\ (\alpha \le \theta \le \beta)$：$ds = \sqrt{r^2(\theta) + [r'(\theta)]^2}\,d\theta$。

### 3. 对称性的运用
若曲线 $L$ 关于某坐标轴对称，且被积函数关于相应变量为奇函数或偶函数，则可类似二重积分那样利用对称性化简。但要注意，曲线关于平面或轴的对称性需要根据具体几何判断。

## 四、第一类曲面积分（对面积的曲面积分）

### 1. 定义与意义
设 $\Sigma$ 为分片光滑的空间曲面，$f(x,y,z)$ 在 $\Sigma$ 上有定义。第一类曲面积分记为 $\iint_\Sigma f(x,y,z)\,dS$，其中 $dS$ 为**面积元素**。

**物理意义**：
- 若 $f(x,y,z)$ 表示面密度，则积分为曲面构件的质量。
- 若 $f \equiv 1$，则 $\iint_\Sigma 1\,dS = S_\Sigma$（曲面的面积）。

**核心性质**：第一类曲面积分**与曲面的侧向无关**。

### 2. 计算方法
基本方法是将曲面投影到某一坐标面上，化为二重积分。设曲面 $\Sigma$ 的方程为 $z = z(x,y)$，$(x,y) \in D_{xy}$，且 $z(x,y)$ 具有连续偏导数。则面积元素为：
$$dS = \sqrt{1 + \left(\frac{\partial z}{\partial x}\right)^2 + \left(\frac{\partial z}{\partial y}\right)^2}\,dx\,dy$$
积分化为：
$$\iint_\Sigma f(x,y,z)\,dS = \iint_{D_{xy}} f(x, y, z(x,y)) \sqrt{1 + z_x^2 + z_y^2}\,dx\,dy$$

**类似地**，若曲面投影到 $xOz$ 面或 $yOz$ 面更方便，则可用相应公式：
- 若曲面为 $y = y(x,z)$，则 $dS = \sqrt{1 + y_x^2 + y_z^2}\,dx\,dz$。
- 若曲面为 $x = x(y,z)$，则 $dS = \sqrt{1 + x_y^2 + x_z^2}\,dy\,dz$。

**选择投影面的原则**：使得投影区域 $D$ 尽量简单，且曲面方程能唯一确定单值函数。

### 3. 对称性与轮换对称性
- 若曲面 $\Sigma$ 关于 $xOy$ 面对称，$f(x,y,z)$ 关于 $z$ 为奇函数，则积分为 $0$；为偶函数，则等于上半曲面部分的 $2$ 倍。
- 若曲面 $\Sigma$ 具有轮换对称性（即 $x,y,z$ 互换后曲面不变），则 $\iint_\Sigma x^2\,dS = \iint_\Sigma y^2\,dS = \iint_\Sigma z^2\,dS$ 等。

## 五、第二类曲线积分（对坐标的曲线积分）

### 1. 定义与物理背景
第二类曲线积分的一般形式为：
$$\int_L P(x,y,z)\,dx + Q(x,y,z)\,dy + R(x,y,z)\,dz$$
或向量形式 $\int_L \mathbf{F} \cdot d\mathbf{r}$，其中 $\mathbf{F} = (P, Q, R)$，$d\mathbf{r} = (dx, dy, dz)$。

**物理意义**：力场 $\mathbf{F}$ 沿曲线 $L$ 对质点所作的**功**。

**方向依赖性**：第二类曲线积分**与曲线的方向有关**。设 $L^-$ 表示与 $L$ 反向的曲线，则 $\int_{L^-} \mathbf{F} \cdot d\mathbf{r} = -\int_L \mathbf{F} \cdot d\mathbf{r}$。

### 2. 直接计算法（参数化法）
设曲线 $L$ 的参数方程为 $x = x(t), y = y(t), z = z(t)$，且当参数 $t$ 从 $\alpha$ 单调变到 $\beta$ 时，对应曲线从起点到终点（方向由参数增加方向确定）。则：
$$dx = x'(t)\,dt,\ dy = y'(t)\,dt,\ dz = z'(t)\,dt$$
积分化为定积分：
$$\int_L Pdx + Qdy + Rdz = \int_\alpha^\beta \left[ P(x(t),y(t),z(t)) x'(t) + Q(\cdots) y'(t) + R(\cdots) z'(t) \right] dt$$
**注意**：下限 $\alpha$ 对应起点，上限 $\beta$ 对应终点，与 $\alpha, \beta$ 的大小无关，完全由方向决定。

### 3. 平面第二类曲线积分与格林公式
对于平面情形 $\int_L P(x,y)\,dx + Q(x,y)\,dy$，若 $L$ 为**封闭曲线**，则可考虑使用**格林公式**。

**格林公式**：设闭区域 $D$ 由分段光滑的曲线 $L$ 围成，函数 $P(x,y), Q(x,y)$ 在 $D$ 上具有一阶连续偏导数，则：
$$\oint_L P\,dx + Q\,dy = \iint_D \left( \frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y} \right) dx\,dy$$
其中 $L$ 是 $D$ 的**正向边界曲线**（沿 $L$ 行走时，区域 $D$ 始终在左手侧）。对于单连通区域，正向通常指逆时针方向。

**格林公式的应用**：
- **简化计算**：闭曲线积分转化为二重积分。
- **求平面区域面积**：取 $P = -y, Q = x$，则 $\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y} = 2$，故 $S_D = \frac{1}{2} \oint_L x\,dy - y\,dx$。也可取 $P=0, Q=x$ 或 $P=-y, Q=0$ 等。
- **非闭曲线的处理**：若 $L$ 不封闭，可补上一条辅助曲线使其封闭，再用格林公式减去辅助线上的积分。

**曲线积分与路径无关的条件**：设 $D$ 为单连通区域，$P, Q$ 在 $D$ 内有一阶连续偏导数，则以下四个命题等价：
1. $\int_L Pdx + Qdy$ 在 $D$ 内与路径无关，只与起终点有关。
2. 沿 $D$ 内任意闭曲线的积分为零：$\oint_L Pdx + Qdy = 0$。
3. 在 $D$ 内恒有 $\frac{\partial Q}{\partial x} = \frac{\partial P}{\partial y}$。
4. $Pdx + Qdy$ 是某个函数 $u(x,y)$ 的全微分，即 $du = Pdx + Qdy$，此时 $u(x,y) = \int_{(x_0,y_0)}^{(x,y)} Pdx + Qdy$。

### 4. 空间第二类曲线积分与斯托克斯公式
对于空间闭曲线上的第二类曲线积分，可借助**斯托克斯公式**转化为曲面积分。

**斯托克斯公式**：设 $\Gamma$ 为分段光滑的空间有向闭曲线，$\Sigma$ 是以 $\Gamma$ 为边界的分片光滑的有向曲面，$\Gamma$ 的方向与 $\Sigma$ 的侧向符合**右手法则**（右手四指沿 $\Gamma$ 方向，拇指指向曲面 $\Sigma$ 的法向）。若函数 $P, Q, R$ 在包含 $\Sigma$ 的空间区域内有一阶连续偏导数，则：
$$\oint_\Gamma Pdx + Qdy + Rdz = \iint_\Sigma 
\begin{vmatrix}
dydz & dzdx & dxdy \\
\frac{\partial}{\partial x} & \frac{\partial}{\partial y} & \frac{\partial}{\partial z} \\
P & Q & R
\end{vmatrix}$$
上式右端也可写为向量形式：$\iint_\Sigma (\nabla \times \mathbf{F}) \cdot \mathbf{n}\,dS$，其中 $\nabla \times \mathbf{F}$ 为旋度。

**使用场景**：直接参数化空间曲线较麻烦，而曲线又恰好是某简单曲面（如平面、球面等）的边界时，用斯托克斯公式将曲线积分化为曲面积分，往往可以极大简化计算。

**旋度与保守场**：若 $\nabla \times \mathbf{F} = \mathbf{0}$ 在单连通区域内恒成立，则空间曲线积分与路径无关，$\mathbf{F}$ 为保守场。

## 六、第二类曲面积分（对坐标的曲面积分）

### 1. 定义与物理背景
第二类曲面积分的一般形式为：
$$\iint_\Sigma P\,dydz + Q\,dzdx + R\,dxdy$$
向量形式为 $\iint_\Sigma \mathbf{F} \cdot d\mathbf{S}$，其中 $d\mathbf{S} = \mathbf{n}\,dS$，$\mathbf{n}$ 为曲面的单位法向量。

**物理意义**：设流体速度场为 $\mathbf{v} = (P, Q, R)$，则第二类曲面积分表示单位时间内流体流过曲面 $\Sigma$ 的**通量**（流量）。

**侧向依赖性**：第二类曲面积分**与曲面的侧向有关**。取相反侧时，积分值变号。

### 2. 直接计算法（投影法）
以计算 $\iint_\Sigma R(x,y,z)\,dxdy$ 为例，需将曲面 $\Sigma$ 投影到 $xOy$ 面上。
- 若 $\Sigma$ 由方程 $z = z(x,y)$ 给出，$(x,y) \in D_{xy}$，则：
$$\iint_\Sigma R(x,y,z)\,dxdy = \pm \iint_{D_{xy}} R(x,y,z(x,y))\,dxdy$$
当取曲面的**上侧**（法向量与 $z$ 轴正向夹角为锐角）时取正号，取**下侧**时取负号。

类似地，对于 $\iint_\Sigma P\,dydz$，需投影到 $yOz$ 面，前侧取正、后侧取负；对于 $\iint_\Sigma Q\,dzdx$，需投影到 $zOx$ 面，右侧取正、左侧取负。

**统一投影法**：若要将三项积分统一投影到某一坐标面（通常选 $xOy$ 面），可利用曲面方程的关系，将 $dydz, dzdx$ 转化为 $dxdy$：
$$dydz = -z_x\,dxdy,\quad dzdx = -z_y\,dxdy$$
从而：
$$\iint_\Sigma P\,dydz + Q\,dzdx + R\,dxdy = \iint_{D_{xy}} \left( -P z_x - Q z_y + R \right) dxdy$$
此时符号已根据所选侧向（如上侧）自动确定。若取下侧，则需整体加负号。

### 3. 高斯公式（奥斯特罗格拉茨基公式）
当积分曲面 $\Sigma$ 为**封闭曲面**时，可运用**高斯公式**将曲面积分转化为三重积分。

**高斯公式**：设空间闭区域 $\Omega$ 由分片光滑的封闭曲面 $\Sigma$ 围成，函数 $P, Q, R$ 在 $\Omega$ 上具有一阶连续偏导数，则：
$$\oiint_\Sigma P\,dydz + Q\,dzdx + R\,dxdy = \iiint_\Omega \left( \frac{\partial P}{\partial x} + \frac{\partial Q}{\partial y} + \frac{\partial R}{\partial z} \right) dv$$
其中 $\Sigma$ 取**外侧**（法向量指向外部）。

**散度**：$\operatorname{div} \mathbf{F} = \frac{\partial P}{\partial x} + \frac{\partial Q}{\partial y} + \frac{\partial R}{\partial z}$，故高斯公式可写为 $\oiint_\Sigma \mathbf{F} \cdot d\mathbf{S} = \iiint_\Omega \operatorname{div} \mathbf{F}\,dv$，表示通量等于散度的体积分。

**应用技巧**：
- **直接使用**：封闭曲面且被积函数偏导易求。
- **补面法**：若 $\Sigma$ 不封闭，可补上一个简单曲面（如平面上的圆盘）使其封闭，用高斯公式计算封闭曲面上的积分，再减去补面上的积分。补面时注意侧向一致性（通常使封闭曲面取外侧）。

## 七、格林公式、高斯公式、斯托克斯公式的综合对比

| 公式 | 维度 | 对象 | 核心等式 | 物理意义 |
| :--- | :--- | :--- | :--- | :--- |
| **格林公式** | 2D | 闭曲线 $L$ $\leftrightarrow$ 平面区域 $D$ | $\oint_L Pdx+Qdy = \iint_D (Q_x - P_y)\,d\sigma$ | 环量 = 旋度的面积分 |
| **高斯公式** | 3D | 闭曲面 $\Sigma$ $\leftrightarrow$ 空间区域 $\Omega$ | $\oiint_\Sigma \mathbf{F}\cdot d\mathbf{S} = \iiint_\Omega \operatorname{div}\mathbf{F}\,dv$ | 通量 = 散度的体积分 |
| **斯托克斯公式** | 3D | 空间闭曲线 $\Gamma$ $\leftrightarrow$ 曲面 $\Sigma$ | $\oint_\Gamma \mathbf{F}\cdot d\mathbf{r} = \iint_\Sigma (\nabla\times\mathbf{F})\cdot d\mathbf{S}$ | 环量 = 旋度的通量 |

**使用三公式的注意事项**：
- **条件检验**：曲线必须封闭（格林、斯托克斯），曲面必须封闭（高斯），且涉及的函数在相应区域内有连续偏导。
- **方向约定**：格林公式中 $L$ 取正向（逆时针）；高斯公式中 $\Sigma$ 取外侧；斯托克斯公式中 $\Gamma$ 与 $\Sigma$ 符合右手法则。
- **奇点处理**：若区域内存在偏导不连续的点（奇点），需挖去奇点小邻域，用复连通区域的相应公式。

## 八、曲线与曲面积分分类总表

| 类型 | 记号 | 与方向关系 | 几何/物理意义 | 主要计算方法 |
| :--- | :--- | :--- | :--- | :--- |
| 第一类曲线 | $\int_L f\,ds$ | 无关 | 弧长加权平均；线质量 | 参数化，化为定积分 |
| 第二类曲线 | $\int_L Pdx+Qdy+Rdz$ | 有关 | 力做功；环量 | 参数化；格林/斯托克斯 |
| 第一类曲面 | $\iint_\Sigma f\,dS$ | 无关 | 面积加权平均；面质量 | 投影，化为二重积分 |
| 第二类曲面 | $\iint_\Sigma P\,dydz+Q\,dzdx+R\,dxdy$ | 有关 | 通量（流量） | 投影法；高斯公式 |

## 九、典型题型与解题模板

### 题型一：三重积分的计算
**步骤**：
1. 分析积分区域 $\Omega$ 的形状与对称性，确定最优坐标系（直角/柱面/球面）。
2. 在选定坐标系下，将 $\Omega$ 的边界用变量范围描述清楚。
3. 利用对称性化简被积函数或积分区域。
4. 列出累次积分，依次计算三次定积分。

**例**：计算 $\iiint_\Omega (x^2+y^2)\,dv$，其中 $\Omega$ 由锥面 $z = \sqrt{x^2+y^2}$ 与平面 $z=1$ 围成。
- 区域为圆锥体，用柱面坐标：$0 \le \theta \le 2\pi$，$0 \le r \le 1$，$r \le z \le 1$。
- 积分：$\int_0^{2\pi} d\theta \int_0^1 r \cdot r^2 \, dr \int_r^1 dz = 2\pi \int_0^1 r^3 (1-r) dr = 2\pi \cdot \frac{1}{20} = \frac{\pi}{10}$。

### 题型二：第一类曲线积分的计算
**步骤**：
1. 写出曲线的参数方程，确定参数范围。
2. 计算弧长微分 $ds$。
3. 代入被积函数，化为定积分计算。

**例**：计算 $\int_L \sqrt{x^2+y^2}\,ds$，$L$ 为圆周 $x^2+y^2 = ax\ (a>0)$。
- 参数化：用极坐标，圆方程 $r = a\cos\theta$，参数 $\theta$ 从 $-\pi/2$ 到 $\pi/2$。
- $x = a\cos^2\theta,\ y = a\cos\theta\sin\theta$。
- $ds = \sqrt{r^2 + r'^2}\,d\theta = a\,d\theta$。
- 积分 $\int_{-\pi/2}^{\pi/2} a\cos\theta \cdot a\,d\theta = 2a^2$。

### 题型三：第二类曲线积分与格林公式
**步骤**：
1. 观察曲线是否封闭。若封闭且满足格林公式条件，优先用格林公式。
2. 若不封闭，考虑补线使其封闭，或直接参数化。
3. 注意方向（正向/反向），以及是否经过奇点。

**例**：计算 $\oint_L (x^2y + y^3)\,dx - (x^3 + xy^2)\,dy$，$L$ 为单位圆 $x^2+y^2=1$ 正向。
- $P = x^2y+y^3,\ Q = -(x^3+xy^2)$。
- $\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y} = -3x^2 - y^2 - (x^2 + 3y^2) = -4(x^2+y^2)$。
- 格林公式：$\iint_D -4(x^2+y^2)\,dxdy = -4\int_0^{2\pi}d\theta \int_0^1 r^2 \cdot r\,dr = -4 \cdot 2\pi \cdot \frac{1}{4} = -2\pi$。

### 题型四：第二类曲面积分与高斯公式
**步骤**：
1. 判断曲面是否封闭。若封闭且满足高斯公式条件，优先用高斯公式。
2. 若不封闭，补面使其封闭（通常补平面），用高斯公式后再减去补面部分。
3. 注意侧向（闭曲面取外侧，补面时注意与原曲面侧向协调）。

**例**：计算 $\iint_\Sigma x^3\,dydz + y^3\,dzdx + z^3\,dxdy$，$\Sigma$ 为球面 $x^2+y^2+z^2=R^2$ 外侧。
- 高斯公式：散度 $\frac{\partial P}{\partial x} + \frac{\partial Q}{\partial y} + \frac{\partial R}{\partial z} = 3(x^2+y^2+z^2)$。
- 积分 $= \iiint_\Omega 3(x^2+y^2+z^2)\,dv$。用球面坐标计算得 $\frac{12}{5}\pi R^5$。

### 题型五：斯托克斯公式的应用
**步骤**：
1. 确认曲线封闭，且是某曲面的边界。
2. 选取一个以该曲线为边界且形状简单的曲面（如平面片）。
3. 根据右手法则确定曲面侧向，计算旋度的曲面积分。
4. 若旋度简单，计算可大大简化。

**例**：计算 $\oint_\Gamma y\,dx + z\,dy + x\,dz$，$\Gamma$ 为平面 $x+y+z=1$ 被三个坐标面截得的三角形边界，从 $z$ 轴正向看为逆时针。
- 取 $\Sigma$ 为该三角形上侧。法向量 $\mathbf{n} = \frac{1}{\sqrt{3}}(1,1,1)$。
- 旋度 $\nabla\times\mathbf{F} = (-1, -1, -1)$。
- 积分 $= \iint_\Sigma (-1,-1,-1) \cdot \mathbf{n}\,dS = -\sqrt{3} \iint_\Sigma dS = -\sqrt{3} \cdot \text{Area}(\Sigma) = -\sqrt{3} \cdot \frac{\sqrt{3}}{2} = -\frac{3}{2}$。

## 十、高频易错点与避坑指南

1. **柱面坐标漏乘 $r$，球面坐标漏乘 $\rho^2\sin\varphi$**：坐标变换必须乘雅可比绝对值，这是最频繁的错误。
2. **第一类积分与第二类积分混淆**：第一类积分与方向无关，第二类与方向有关，方向反了差一个负号。
3. **格林公式中正向的判断**：正向是区域在左侧，单连通区域一般指逆时针。反向则需加负号。
4. **高斯公式要求闭曲面外侧**：非闭曲面不能直接用，必须补面；补面后注意整体取外侧，再减去补面部分时补面应取相应的内侧或外侧。
5. **斯托克斯公式的方向与侧向的右手法则**：曲线方向与曲面法向必须满足右手法则，否则差负号。
6. **投影时符号处理错误**：第二类曲面积分投影到坐标面时，符号由曲面的侧向决定（上侧正、下侧负等），或者用统一投影法时牢记公式 $-Pz_x - Qz_y + R$。
7. **参数化时参数范围与曲线方向不对应**：参数从小到大的方向必须与积分路径方向一致。
8. **对称性在第二类积分中的误用**：第二类积分（尤其曲面积分）的对称性使用需格外谨慎，要同时考虑曲面侧向与函数的奇偶性，有时奇函数在对称侧向反而不会抵消（因为侧向相反导致符号抵消）。
9. **忽略奇点**：若被积函数或偏导在区域内有不连续点，需挖洞处理，再用复连通区域的相应公式。
10. **混淆 $dS$ 与 $dxdy$**：第一类曲面积分用 $dS = \sqrt{1+z_x^2+z_y^2}\,dxdy$，第二类直接用 $dxdy$，注意区别。

## 十一、本章知识网络图

- 🎯 **核心目标**：把空间区域、曲线边界、曲面边界之间的积分关系打通。
  - 🧊 **三重积分**
    - **直角坐标**：投影区域 + 上下截面，关键是写准积分限。
    - **柱面坐标**：$dv=r\,dr\,d\theta\,dz$，适合圆柱、圆锥、旋转区域。
    - **球面坐标**：$dv=\rho^2\sin\varphi\,d\rho\,d\varphi\,d\theta$，适合球域、球壳。
    - **应用方向**：体积、质量、质心、转动惯量。
  - 📏 **第一类曲线/曲面积分**
    - **曲线第一类**：$\int_L f\,ds$，与方向无关，参数化后计算 $ds$。
    - **曲面第一类**：$\iint_\Sigma f\,dS$，与侧向无关，投影后计算 $dS$。
    - **本质理解**：对长度或面积进行加权累加。
  - 🧭 **第二类曲线积分**
    - **基本形式**：$\int_L Pdx+Qdy+Rdz$，与方向有关。
    - **直接法**：参数化曲线，把 $dx,dy,dz$ 全部替换。
    - **格林公式**：平面闭曲线转二重积分。
    - **斯托克斯公式**：空间闭曲线转曲面积分。
  - 🌊 **第二类曲面积分**
    - **基本形式**：$\iint_\Sigma P\,dydz+Q\,dzdx+R\,dxdy$。
    - **物理意义**：向量场穿过有向曲面的通量。
    - **投影法**：必须先确定曲面侧向。
    - **高斯公式**：闭曲面通量转三重积分。
  - 🔗 **三大公式**
    - **格林公式**：平面闭曲线积分 $\leftrightarrow$ 平面区域二重积分。
    - **高斯公式**：闭曲面通量 $\leftrightarrow$ 空间区域三重积分。
    - **斯托克斯公式**：空间闭曲线环量 $\leftrightarrow$ 曲面旋度通量。
## 十二、一句话总结

**多元积分学的核心是“区域与边界”的对话。三重积分深耕空间区域的累加，第一类曲线曲面积分聚焦几何度量的加权求和，第二类积分则刻画向量场的环量与通量。格林、高斯、斯托克斯三大公式将边界积分与区域积分贯通一体，掌握它们的方向约定、使用条件与物理背景，方能在综合题中化繁为简，直击要害。**
