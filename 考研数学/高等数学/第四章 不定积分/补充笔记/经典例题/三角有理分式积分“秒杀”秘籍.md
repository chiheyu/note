# 三角有理分式积分的“待定系数法”总结

## 1. 适用题型
适用于被积函数为正弦、余弦一次线性组合的分式积分，标准形式为：
$$\int \frac{a \sin x + b \cos x}{c \sin x + d \cos x} dx$$

> **注**：如果分子或分母只有其中一项（例如只有 $\cos x$），可视为另一项的系数为 $0$，该方法同样适用。

---

## 2. 核心思想
避免使用计算量庞大的万能公式，将**分子**巧妙拆解为与**分母**相关的两部分：
* **一部分是分母本身**（这部分积分后产生一次项 $x$）。
* **另一部分是分母的导数**（这部分积分后产生对数项 $\ln|\text{分母}|$）。

---

## 3. 标准操作步骤

### 第一步：构造恒等式
设分子为 $M(x)$，分母为 $N(x)$。令分子等于分母及其导数的线性组合：
$$M(x) = A \cdot N(x) + B \cdot N'(x)$$
即：
$$a \sin x + b \cos x = A(c \sin x + d \cos x) + B(c \cos x - d \sin x)$$

### 第二步：对比系数求常数
将上式右侧展开，合并 $\sin x$ 和 $\cos x$ 的同类项，通过对应系数相等列出方程组：
* $\sin x$ 的系数：$a = Ac - Bd$
* $\cos x$ 的系数：$b = Ad + Bc$

通过解这个二元一次方程组，求出具体的常数 $A$ 和 $B$。

### 第三步：代入并直接积分
将求得的拆分形式代回原积分，积分式自动分离为两个基础形式：
$$\int \frac{A \cdot N(x) + B \cdot N'(x)}{N(x)} dx = \int \left( A + B \frac{N'(x)}{N(x)} \right) dx$$
利用基本积分公式 $\int \frac{1}{u} du = \ln|u| + C$，直接写出最终结果：
$$Ax + B \ln|c \sin x + d \cos x| + C$$

---

## 4. 进阶变式（带常数项）
如果积分的分子或分母中带有常数项，例如：
$$\int \frac{a \sin x + b \cos x + e}{c \sin x + d \cos x + f} dx$$

只需在第一步的恒等式中增加一个待定常数项 $K$：
$$M(x) = A \cdot N(x) + B \cdot N'(x) + K$$

展开后对比 $\sin x$、$\cos x$ 的系数以及常数项，解出 $A$、$B$、$K$。
其积分结果前两项依然是 $Ax + B \ln|N(x)|$，仅针对最后剩下的常数项部分 $K \int \frac{1}{c \sin x + d \cos x + f} dx$ 使用万能公式单独计算即可。

---

## 5. 方法优势对比

| 特性 | 待定系数法 | 万能公式 ($t = \tan \frac{x}{2}$) |
| :--- | :--- | :--- |
| **计算量** | **极小**（只需解简单的线性方程组） | **极大**（涉及复杂的通分和有理分式拆分） |
| **出错率** | **低**（结构清晰，步骤固定） | **高**（常数项、符号和高次幂极易算错） |
| **适用范围** | 仅限 $\sin x$ 和 $\cos x$ 的一次线性组合 | 通用于所有三角有理式，但效率低下 |
