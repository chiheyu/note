
## 一、 极限的核心概念与性质

### 1. 数列极限的保号性与保序性
* **保序性：** 若 $\lim a_n = a, \lim b_n = b$，且 $a < b$，则当 $n$ 充分大时，必然有 $a_n < b_n$。
* **不等式取极限：** 若 $M \le a_n \le N$，则 $\lim M \le \lim a_n \le \lim N$。（注意：即使原数列是严格不等号，取极限后也**必须**带上等号）。
* **$\epsilon-N$ 语言的逆向思维：** 遇到抽象的极限判断题，常通过构造反例来证伪。例如，已知 $\lim a_n = a \neq 0$，构造 $a_n = a - \frac{2}{n}$ 可打破常规思维定势。

### 2. “无界”与“无穷大”的严格区分
* **无界变量：** 只要能找到**一个**走向无穷的子序列，函数就是无界的。它可能在无穷大和零之间剧烈震荡（例如 $f(x) = x \sin x$）。
* **无穷大：** 要求当 $x \to \infty$（或 $x \to x_0$）时，**所有的**函数值绝对值 $|f(x)|$ 都必须无限增大。
* **核心结论：** 无穷大必定是无界变量，但无界变量不一定是无穷大。

## 二、 极限计算的核心技法与避坑指南

### 1. 等价无穷小的正确打开方式
* **适用场景：** 乘除法中可以无脑替换；加减法中必须满足“非同阶相减”或“提取公因式转化为乘法”的前提条件。
* **核心公式（$x \to 0$）：**
    * 代数类：$\ln(1+x) \sim x$；$e^x - 1 \sim x$；$(1+x)^\alpha - 1 \sim \alpha x$
    * 三角类：$\sin x \sim x$；$\tan x \sim x$；$\arcsin x \sim x$；$\arctan x \sim x$；$1 - \cos x \sim \frac{1}{2}x^2$

### 2. 泰勒公式（麦克劳林展开式）：加减法的终极武器
* **“上下同阶”原则：** 在 $\frac{0}{0}$ 型极限的加减法中，若发生“首项抵消”（如 $\tan x - \sin x$），绝对不能用等价无穷小，必须用泰勒公式展开到不为零的第一项。
* **必背高频展开式（$x \to 0$）：**
    * $\sin x = x - \frac{1}{3!}x^3 + o(x^3)$
    * $\cos x = 1 - \frac{1}{2!}x^2 + \frac{1}{4!}x^4 + o(x^4)$
    * $e^x = 1 + x + \frac{1}{2!}x^2 + \frac{1}{3!}x^3 + o(x^3)$
    * $\ln(1+x) = x - \frac{1}{2}x^2 + \frac{1}{3}x^3 + o(x^3)$
    * $\tan x = x + \frac{1}{3}x^3 + o(x^3)$

### 3. $1^{\infty}$ 型极限（幂指函数）
* **万能公式：** 若 $\lim u(x) = 0$ 且 $\lim v(x) = \infty$，则 $\lim (1 + u)^v = e^{\lim u \cdot v}$。
* **解题三步走：** 强行凑出 $1$ $\to$ 找出无穷小 $u$ $\to$ 计算指数部分的极限 $\lim u \cdot v$。

### 4. 趋于负无穷（$x \to -\infty$）的致命陷阱
* **绝对值变号：** 牢记 $\sqrt{x^2} = |x|$。当 $x \to -\infty$ 时，**$\sqrt{x^2} = -x$**。
* **破局方法：** 遇到 $x \to -\infty$，建议第一步直接进行变量代换（令 $t = -x$），将问题转化为 $t \to +\infty$，彻底根除符号出错的隐患。

## 三、 函数的连续性与间断点分析

### 1. 极限存在与连续的本质区别
* **极限存在：** $\lim_{x \to x_0} f(x) = A$。只关心 $x_0$ 附近点的值，与 $x_0$ 本身的定义值无关。
* **连续：** $\lim_{x \to x_0} f(x) = f(x_0)$。极限值必须等于该点的函数定义值。

### 2. 必须分左右极限讨论的“可疑分子”
遇到以下结构，必须无条件拆分 $x \to x_0^+$ 和 $x \to x_0^-$：
1.  **分母趋于 0 的指数：** $e^{\frac{1}{x}}$、$e^{\frac{1}{x-1}}$（$0^+$ 时为 $+\infty$，$0^-$ 时为 $0$）。
2.  **分母趋于 0 的反三角：** $\arctan\frac{1}{x}$（$0^+$ 时为 $\frac{\pi}{2}$，$0^-$ 时为 $-\frac{\pi}{2}$）。
3.  **其他：** 绝对值函数 $\frac{|x|}{x}$、符号函数 $\text{sgn}(x)$、取整函数 $[x]$、以及分段函数的分界点。

### 3. 间断点的寻找与分类
* **第一类间断点（左右极限均存在）：**
    * 可去间断点：左极限 $=$ 右极限 $\neq$ 函数值（或无定义）。
    * 跳跃间断点：左极限 $\neq$ 右极限。
* **第二类间断点（至少有一个极限不存在）：**
    * 无穷间断点：极限为 $\infty$（常出现在分母为 0 处）。
    * 振荡间断点：极限在某区间内不断跳跃（如 $\sin\frac{1}{x}$）。

## 四、 递推数列极限（大题专属）

### 1. 单调有界准则
* **核心定理：** 单调有界数列必有极限。
* **标准解题三步曲：**
    1.  **证有界：** 利用均值不等式（$\sqrt{xy} \le \frac{x+y}{2}$）或数学归纳法证明数列有上界或下界。
    2.  **证单调：** 利用作差法（$a_{n+1} - a_n$ 或 $a_{n+1}^2 - a_n^2$）或作商法判断符号，证明数列单调递增或递减。
    3.  **求极限：** 设 $\lim_{n \to \infty} a_n = A$，对原递推等式两边同时取极限，解方程求出 $A$，并结合有界性/单调性舍去不合题意的解。
