## 一、本节核心框架：向量是线性组合的基本对象

向量是线性代数中最基础的单元。在中学阶段，向量主要指向具有大小和方向的几何量（二维或三维）；而在考研线性代数中，向量被抽象为 $n$ 维数组，成为刻画高维空间、研究线性方程组解结构以及矩阵列（行）空间的核心工具。

本节旨在建立 $n$ 维向量的代数运算体系，并重点引入**线性组合**与**线性表示**的概念，为后续学习向量组的线性相关性、极大无关组以及向量空间理论奠定基础。

**学习要点**：
- 理解 $n$ 维向量的定义及其与几何向量的联系与区别。
- 熟练掌握向量的加法、数乘运算及八条运算律。
- 深刻理解线性组合与线性表示的定义，并能将表示问题转化为线性方程组的求解问题。
- 掌握向量组与矩阵的对应关系，学会利用矩阵的秩和初等变换研究向量。

---

## 二、$n$ 维向量的定义与基本形式

### 1. 定义
由 $n$ 个数 $a_1, a_2, \cdots, a_n$ 组成的有序数组称为 **$n$ 维向量**，记作：
$$\alpha = (a_1, a_2, \cdots, a_n) \quad \text{或} \quad \alpha = \begin{pmatrix} a_1 \\ a_2 \\ \vdots \\ a_n \end{pmatrix}$$
其中 $a_i$ 称为向量 $\alpha$ 的第 $i$ 个**分量**。

**向量的分类**：
- **行向量**：写成一行的形式 $\alpha = (a_1, a_2, \cdots, a_n)$，对应 $1 \times n$ 矩阵。
- **列向量**：写成一列的形式 $\alpha = \begin{pmatrix} a_1 \\ a_2 \\ \vdots \\ a_n \end{pmatrix}$，对应 $n \times 1$ 矩阵。

**默认约定**：在考研数学中，若无特殊说明，向量一般指**列向量**。行向量通常视为列向量的转置，记作 $\alpha^T$。

### 2. 特殊向量
- **零向量**：所有分量均为 $0$ 的向量，记作 $\mathbf{0} = (0,0,\cdots,0)^T$。
- **负向量**：将 $\alpha$ 的各分量取相反数得到的向量，记作 $-\alpha$。
- **单位坐标向量**：只有第 $i$ 个分量为 $1$，其余分量为 $0$ 的向量，记作 $e_i$（如 $e_1 = (1,0,\cdots,0)^T$）。
- **相等向量**：两个同维向量 $\alpha, \beta$，若对应分量全部相等，则称 $\alpha = \beta$。

### 3. 几何直观与高维推广
- 二维向量 $(x,y)$ 对应平面上的有向线段。
- 三维向量 $(x,y,z)$ 对应空间中的有向线段。
- $n>3$ 时，向量失去了直接的几何图像，但其代数运算规则与低维完全一致。通过抽象定义，我们可以将低维的线性关系推广到任意高维空间。

## 三、向量的线性运算

### 1. 向量加法
设 $\alpha = (a_1, a_2, \cdots, a_n)^T$，$\beta = (b_1, b_2, \cdots, b_n)^T$，定义：
$$\alpha + \beta = (a_1+b_1, a_2+b_2, \cdots, a_n+b_n)^T$$
**几何意义（二维/三维）**：平行四边形法则或三角形法则。

**加法运算律**：
- 交换律：$\alpha + \beta = \beta + \alpha$
- 结合律：$(\alpha + \beta) + \gamma = \alpha + (\beta + \gamma)$
- 有零元：$\alpha + \mathbf{0} = \alpha$
- 有负元：$\alpha + (-\alpha) = \mathbf{0}$

### 2. 向量数乘（数量乘法）
设 $k$ 为实数，$\alpha = (a_1, \cdots, a_n)^T$，定义：
$$k\alpha = (ka_1, ka_2, \cdots, ka_n)^T$$
**几何意义**：$k>0$ 时同向伸缩，$k<0$ 时反向伸缩，$|k|$ 为伸缩比例。

**数乘运算律**：
- $1 \cdot \alpha = \alpha$
- $k(l\alpha) = (kl)\alpha$
- 分配律1：$(k+l)\alpha = k\alpha + l\alpha$
- 分配律2：$k(\alpha+\beta) = k\alpha + k\beta$

### 3. 向量的线性运算与矩阵行变换的统一
向量的加法和数乘本质上就是对应分量的加法和乘法。当我们将向量组排列成矩阵时，矩阵的**初等行变换**本质就是对行向量进行线性运算；**初等列变换**则是对列向量进行线性运算。这种统一性是后续用矩阵方法解决向量组问题的理论依据。

## 四、线性组合与线性表示

### 1. 线性组合的定义
给定向量组 $A: \alpha_1, \alpha_2, \cdots, \alpha_s$ 和一组实数 $k_1, k_2, \cdots, k_s$，称向量：
$$k_1\alpha_1 + k_2\alpha_2 + \cdots + k_s\alpha_s$$
为向量组 $A$ 的一个**线性组合**，$k_1,\cdots,k_s$ 称为该组合的**系数**。

### 2. 线性表示（线性表出）
若存在一组数 $k_1, k_2, \cdots, k_s$，使得：
$$\beta = k_1\alpha_1 + k_2\alpha_2 + \cdots + k_s\alpha_s$$
则称向量 $\beta$ 可由向量组 $\alpha_1, \alpha_2, \cdots, \alpha_s$ **线性表示**（或线性表出）。

**特殊情况**：
- **零向量**必可由任意向量组线性表示：$\mathbf{0} = 0\alpha_1 + \cdots + 0\alpha_s$。
- **向量组中任一向量**可由该组本身线性表示：$\alpha_i = 0\alpha_1 + \cdots + 1\alpha_i + \cdots + 0\alpha_s$。

### 3. 线性表示的转化——方程组与矩阵语言
这是考研解题的关键转化链条：

> $\beta$ 可由 $\alpha_1, \cdots, \alpha_s$ 线性表示  
> $\iff$ 存在实数 $x_1, \cdots, x_s$ 使得 $x_1\alpha_1 + \cdots + x_s\alpha_s = \beta$  
> $\iff$ 方程组 $AX = \beta$ 有解（其中 $A = (\alpha_1, \cdots, \alpha_s)$ 为列向量组构成的矩阵）  
> $\iff$ 系数矩阵的秩等于增广矩阵的秩：$r(A) = r(A \mid \beta)$

**进一步推论**：
- 若表示**唯一** $\iff$ 方程组 $AX = \beta$ 有唯一解 $\iff r(A) = r(A \mid \beta) = s$（$s$ 为向量组中向量个数）。
- 若表示**不唯一** $\iff$ 方程组有无穷多解 $\iff r(A) = r(A \mid \beta) < s$。

### 4. 线性表示的传递性
若向量组 (Ⅰ) $\alpha_1, \cdots, \alpha_s$ 中每个向量均可由向量组 (Ⅱ) $\beta_1, \cdots, \beta_t$ 线性表示，且向量组 (Ⅱ) 中每个向量均可由向量组 (Ⅲ) $\gamma_1, \cdots, \gamma_p$ 线性表示，则向量组 (Ⅰ) 可由向量组 (Ⅲ) 线性表示。简言之，**线性表示关系具有传递性**。

## 五、向量组与矩阵的关系

将向量组的研究转化为矩阵的研究，是线性代数最重要的方法论。

### 1. 向量组的矩阵表示
设向量组 $A: \alpha_1, \alpha_2, \cdots, \alpha_s$（均为列向量），将它们按列排成一个 $n \times s$ 矩阵：
$$A = (\alpha_1, \alpha_2, \cdots, \alpha_s)$$
此时，对向量组做线性运算、判断线性表示、研究相关性等问题，均可通过对矩阵 $A$ 进行**初等行变换**或计算**秩**来解决。

### 2. 初等行变换不改变列向量组的线性关系
**重要定理**：对矩阵 $A$ 进行初等**行**变换化为矩阵 $B$，则 $A$ 的列向量组与 $B$ 的列向量组具有**完全相同的线性关系**。
- 若 $A$ 的某些列向量线性无关，则 $B$ 中对应位置的列向量也线性无关。
- 若 $A$ 中某列向量可由其他列线性表示，则 $B$ 中对应位置也具有相同的表示系数。

**操作意义**：研究列向量组时，只管放心大胆地做初等行变换，将矩阵化为行阶梯形或行最简形，然后读取列向量间的线性关系。但**严禁做初等列变换**（列变换会打乱列向量原有的线性组合关系）。

### 3. 向量组秩与矩阵秩的统一
向量组的秩定义为该组极大线性无关组所含向量的个数。而矩阵的秩等于其列向量组的秩，也等于其行向量组的秩。因此：
$$r(\alpha_1, \alpha_2, \cdots, \alpha_s) = r(A)$$
其中 $A = (\alpha_1, \cdots, \alpha_s)$。这样，向量组的秩问题就完全转化为矩阵秩的计算问题。

## 六、等价向量组

### 1. 定义
设有两个 $n$ 维向量组：
(Ⅰ) $\alpha_1, \alpha_2, \cdots, \alpha_s$
(Ⅱ) $\beta_1, \beta_2, \cdots, \beta_t$
若向量组 (Ⅰ) 中每个向量均可由向量组 (Ⅱ) 线性表示，且向量组 (Ⅱ) 中每个向量均可由向量组 (Ⅰ) 线性表示，则称这两个向量组**等价**。

### 2. 等价的矩阵判定条件
构造矩阵 $A = (\alpha_1, \cdots, \alpha_s)$ 和 $B = (\beta_1, \cdots, \beta_t)$。
向量组 (Ⅰ) 与 (Ⅱ) 等价 $\iff$ 矩阵 $A$ 与 $B$ 的列向量组可互相线性表示。
这等价于矩阵方程 $AX = B$ 和 $BY = A$ 均有解，进一步等价于：
$$r(A) = r(B) = r(A \mid B)$$
即拼接后的矩阵的秩等于各自矩阵的秩。

### 3. 等价的性质
- 反身性：任意向量组与自身等价。
- 对称性：若 (Ⅰ) 与 (Ⅱ) 等价，则 (Ⅱ) 与 (Ⅰ) 等价。
- 传递性：若 (Ⅰ) 与 (Ⅱ) 等价，(Ⅱ) 与 (Ⅲ) 等价，则 (Ⅰ) 与 (Ⅲ) 等价。

### 4. 等价向量组的重要推论
- **等价的向量组具有相同的秩**。（注意：秩相同只是等价的必要条件，不是充分条件）
- 等价的线性无关向量组所含向量个数相同。
- 任意向量组与其极大线性无关组等价。

## 七、向量运算与线性表示的计算方法

### 1. 判定向量 $\beta$ 能否由 $\alpha_1, \cdots, \alpha_s$ 线性表示
**方法一（方程组法）**：
设 $x_1\alpha_1 + \cdots + x_s\alpha_s = \beta$，解非齐次线性方程组。有解则能表示，无解则不能。

**方法二（矩阵秩法）**：
构造增广矩阵 $B = (\alpha_1, \cdots, \alpha_s \mid \beta)$，比较 $r(A)$ 与 $r(B)$。

**方法三（初等行变换法）**：
对 $B$ 做初等行变换化为行最简形，观察是否出现矛盾行（如 $0 = c$，$c \neq 0$）。

### 2. 将向量组 (Ⅰ) 用向量组 (Ⅱ) 线性表示
这本质上是解矩阵方程。例如，若 $\alpha_1, \alpha_2$ 可由 $\beta_1, \beta_2, \beta_3$ 线性表示，求表示系数。只需将 $(\beta_1, \beta_2, \beta_3 \mid \alpha_1, \alpha_2)$ 进行初等行变换，将左侧系数矩阵化为单位阵（或行最简形），右侧即得表示矩阵。

## 八、向量组线性相关性的预热

虽然本节重点是线性组合与表示，但线性相关性是紧随其后的核心内容。此处先引入基本直觉：

- 若向量组中存在某个向量可由其余向量线性表示，则该向量组**线性相关**。
- 若向量组中任一向量都不能由其余向量线性表示，则**线性无关**。
- 对于仅含一个向量的向量组：若为零向量则线性相关；若为非零向量则线性无关。
- 对于两个向量：线性相关 $\iff$ 对应分量成比例（共线）。
- 对于三个三维向量：线性相关 $\iff$ 三向量共面（行列式为零）。

## 九、高频易错点与避坑指南

1. **行向量与列向量虽然维数相同，但在矩阵乘法中不能混淆**  
   $n$ 维行向量是 $1 \times n$ 矩阵，$n$ 维列向量是 $n \times 1$ 矩阵。做内积时需转置匹配。

2. **线性组合的系数是数，不是向量**  
   $k_1\alpha_1$ 中的 $k_1$ 是实数，不能写成向量形式。

3. **零向量可由任意向量组线性表示，表示系数全为零**  
   这是唯一确定的一种表示方式（若要求系数全为零）。但这并不说明向量组线性无关，反而零向量自身是线性相关的。

4. **向量组问题与矩阵问题的切换**  
   研究列向量组关系时，只做**初等行变换**；研究行向量组关系时，只做**初等列变换**。不可混淆。

5. **“$\beta$ 可由 $\alpha_1, \cdots, \alpha_s$ 线性表示”是存在性命题**  
   系数存在即可，不要求唯一。若进一步要求表示唯一，则需增加条件（如 $\alpha_1, \cdots, \alpha_s$ 线性无关）。

6. **等价向量组的秩相同，但秩相同的向量组未必等价**  
   例如两个 $3$ 维向量组，秩均为 $2$，但一个张成平面 $P_1$，另一个张成平面 $P_2$，若 $P_1 \neq P_2$，则它们不等价。

7. **判断能否线性表示时，增广矩阵不要写反**  
   方程组是 $x_1\alpha_1 + \cdots + x_s\alpha_s = \beta$，增广矩阵是 $(\alpha_1, \cdots, \alpha_s \mid \beta)$，不要把 $\beta$ 放在前面。

## 十、经典题型与例题精讲

### 题型一：判断向量能否由向量组线性表示
**例题**：设 $\alpha_1 = (1,2,-1)^T, \alpha_2 = (2,3,1)^T, \beta = (4,7,-1)^T$。问 $\beta$ 能否由 $\alpha_1, \alpha_2$ 线性表示？若能，写出表示式。
**解**：
设 $x_1\alpha_1 + x_2\alpha_2 = \beta$，即解方程组：
$$\begin{pmatrix}1&2\\2&3\\-1&1\end{pmatrix} \begin{pmatrix}x_1\\x_2\end{pmatrix} = \begin{pmatrix}4\\7\\-1\end{pmatrix}$$
增广矩阵：
$$\begin{pmatrix}1&2&4\\2&3&7\\-1&1&-1\end{pmatrix} \xrightarrow{\text{行变换}} \begin{pmatrix}1&2&4\\0&-1&-1\\0&3&3\end{pmatrix} \xrightarrow{\text{行变换}} \begin{pmatrix}1&2&4\\0&1&1\\0&0&0\end{pmatrix}$$
得 $x_2 = 1, x_1 = 2$，且无矛盾行。故能表示，且 $\beta = 2\alpha_1 + \alpha_2$。

### 题型二：讨论含参数的线性表示问题
**例题**：已知 $\alpha_1 = (1,0,1)^T, \alpha_2 = (1,1,2)^T, \beta = (a, b, c)^T$。讨论 $a,b,c$ 满足什么条件时，$\beta$ 可由 $\alpha_1, \alpha_2$ 线性表示？表示是否唯一？
**解**：
增广矩阵：
$$\begin{pmatrix}1&1&a\\0&1&b\\1&2&c\end{pmatrix} \to \begin{pmatrix}1&1&a\\0&1&b\\0&1&c-a\end{pmatrix} \to \begin{pmatrix}1&1&a\\0&1&b\\0&0&c-a-b\end{pmatrix}$$
方程组有解 $\iff c - a - b = 0$。此时 $r(A)=r(\bar{A})=2$，等于未知数个数，故表示唯一。
结论：当 $c = a + b$ 时能唯一线性表示；否则不能。

### 题型三：求一个向量组用另一个向量组表示的系数矩阵
**例题**：已知向量组 (Ⅰ)：$\alpha_1 = (1,1)^T, \alpha_2 = (1,-1)^T$；向量组 (Ⅱ)：$\beta_1 = (1,0)^T, \beta_2 = (0,1)^T$。求 (Ⅱ) 用 (Ⅰ) 线性表示的系数矩阵。
**解**：
即求矩阵 $X$ 使得 $(\alpha_1, \alpha_2) X = (\beta_1, \beta_2)$。
$$A = \begin{pmatrix}1&1\\1&-1\end{pmatrix},\quad B = \begin{pmatrix}1&0\\0&1\end{pmatrix}$$
解矩阵方程 $AX = B$，得 $X = A^{-1}B$。
计算得 $A^{-1} = \frac{1}{2}\begin{pmatrix}1&1\\1&-1\end{pmatrix}$，故 $X = \frac{1}{2}\begin{pmatrix}1&1\\1&-1\end{pmatrix}$。
即 $\beta_1 = \frac{1}{2}\alpha_1 + \frac{1}{2}\alpha_2,\ \beta_2 = \frac{1}{2}\alpha_1 - \frac{1}{2}\alpha_2$。

### 题型四：证明等价向量组的秩相同
**证明**：设向量组 (Ⅰ) 与 (Ⅱ) 等价。由 (Ⅰ) 可由 (Ⅱ) 线性表示，则 $r(Ⅰ) \le r(Ⅱ)$；由 (Ⅱ) 可由 (Ⅰ) 线性表示，则 $r(Ⅱ) \le r(Ⅰ)$。故 $r(Ⅰ) = r(Ⅱ)$。

## 十一、本章知识网络图

- 🎯 **核心目标**：把 $n$ 维数组理解为线性组合、线性表示和向量组结构的基本对象。
  - 🧩 **向量定义**
    - **基本形式**：$n$ 维行向量与列向量。
    - **特殊向量**：零向量、负向量、单位坐标向量。
    - **分量表示**：向量运算最终都落在分量计算上。
  - 🧮 **线性运算**
    - **加法**：对应分量相加。
    - **数乘**：每个分量同时倍乘。
    - **运算律**：构成向量空间运算规则的基础。
  - 🔗 **线性组合与线性表示**
    - **线性组合**：$k_1\alpha_1+\cdots+k_s\alpha_s$。
    - **线性表示**：$\beta$ 能否写成某向量组的线性组合。
    - **存在性**：转化为非齐次方程组是否有解。
    - **唯一性**：转化为对应向量组是否线性无关。
  - 🧱 **向量组与矩阵**
    - **列向量组**：排成矩阵 $A=(\alpha_1,\cdots,\alpha_s)$。
    - **秩的连接**：向量组的秩等于对应矩阵的秩。
    - **表示问题**：本质是矩阵方程 $AX=\beta$。
  - ⚠️ **易错提醒**
    - **形状匹配**：行向量和列向量不能随意混用。
    - **变换区别**：初等行变换和初等列变换作用对象不同。
    - **等价误区**：等价向量组秩相同，但秩相同不一定等价。
## 十二、一句话总结

**向量是线性代数的基础语言。理解向量的线性运算、掌握线性组合与线性表示的定义，并能将“表示问题”迅速转化为“矩阵的秩”与“线性方程组解的存在性”问题，是攻克向量组线性相关性与极大无关组等后续难题的必备前置技能。**
