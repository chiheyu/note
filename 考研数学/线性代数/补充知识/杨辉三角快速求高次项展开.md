# 杨辉三角 (Pascal's Triangle) 核心知识点

## 1. 基本定义与构造规律
杨辉三角是一个无限延伸的数字阵列，主要用于快速获取二项式展开的系数。

**构造规则：**
* **边界为 1：** 阵列的左右两条斜边（即每行的首尾数字）永远是 `1`。
* **中间项相加：** 内部的每一个数字，等于它正上方两个数字之和。

> **示例（前6行）：**
> 第 0 行：1
> 第 1 行：1  1
> 第 2 行：1  2  1
> 第 3 行：1  3  3  1
> 第 4 行：1  4  6  4  1
> 第 5 行：1  5  10 10  5  1

---

## 2. 核心数学性质

* **对称性：** 每一行的数字左右完全对称。
* **组合数关联：** 杨辉三角的第 $n$ 行、第 $k$ 个数（从 0 开始计数），恰好等于组合数 $C_n^k$（或记作 $\binom{n}{k}$）。
    * 例如，第 5 行第 2 个数（从 0 开始算，即数字 10），等于 $C_5^2 = \frac{5 \times 4}{2 \times 1} = 10$。
* **行和规律：** 第 $n$ 行的所有数字之和等于 $2^n$。
    * 例如，第 3 行：$1 + 3 + 3 + 1 = 8 = 2^3$。

---

## 3. 核心应用：二项式定理

杨辉三角最直接的作用是提供 $(x+y)^n$ 展开式的系数。

**通用公式 (二项式定理)：**
$$(x+y)^n = C_n^0 x^n + C_n^1 x^{n-1}y + C_n^2 x^{n-2}y^2 + \dots + C_n^n y^n$$

**展开操作指南：**
1.  **查系数：** 展开 $n$ 次方，直接使用杨辉三角第 $n$ 行的数字作为各项的系数。
2.  **排幂次：** 第一项 $x$ 的指数从 $n$ 递减到 0；第二项 $y$ 的指数从 0 递增到 $n$。
3.  **定符号：**
    * 如果是 $(x+y)^n$，所有项均为正号 `+`。
    * 如果是 $(x-y)^n$，相当于 $y$ 带有负号，展开后各项符号呈**正负交替**（`+` `-` `+` `-` ...）。

---

## 4. 在矩阵（线性代数）中的应用技巧

在处理矩阵多项式或求逆矩阵时，杨辉三角可以极大提升计算速度，免去繁琐的矩阵乘法。

**⚠️ 适用条件：** 只有当两个矩阵**可交换**时（即 $AB = BA$），才能使用二项式定理展开。
* **最常见场景：** 矩阵 $A$ 与单位矩阵 $E$ （因为 $AE = EA = A$ 永远成立，必定可交换）。

**实战案例：展开 $(A-E)^5$**
* **提取系数：** 查阅杨辉三角第 5 行，系数为 `1, 5, 10, 10, 5, 1`。
* **确定符号：** 中间是减号，符号必然交替为 `+ - + - + -`。
* **降幂排列：**
    $$(A-E)^5 = A^5 - 5A^4E + 10A^3E^2 - 10A^2E^3 + 5AE^4 - E^5$$
* **化简（因为 $E^k = E$ 且 $A^kE = A^k$）：**
    $$A^5 - 5A^4 + 10A^3 - 10A^2 + 5A - E$$

**🔥 错题防范注意点：** 矩阵的 0 次方是单位矩阵 $E$，千万不能写成普通数字 $1$！例如上述多项式的常数项最后必须写成 $-E$，而绝对不能写成 $-1$。
