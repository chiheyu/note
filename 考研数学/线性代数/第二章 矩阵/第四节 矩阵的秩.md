## 一、 本节核心框架：秩是刻画矩阵“有效信息量”的唯一指标

### 1. 秩的多维视角
矩阵的秩 $r(A)$ 是线性代数中最核心的数字特征，它将矩阵、向量组、线性方程组三大板块完美串联：
* **子式视角（代数定义）：** 矩阵中非零子式的最高阶数。
* **向量组视角（几何意义）：** $r(A) =$ 矩阵行向量组的秩 $=$ 矩阵列向量组的秩（即极大线性无关组中向量的个数）。
* **方程组视角（空间维数）：** $r(A)$ 决定了齐次线性方程组 $Ax=0$ 基础解系所含解向量的个数（即 $n - r(A)$）。

---

## 二、 秩的严格定义与阶梯形矩阵

### 1. $k$ 阶子式与秩的定义
* **$k$ 阶子式：** 在 $m \times n$ 矩阵 $A$ 中任取 $k$ 行 $k$ 列，其交点上的 $k^2$ 个元素按原顺序构成的行列式。
* **秩的定义：** 设 $A$ 中至少有一个 $r$ 阶子式不为 $0$，且**所有**的 $r+1$ 阶子式（如果存在的话）全为 $0$，则称 $A$ 的秩为 $r$，记作 $r(A) = r$ 或 $\text{rank}(A) = r$。
* **规定：** 零矩阵的秩为 $0$。

### 2. 阶梯形矩阵与秩的“直读”
* 经过初等行变换，矩阵可以化为**行阶梯形矩阵**。
* **核心定理：** 行阶梯形矩阵的秩等于其**非零行的行数**。
* **理论升华：** 初等变换（无论是行变换还是列变换）**绝对不改变**矩阵的秩。即若 $A \cong B$（$A$ 与 $B$ 等价），则 $r(A) = r(B)$。

---

## 三、 秩的核心计算兵法（满分实战）

1. **数值型矩阵求秩：**
   * **唯一准则：** 永远优先使用**初等行变换**，将其化为行阶梯形矩阵，数非零行的个数。
   * **警告：** 千万不要企图通过算行列式来找秩，高阶矩阵算子式的工作量是毁灭性的。
2. **含参数矩阵求秩：**
   * **小规模（如 $3 \times 3$ 或 $4 \times 4$ 方阵）：** 优先算行列式 $|A|$。令 $|A|=0$ 求出参数的“奇点”，然后将具体参数代回原矩阵，化阶梯形求秩。
   * **非方阵或大规模：** 行变换化阶梯形，在主元位置出现含参表达式时，按该表达式“等于 $0$”和“不等于 $0$”进行分类讨论。

## 四、 秩的八大黄金不等式与性质（考研证明题的题眼）

*这是考研线性代数中出现频率最高、技巧性最强的一组公式，必须烂熟于心！*

### 1. 基础界限
$$0 \le r(A_{m \times n}) \le \min(m, n)$$
$$r(A) = r(A^T)$$

### 2. 加法与减法（子空间维度限制）
$$r(A \pm B) \le r(A) + r(B)$$
*(几何意义：两个空间的和空间的维数，不超过各自维数之和)*

### 3. 乘法的不等式链（绝对重点）
* **基本乘法：** $r(AB) \le \min(r(A), r(B))$ （乘积的秩不超过因子的秩）。
* **西尔维斯特 (Sylvester) 不等式（极高频）：** 设 $A$ 为 $m \times n$ 矩阵，$B$ 为 $n \times s$ 矩阵，则：
  $$r(A) + r(B) - n \le r(AB)$$
* **极其重要的推论：** 若 $AB = O$，则 $r(A) + r(B) \le n$。（原因：$AB=O \implies r(AB)=0$，代入上式即得。常用于证明题的切入点）。

### 4. 满秩矩阵的“保秩性”
* 若 $P, Q$ 可逆（即满秩），则 $r(PAQ) = r(A)$。
* **通俗理解：** 乘以可逆矩阵相当于进行一系列初等变换，绝不改变矩阵的秩。

### 5. 伴随矩阵的秩（常考选择题）
对于 $n$ 阶方阵 $A$（$n \ge 2$）：
* 若 $r(A) = n$，则 $r(A^*) = n$。
* 若 $r(A) = n-1$，则 $r(A^*) = 1$。
* 若 $r(A) < n-1$，则 $r(A^*) = 0$（即 $A^*$ 为零矩阵）。

### 6. 实对称矩阵专属特权
对于实矩阵 $A$：
$$r(A^T A) = r(A A^T) = r(A)$$

### 7. 分块矩阵的秩
* $r\begin{pmatrix} A & O \\ O & B \end{pmatrix} = r(A) + r(B)$
* $r\begin{pmatrix} A & C \\ O & B \end{pmatrix} \ge r(A) + r(B)$

## 五、 满分书写规范与经典例题（考研 Standard Proof Formats）

### 例 1：利用乘积为零证明秩的不等式（满分证明格式）
**题目：** 设 $A, B$ 均为 $n$ 阶方阵，且满足 $AB = A + B$，证明：$r(A-E) + r(B-E) = n$。

**【满分解答范本】**
**证明：**
(1) 由已知条件 $AB = A + B$，移项可得：
$$AB - A - B = O$$
(2) 两边同时加上单位阵 $E$，凑配因式变形为：
$$AB - A - B + E = E$$
$$(A-E)(B-E) = E$$
(3) 由矩阵乘法的秩不等式 $r(XY) \le \min(r(X), r(Y))$，有：
$$r[(A-E)(B-E)] \le r(A-E)$$
又因为 $(A-E)(B-E) = E$，且 $r(E) = n$，故：
$$n \le r(A-E) \le n \implies r(A-E) = n$$
同理可得：
$$r(B-E) = n$$
(4) 从而 $r(A-E) + r(B-E) = n + n = 2n$。
*(注：若题目是 $AB=O$ 证明 $r(A)+r(B)\le n$，则直接引用 $AB=O \implies B$ 的列向量是 $Ax=0$ 的解，进而 $r(B) \le n - r(A)$ 完成证明。这是考研最标准的两套证明逻辑)*

## 六、 高频易错点与致命误区（避坑指南）

1. **概念混淆：** 矩阵的秩**绝不等于**非零元素的个数！$\begin{pmatrix} 1 & 1 \\ 1 & 1 \end{pmatrix}$ 有 4 个非零元素，但秩只有 1。
2. **初等变换改变行列式：** 行（列）变换不改变矩阵的秩，但除了倍加变换外，**交换和倍乘都会改变行列式的值**。求秩时可以随意变换，但若顺带求 $|A|$，必须小心系数和符号的补救。
3. **等价与同秩的陷阱：**
   * 两个**同型矩阵** $A$ 和 $B$ 等价 $\iff r(A) = r(B)$。
   * 若只说 $r(A)=r(B)$，但没说它们同型（维度不同），则它们**不能**称为等价。
4. **$r(A+B)$ 与 $r(A)+r(B)$ 错用等号：** $r(A+B)$ 通常严格小于 $r(A)+r(B)$，绝不能凭直觉当成线性运算直接拆开。
5. **列向量的秩拼接：** $r(A \mid b) \le r(A) + 1$（增广矩阵的秩最多比原矩阵大 1，这是判断非齐次方程组解的底层逻辑）。

## 七、 必须掌握的核心结论清单

* 阶梯形矩阵求秩法。
* $Ax=0$ 的解空间维数公式：$n - r(A)$。
* $AB=O \implies r(A)+r(B) \le n$ （历年大题高频第一问）。
* 伴随矩阵 $A^*$ 秩的 1、n、n-1 判定法。
* 实矩阵 $A^TA$ 与 $A$ 同秩的性质。

**秩是穿透矩阵维度的“降维打击”工具，计算它全靠“行变换化阶梯型”，而考研证明题的半壁江山，都建立在“西尔维斯特不等式”与“$AB=O \implies r(A)+r(B) \le n$”的巧妙转化之上。**
