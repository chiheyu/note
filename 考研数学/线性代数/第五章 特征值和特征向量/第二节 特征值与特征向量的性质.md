## 一、本节核心框架：特征值连接迹、行列式和矩阵多项式

特征值的性质是线性代数中“计算加速器”与“逻辑推演器”的双重角色。掌握这些性质，可以在选择题和填空题中绕过繁琐的矩阵求逆、高次幂运算，直接得出结果；在证明题中，特征值的性质也是构建论证链条的关键一环。

本节将在第一节“基本概念与计算”的基础上，深入剖析特征值的内在数量关系、运算保持规律以及与相似矩阵的深刻联系。

---

## 二、特征值与迹、行列式的关系

这是贯穿考研数学始终的两个最常用恒等式，必须烂熟于心。

### 1. 基本公式
设 $n$ 阶方阵 $A$ 的全部特征值为 $\lambda_1, \lambda_2, \cdots, \lambda_n$（重根按重数计入，包括可能出现的复数根），则：

$$\sum_{i=1}^n \lambda_i = \operatorname{tr}(A) = a_{11} + a_{22} + \cdots + a_{nn}$$

$$\prod_{i=1}^n \lambda_i = |A|$$

**公式推导依据**：
特征多项式展开为：
$$f(\lambda) = |\lambda E - A| = \lambda^n - (\operatorname{tr} A)\lambda^{n-1} + \cdots + (-1)^n |A|$$
由代数基本定理，$f(\lambda) = (\lambda - \lambda_1)(\lambda - \lambda_2)\cdots(\lambda - \lambda_n)$。
比较两边 $\lambda^{n-1}$ 和常数项的系数即可得证。

### 2. 重要推论
- **推论1**：矩阵 $A$ 可逆的充要条件是 $0$ 不是 $A$ 的特征值（即 $|A| \neq 0$）。
- **推论2**：若 $A$ 为 $n$ 阶矩阵，秩 $r(A) < n$，则 $0$ 必为特征值，且其代数重数至少为 $n - r(A)$。
- **推论3**：实对称矩阵（或任意方阵）的迹和行列式不依赖于基的选取，是相似不变量。

### 3. 常见应用场景
- **已知特征值求参数**：若题设告知特征值，可直接联立迹和行列式方程反解参数。
- **验证计算结果**：计算完所有特征值后，快速求和与求积验证是否等于迹和行列式。
- **抽象矩阵求行列式**：不必知道矩阵具体元素，只要知道特征值，行列式立得。

## 三、矩阵多项式与逆矩阵的特征值

这是特征值最强大的运算性质，核心思想是**函数作用在矩阵上等同于作用在特征值上**。

### 1. 基本定理
若 $\lambda$ 是矩阵 $A$ 的特征值，$\xi$ 是对应的特征向量，则对于任意多项式 $f(x) = a_mx^m + \cdots + a_1x + a_0$，有：
$$f(A)\xi = f(\lambda)\xi$$
即：**$\lambda$ 的多项式 $f(\lambda)$ 是矩阵多项式 $f(A)$ 的特征值，且对应的特征向量仍为 $\xi$**。

### 2. 常见特例列表

| 矩阵运算 | 特征值变化 | 特征向量变化 | 前提条件 |
| :--- | :--- | :--- | :--- |
| $kA$ （$k \neq 0$ 常数） | $k\lambda$ | 不变 | 无 |
| $A^m$ （$m$ 为正整数） | $\lambda^m$ | 不变 | 无 |
| $A + kE$ | $\lambda + k$ | 不变 | 无 |
| $f(A)$ （多项式） | $f(\lambda)$ | 不变 | 无 |
| $A^{-1}$ | $\frac{1}{\lambda}$ | 不变 | $A$ 可逆（$\lambda \neq 0$） |
| $A^*$ （伴随矩阵） | $\frac{\|A\|}{\lambda}$ | 不变 | $A$ 可逆（$\lambda \neq 0$） |
| $A^T$ | $\lambda$ | **一般改变** | 无 |

**注**：关于伴随矩阵 $A^*$ 的特征值公式 $\frac{|A|}{\lambda}$ 可由 $A^* = |A|A^{-1}$ 结合多项式性质直接得到。若 $A$ 不可逆（存在零特征值），该公式需单独讨论。

### 3. 特别强调：特征向量的“遗传性”
- 在 $kA, A^m, f(A), A^{-1}, A^*$ 中，**特征向量 $\xi$ 完全不变**。这一性质在求解矩阵高次幂作用在向量上时极其有用。
- 注意：$A^T$ 的特征值与 $A$ 相同，但特征向量通常不同，除非 $A$ 为对称矩阵。

## 四、不同特征值对应特征向量的线性无关性

### 1. 核心定理
设 $\lambda_1, \lambda_2, \cdots, \lambda_m$ 是矩阵 $A$ 的**互不相同**的特征值，$\xi_{i1}, \xi_{i2}, \cdots, \xi_{ik_i}$ 是属于 $\lambda_i$ 的线性无关的特征向量。则由所有这些向量构成的集合：
$$\{ \xi_{11}, \cdots, \xi_{1k_1}, \xi_{21}, \cdots, \xi_{mk_m} \}$$
是**线性无关**的。

### 2. 通俗理解
- **不同特征值的特征向量之间绝对不会“共线”或“共面”**，它们天然地张成了不同方向的子空间。
- **属于同一特征值的特征向量不一定线性无关**，这取决于该特征值的几何重数。若几何重数大于1，则存在多个线性无关的特征向量；反之若几何重数等于1，则只有一个线性无关方向。

### 3. 定理应用价值
- **证明矩阵可对角化**：若 $n$ 阶矩阵有 $n$ 个互不相同的特征值，则必可对角化（因为能凑齐 $n$ 个线性无关的特征向量）。
- **构建特征空间基底**：不同特征值对应的特征子空间是**直和**关系，即 $V_{\lambda_i} \cap \sum_{j \neq i} V_{\lambda_j} = \{0\}$。

## 五、相似矩阵的特征值

### 1. 相似的定义与性质
若存在可逆矩阵 $P$，使得 $B = P^{-1}AP$，则称 $A$ 与 $B$ **相似**，记作 $A \sim B$。

**相似矩阵具有完全相同的：**
1. 特征多项式（$|\lambda E - A| = |\lambda E - B|$）
2. 特征值（包括代数重数）
3. 行列式（$|A| = |B|$）
4. 迹（$\operatorname{tr}(A) = \operatorname{tr}(B)$）
5. 秩（$r(A) = r(B)$）

**注意**：
- 相似矩阵的特征向量一般**不同**。若 $\xi$ 是 $A$ 的特征向量，则 $P^{-1}\xi$ 是 $B$ 的对应特征向量。
- 特征值相同是相似的必要条件，**并非充分条件**。例如 $A = \begin{pmatrix}1&1\\0&1\end{pmatrix}$ 与 $B = \begin{pmatrix}1&0\\0&1\end{pmatrix}$ 特征值均为 $1$，但不相似（前者不可对角化，后者已对角化）。

### 2. 由特征值推导相似关系
若题目告知两矩阵特征值相同，不能直接得出相似结论。必须进一步考察**特征向量的个数**或**最小多项式**是否一致。

## 六、其他重要特征值性质补充

考研中常考的进阶性质，往往以二级结论的形式出现在选填题中。

### 1. 关于矩阵乘积的特征值
- **性质**：$AB$ 与 $BA$ 具有相同的**非零特征值**（包括代数重数）。
  - 特别地，当 $A,B$ 均为 $n$ 阶方阵时，$AB$ 与 $BA$ 的所有特征值（含零）均相同，且迹与行列式相等。
  - 若 $A$ 为 $m \times n$ 矩阵，$B$ 为 $n \times m$ 矩阵，则 $AB$ 与 $BA$ 的非零特征值相同，但零特征值的重数可能不同（由于阶数不同）。

### 2. 幂等矩阵与对合矩阵的特征值
- 若 $A^2 = A$（幂等矩阵），则特征值只能为 $0$ 或 $1$。
- 若 $A^2 = E$（对合矩阵），则特征值只能为 $1$ 或 $-1$。
- 若 $A^m = 0$（幂零矩阵），则特征值全为 $0$。

### 3. 实对称矩阵的特征值性质（先导）
- 实对称矩阵的特征值全为**实数**。
- 实对称矩阵属于不同特征值的特征向量**相互正交**。
- 实对称矩阵必可**正交相似对角化**。

### 4. 特征值的分布范围（圆盘定理）
- **格施哥林（Gershgorin）圆盘定理**：矩阵 $A$ 的任一特征值必落在复平面上以 $a_{ii}$ 为圆心、以 $r_i = \sum_{j \neq i} |a_{ij}|$ 为半径的圆盘并集内。
- 应用：快速估计特征值范围，或证明矩阵可逆（若所有圆盘不含零点）。

### 5. 特征值的连续性
若矩阵元素连续依赖于参数 $t$，则特征值也连续依赖于 $t$。这一性质在讨论扰动问题时非常关键。

## 七、高频易错点与避坑指南

1. **相似矩阵特征值相同，但特征值相同未必相似**  
   反例：$\begin{pmatrix}1&1\\0&1\end{pmatrix}$ 与 $\begin{pmatrix}1&0\\0&1\end{pmatrix}$。

2. **特征向量不一定随矩阵运算完全不变**  
   只有在多项式 $f(A)$ 及逆矩阵等运算下特征向量才保持不变。转置 $A^T$ 改变特征向量，相似变换 $P^{-1}AP$ 也改变特征向量（变为 $P^{-1}\xi$）。

3. **$|A| = \prod \lambda_i$ 中的连乘必须计入所有代数重数**  
   包括复数根。如果漏掉共轭复根，乘积会出错。

4. **迹与行列式公式对非方阵无意义**  
   非方阵没有特征值定义，迹与行列式的特征值关系自然不适用。

5. **不同特征值的特征向量线性无关，同一特征值的未必**  
   这是对角化的关键。若某一特征值几何重数不足，该特征值的特征向量不足以构成极大线性无关组。

6. **伴随矩阵特征值公式 $|A|/\lambda$ 仅对可逆矩阵成立**  
   当 $\lambda=0$ 时，该式无意义。若 $A$ 不可逆，则 $A^*$ 的秩不超过1，特征值需另行分析。

7. **矩阵多项式特征值代入时，注意定义域**  
   例如 $A^{-1}$ 要求 $A$ 可逆，$\sqrt{A}$ 要求 $A$ 正定等。题目若未明确可逆，不能盲目套用 $\frac{1}{\lambda}$。

## 八、经典题型与例题精讲

### 题型一：利用迹和行列式求参数或特征值
**例题**：设 3 阶矩阵 $A$ 的特征值为 $1, 2, \lambda$，已知 $\operatorname{tr}(A) = 5$，$|A| = -6$，求 $\lambda$。
**解**：
由迹的性质：$1 + 2 + \lambda = 5 \implies \lambda = 2$。
验证行列式：$1 \times 2 \times 2 = 4 \neq -6$，矛盾！
说明题目条件不自治，实际解题中应先利用两个条件之一解出 $\lambda$，再用另一个条件检查是否可能。若两者冲突，可能题目有误或需考虑复数根等其他信息。

### 题型二：求矩阵多项式的特征值与行列式
**例题**：已知 3 阶矩阵 $A$ 的特征值为 $1, -1, 2$，求 $|A^3 - 3A + 2E|$。
**解**：
设 $f(x) = x^3 - 3x + 2$。则 $f(A)$ 的特征值为：
$$f(1) = 1 - 3 + 2 = 0$$
$$f(-1) = -1 + 3 + 2 = 4$$
$$f(2) = 8 - 6 + 2 = 4$$
因此 $|f(A)| = 0 \times 4 \times 4 = 0$。

### 题型三：利用 $AB$ 与 $BA$ 特征值相同解题
**例题**：设 $\alpha = (1, 2, 3)^T$，$\beta = (1, \frac{1}{2}, \frac{1}{3})^T$，令 $A = \alpha \beta^T$，求 $|A + 3E|$。
**解**：
$A$ 为 $3 \times 3$ 矩阵。由性质知 $A = \alpha \beta^T$ 与 $B = \beta^T \alpha$（一个数）具有相同的非零特征值。
计算 $B = 1\times1 + 2\times\frac{1}{2} + 3\times\frac{1}{3} = 1 + 1 + 1 = 3$。
故 $A$ 的非零特征值为 $3$（一重）。又 $r(A)=1$，故另两个特征值为 $0$。
所以 $A$ 的特征值为 $3, 0, 0$。
那么 $A + 3E$ 的特征值为 $6, 3, 3$。
因此 $|A + 3E| = 6 \times 3 \times 3 = 54$。

### 题型四：证明题——不同特征值的特征向量线性无关
**例题**：设 $\lambda_1 \neq \lambda_2$ 是 $A$ 的两个特征值，$\xi_1$ 是 $\lambda_1$ 的特征向量，$\xi_2$ 是 $\lambda_2$ 的特征向量。证明对任意非零常数 $k_1, k_2$，$k_1\xi_1 + k_2\xi_2$ 不再是 $A$ 的特征向量。
**证明**：
假设 $k_1\xi_1 + k_2\xi_2$ 是特征向量，则存在 $\mu$ 使 $A(k_1\xi_1 + k_2\xi_2) = \mu(k_1\xi_1 + k_2\xi_2)$。
左式 $= k_1\lambda_1\xi_1 + k_2\lambda_2\xi_2$。
于是 $k_1(\lambda_1 - \mu)\xi_1 + k_2(\lambda_2 - \mu)\xi_2 = 0$。
因为 $\xi_1, \xi_2$ 线性无关，必有系数为零：$k_1(\lambda_1 - \mu) = 0$ 且 $k_2(\lambda_2 - \mu) = 0$。
因 $k_1, k_2 \neq 0$，得 $\lambda_1 = \mu = \lambda_2$，与假设矛盾。故得证。

## 九、本章知识网络图

- 🎯 **核心目标**：把复杂矩阵运算转化为特征值的数值运算。
  - 🔢 **数量关系**
    - **迹公式**：$\sum\lambda_i=\operatorname{tr}(A)$。
    - **行列式公式**：$\prod\lambda_i=|A|$。
    - **用途**：快速反推参数、检验特征值计算是否正确。
  - 🧮 **运算保持性质**
    - **数乘**：$kA$ 的特征值为 $k\lambda$。
    - **幂运算**：$A^m$ 的特征值为 $\lambda^m$。
    - **矩阵多项式**：$f(A)$ 的特征值为 $f(\lambda)$。
    - **逆矩阵**：$A^{-1}$ 的特征值为 $1/\lambda$。
  - 🔗 **线性无关性**
    - **核心结论**：不同特征值对应的特征向量线性无关。
    - **应用方向**：为矩阵对角化提供特征向量个数保障。
  - 🔁 **相似矩阵性质**
    - **保持不变**：特征多项式、特征值、迹、行列式。
    - **不一定保持**：具体特征向量形式。
  - 🧩 **特殊矩阵**
    - **幂等矩阵**：特征值只能为 $0$ 或 $1$。
    - **对合矩阵**：特征值只能为 $1$ 或 $-1$。
    - **实对称矩阵**：特征值为实数，特征向量可正交化。
## 十、一句话总结

**特征值的性质将复杂的矩阵运算降维为简单的数的运算。牢记迹与行列式的恒等式、多项式保持律以及不同特征值对应特征向量的线性无关性，即可在秒杀选填题的同时，为后续矩阵对角化和二次型标准化打下坚实的理论基础。**
