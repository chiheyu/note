# 📌 考研高数经典积分：有理函数积分的“降维打击”

## 题目
求不定积分：
$$I = \int \frac{1}{x^4(1+x^2)} dx$$

---

## 方法一：分子“无中生有”拆项法（推荐！极速秒杀）

**核心思想**：利用常数 $1 = (1+x^2) - x^2$，巧妙地将分子与分母进行抵消，从而将复杂的乘积形式拆解为简单的加减式。

**推导步骤**：
1. **第一次“无中生有”**：将分子上的 $1$ 替换为 $(1+x^2) - x^2$：
   $$I = \int \frac{(1+x^2) - x^2}{x^4(1+x^2)} dx$$

2. **拆分为两项，约去部分分母**：
   $$I = \int \left( \frac{1+x^2}{x^4(1+x^2)} - \frac{x^2}{x^4(1+x^2)} \right) dx$$
   $$I = \int \left( \frac{1}{x^4} - \frac{1}{x^2(1+x^2)} \right) dx$$

3. **第二次“无中生有”**：对第二项 $\frac{1}{x^2(1+x^2)}$ 再次使用同样的技巧：
   $$\frac{1}{x^2(1+x^2)} = \frac{(1+x^2) - x^2}{x^2(1+x^2)} = \frac{1}{x^2} - \frac{1}{1+x^2}$$

4. **组合回原积分**：将所有拆解后的项放回式子中：
   $$I = \int \left( \frac{1}{x^4} - \frac{1}{x^2} + \frac{1}{1+x^2} \right) dx$$
   $$I = \int x^{-4} dx - \int x^{-2} dx + \int \frac{1}{1+x^2} dx$$

5. **套用基础积分公式得出最终结果**：
   $$I = -\frac{1}{3}x^{-3} - \left(-\frac{1}{x}\right) + \arctan x + C$$
   $$I = -\frac{1}{3x^3} + \frac{1}{x} + \arctan x + C$$

---

## 方法二：三角代换法（万能保底法）

**核心思想**：看到 $1+x^2$ 的结构，形成肌肉记忆，直接利用三角恒等式 $1+\tan^2 t = \sec^2 t$ 进行代换，消除根号或加法结构。

**推导步骤**：
1. **作三角代换**：令 $x = \tan t$，则 $dx = \sec^2 t dt$，且 $1+x^2 = \sec^2 t$。
   $$I = \int \frac{1}{\tan^4 t \cdot \sec^2 t} \cdot \sec^2 t dt$$

2. **约去 $\sec^2 t$，化简为余切函数**：
   $$I = \int \frac{1}{\tan^4 t} dt = \int \cot^4 t dt$$

3. **利用恒等式降次拆分**：利用 $\cot^2 t = \csc^2 t - 1$：
   $$I = \int \cot^2 t (\csc^2 t - 1) dt$$
   $$I = \int \cot^2 t \csc^2 t dt - \int \cot^2 t dt$$

4. **分别计算这两项**：
   * 第一项（凑微分法）：$\int \cot^2 t \csc^2 t dt = -\int \cot^2 t d(\cot t) = -\frac{1}{3}\cot^3 t$
   * 第二项（再用一次恒等式）：$-\int (\csc^2 t - 1) dt = -(-\cot t - t) = \cot t + t$

5. **组合得到关于 $t$ 的积分结果**：
   $$I = -\frac{1}{3}\cot^3 t + \cot t + t + C$$

6. **回代为关于 $x$ 的函数**：因为 $x = \tan t$，所以 $\cot t = \frac{1}{x}$，且 $t = \arctan x$。代入得：
   $$I = -\frac{1}{3}\left(\frac{1}{x}\right)^3 + \frac{1}{x} + \arctan x + C$$
   $$I = -\frac{1}{3x^3} + \frac{1}{x} + \arctan x + C$$

---
> **💡 考场高阶总结：**
> 遇到分母为 $x^n(1+x^2)$ 的有理函数积分时，**优先尝试分子“无中生有”凑项法**（凑出分母因式的差）。这种方法能够完美避开复杂的三角函数降次运算和容易出错的回代过程，是考研实战中节约时间的利器。
