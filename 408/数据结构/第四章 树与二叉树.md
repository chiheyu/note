## 一、树的基本概念与性质

### 1. 树的严格定义

树是由 $n\ (n \ge 0)$ 个结点组成的有限集合。  
* 当 $n=0$ 时称为**空树**。
* 当 $n>0$ 时，有且仅有一个特定的称为**根 (Root)** 的结点；其余结点可分为 $m\ (m>0)$ 个互不相交的有限集 $T_1, T_2, \dots, T_m$，其中每一个集合本身又是一棵树，称为根的**子树 (SubTree)**。

**本质理解与408考点：** 树是一种“一对多”的逻辑层次结构。树作为一种逻辑结构，同时也是一种**分层结构**，具有两个特点：
1. 树的根结点没有前驱，除根结点外的所有结点**有且只有一个前驱**（父结点）。
2. 树中所有结点可以有**零个或多个后继**（子结点）。

### 2. 核心术语辨析（选择题高频）

* **结点的度与树的度：** * 结点的度：一个结点拥有的子树个数（即分支数）。
  * 树的度：树内各结点的度的**最大值**。
* **结点关系：** * 叶子结点（终端结点）：度为 0 的结点。
  * 分支结点（非终端结点）：度不为 0 的结点。
  * 兄弟结点：共享同一个父结点的结点集合。
* **层次、深度与高度：**
  * **层次：** 从根开始定义，根为第 1 层，它的孩子为第 2 层，以此类推。
  * **深度：** 结点的深度是从**根结点自顶向下**逐层累加的。
  * **高度：** 结点的高度是从**叶结点自底向上**逐层累加的。
  * 树的高度（或深度）是树中结点的最大层数。
* **有序树与无序树：** 如果树中结点的各子树从左至右是有次序的，不能互换，称之为有序树，否则为无序树。
* **路径与路径长度：** 树中两个结点之间的路径是由这两个结点之间所经过的结点序列构成的；路径长度是路径上经过的**边的个数**。

### 3. 树的五大常考数学性质（必须熟练计算）

1. **结点数与边数关系：** 树中的结点数等于所有结点的度数之和加 1（即 $n = \sum d_i + 1$）。推论：若树中有 $n$ 个结点，则边数为 $n-1$。
2. **每层结点数上限：** 度为 $m$ 的树中第 $i$ 层上至多有 $m^{i-1}$ 个结点（$i \ge 1$）。
3. **树的结点数上限：** 高度为 $h$ 的 $m$ 叉树至多有 $\frac{m^h-1}{m-1}$ 个结点。
4. **树的高度下限：** 具有 $n$ 个结点的 $m$ 叉树的最小高度为 $\lceil \log_m(n(m-1)+1) \rceil$。
5. 度为 $m$ 的树与 $m$ 叉树的区别：度为 $m$ 的树必须至少有一个度为 $m$ 的结点；而 $m$ 叉树允许所有结点的度都小于 $m$，甚至可以是空树。

## 二、二叉树 (Binary Tree)

### 1. 二叉树定义与特点

二叉树是每个结点**最多**有两棵子树的有序树（即二叉树中不存在度大于 2 的结点）。
二叉树的子树有左右之分，**其次序不能任意颠倒**（即使树中某结点只有一棵子树，也要区分它是左子树还是右子树）。

### 2. 满二叉树与完全二叉树（408重中之重）

* **满二叉树：** 高度为 $h$ 且含有 $2^h-1$ 个结点的二叉树。
  *特点：* 每一层都含有最多的结点；除了叶子结点外，每个结点的度数均为 2；叶子结点全部集中在最底层。
* **完全二叉树：** 高度为 $h$、有 $n$ 个结点的二叉树，当且仅当其每个结点都与高度为 $h$ 的满二叉树中编号为 $1 \sim n$ 的结点一一对应时，称为完全二叉树。
  *特点（判断依据）：*
  1. 叶子结点只可能出现在层次最大的**两层**上。
  2. 若有度为 1 的结点，则**只可能有一个**，且该结点只有左孩子而无右孩子（即不可能存在只有右孩子没有左孩子的情况）。
  3. 按层序编号，一旦某结点 $i$ 没有左孩子或没有右孩子，则它后面的所有结点必然全是叶子结点。

### 3. 二叉树的核心数学性质（大题/选择题计算基础）

1. **任意二叉树结点关系证明：**
   设度为 0, 1, 2 的结点个数分别为 $n_0, n_1, n_2$，总结点数为 $n$。
   由结点总数得出：$n = n_0 + n_1 + n_2$
   由边数得出：$n - 1 = 0 \cdot n_0 + 1 \cdot n_1 + 2 \cdot n_2 = n_1 + 2n_2$
   联立两式消去 $n_1$ 得到：**$n_0 = n_2 + 1$** （叶子结点数总是比度为 2 的结点数多 1）。
2. **完全二叉树的高度：** 具有 $n$ 个结点的完全二叉树的高度为 $\lfloor \log_2 n \rfloor + 1$ 或 $\lceil \log_2 (n+1) \rceil$。
3. **完全二叉树的编号性质（设根为 1，结点范围 $1 \sim n$）：**
   * 若 $i > 1$，则其双亲编号为 $\lfloor i/2 \rfloor$。
   * 若 $2i \le n$，则结点 $i$ 的左孩子编号为 $2i$；否则无左孩子。
   * 若 $2i+1 \le n$，则结点 $i$ 的右孩子编号为 $2i+1$；否则无右孩子。
   * 结点 $i$ 所在的层次为 $\lfloor \log_2 i \rfloor + 1$。
   * 叶子结点的编号起止：$\lfloor n/2 \rfloor + 1 \sim n$。

## 三、二叉树的存储结构

### 1. 顺序存储结构

用一组地址连续的存储单元依次自上而下、自左至右存储完全二叉树上的结点元素。
* **适用场景：** 仅适合**满二叉树**和**完全二叉树**。
* **缺点：** 对于一般的二叉树，为了保持编号的对应关系，需要填充大量空结点，会导致空间的极大浪费（最坏情况下，高度为 $h$ 且只有 $h$ 个结点的单支树需要 $2^h-1$ 个存储单元）。

### 2. 链式存储结构（二叉链表）

采用两个指针域分别指向左、右孩子。
```c
typedef struct BiTNode {
    ElemType data;                      // 数据域
    struct BiTNode *lchild, *rchild;    // 左右孩子指针
} BiTNode, *BiTree;
```
**高频定理（空指针定理）：**在含有$n$个结点的二叉链表中，含有**$n+1$一个空链域**。 （证明：共有$2n$一个指针域，除了根结点外，每个结点都被一条边（指针）指向，共消耗$n-1$个指针，剩余空指针数为$2n - (n-1) = n+1$）。这$n+1$一个空指针是指针二叉树构造的基础。

## 四、二叉树的遍历（核心算法编写）

遍历是指按某条搜索路径访问树中的每个结点，使得每个结点均被访问一次，并且仅被访问一次。

### 1. 深度优先遍历 (DFS - 借助栈/下降)

- **先序遍历 (PreOrder)：**根$\to$左子树$\to$右子树
    
- **中序遍历 (InOrder)：**左子树$\to$根$\to$右子树
    
- **后序遍历 (PostOrder)：**左子树$\to$右子树$\to$根

_代码模板（以中序依次为例）：_
```
void InOrder(BiTree T) {
    if (T != NULL) {
        InOrder(T->lchild); // 递归遍历左子树
        visit(T);           // 访问根结点
        InOrder(T->rchild); // 递归遍历右子树
    }
}
```

_考点提示：_先序、中序、后序遍历的**访问路径是几个的**（只是沿着结点的外围跑一圈），**访问结点的时机不同**（第一路过、第二次路过、第三次路过）。

### 2. 广度优先遍历 (BFS - 层序遍历，借助队列)

思想：从上到下、从左到右依次访问。

1. 将根结点入队。
    
2. 若队列非空，出队一个结点并访问。
    
3. 若该结点有左孩子，将左孩子入队；若有右孩子，将右孩子入队。
    
4. 重复 2, 3 步直到队列为空。

### 3. 二叉树的构造（唯一确定）

- **先序序列 + 中序序列** $\to$可以唯一确定。
    
- **后序序列 + 中序序列** $\to$可以唯一确定。
    
- **层序序列 + 中序序列** $\to$可以唯一确定。
    
- _早上：_先序序列+后序序列**不能**唯一确定一棵二叉树！（只能确定哪些结点是祖先，哪些是子孙，无法确定单个孩子的左右关系）。

## 五、线索二叉树（Threaded Binary Tree）

### 1.为什么要线索化？

普通二叉链表找到某个结点的前驱和后继必须从根开始完整遍历一次，效率低。线索化利用了二叉链表中的$n+1$个空指针，将它们指向当前遍历序列下的**前驱动**或**后继**。

### 2. 引线二叉树的结构

为了区分指针是指向真正的孩子，还是指向线索（前驱/后继），增加两个标志位`ltag`和`rtag`。
```
typedef struct ThreadNode {
    ElemType data;
    struct ThreadNode *lchild, *rchild;
    int ltag, rtag; // 0代表孩子结点，1代表线索
} ThreadNode, *ThreadTree;
```

- `ltag == 0`：`lchild`指向左孩子；`ltag == 1`：`lchild`指向前方指引。
    
- `rtag == 0`：`rchild`指向右孩子；`rtag == 1`：`rchild`指向后面的线索。

### 3.中序线索二叉树的寻找线索规律

- **寻找后续：**
    
    - 若`p->rtag == 1`，则`p->rchild`直接指向其后继。
        
    - 若`p->rtag == 0`，则其后继接着**右子树中最左下角的结点**。
        
- **找前驱：**
    
    - 若`p->ltag == 1`，则`p->lchild`直接指向其前驱。
        
    - 若`p->ltag == 0`，则其前驱旋转**左子树中最右下角的结点**。

## 六、树、森林与二叉树的转换（408极速避坑）

### 1.树/森林转二叉树（口诀：左孩子，右兄弟）

1. **连线：**在所有兄弟结点之间加一条连线。
    
2. **抹线：**对每个结点，除了保留与**长子**（最左边的孩子）的连线外，抹掉与其他所有孩子的连线。
    
3. **旋转：**原树中的长子等于二叉树的左孩子，原树中的右边等于二叉树的右孩子。

### 2.遍历序列的惊人对应关系（必背表格！）

|**树的游览**|**森林的游览**|**二叉树的游览**|
|---|---|---|
|**先根**游览|**先序**遍历|**先序**遍历|
|**后根**游览|**中序**遍历|**中序**遍历|

**408常考陷阱：**树的**后根**遍历应答转换后二叉树的**中序**遍历，千万不要直觉应答生成后序遍历！森林也没有后序遍历，只有先序和中序。

## 七、哈夫曼树与哈夫曼编码（Huffman Tree）

### 1. 核心概念

- **结点的带权路径长度：**从树的根到该结点的路径长度（边数）与该结点上权值的乘积。
    
- **树的带权路径长度（WPL）：**树中所有**叶子结点**的带权路径长度之和：$WPL = \sum_{i=1}^{n} w_i l_i$。
    
- **哈夫曼树（最普通二叉树）：**含有$n$个带权叶子结点的二叉树中，WPL最小的二叉树。

### 2. 哈夫曼树的构造算法

1. 将$n$单个结点作为$n$棵只含一个根结点的二叉树，构成森林$F$。
    
2. 在$F$中选出两棵树根结点权值**最小**的树作为左、右子树构造一棵新的二叉树，新树根结点的权值为左右子树权值之和。
    
3. 在$F$中间删除这两棵树，放入新树加入$F$。
    
4. 重复2和3，直到$F$中轴线一棵树。

### 3. 哈夫曼树重要财产

1. 每个最终终点最终都成为叶终点，权值越小终点到根终点的路径长度越大。
    
2. 中共新建了$n-1$个结点，因此哈夫曼树的结点总数为$2n-1$。
    
3. **哈夫曼树中不存在度为 1 的结点**（即$n_1 = 0$）。

### 4. 哈夫曼编码（稀疏编码）

- **导出编码：**没有一个编码是另一个编码的导出。
    
- 将哈夫曼树的左分支标记为0，右分支标记为1，从根到叶子的分支分支向上即为哈夫曼编码，它必然是最顶层编码，能保证数据压缩率最高且无歧义编码。

## 八、并查集（不相交集）

并查集是一种简单的集合表示，通常用**双亲表示法**的阵列来实现（即阵列中存是父结点的下标，根结点存-1或它的绝对值代表集合元素个数）。

### 1.核心操作

- `Initial(S)`：初始化，将每个备份元素设置为-1。
    
- `Find(S, x)`：查找$x$其中的集合（即一直寻找向上的双亲，直到估计负数的根结点），时间复杂度最坏$O(n)$。
    
- `Union(S, root1, root2)`：将两个不同的集合合并。令其中一个根结点指向另一个根结点。时间复杂度$O(1)$。

### 2.性能优化手段（408大题考点）

- **按排序合并（Union by Rank）：**合并时，总是将结点稀疏（或高度增大）的树作为子树拼接到结点基线（或高度增大）的树上。这样构造的树高不超过$\lfloor \log_2 n \rfloor + 1$。`Find`复杂度降为$O(\log n)$。
    
- **路径压缩（Path Compression）：**在`Find`执行时，顺便将查找路径上的所有结点都直接挂到根结点下面。结合按排序排序，单次查询的平铺时间复杂度接近$O(1)$（严格来说是阿克曼函数的反函数$\alpha(n)$）。

## 九、堆（Heap）——与完全二叉树结合紧密

堆是一棵**完全二叉树**，且满足特定的大小关系。通常使用顺序仓库（下标从 1 开始）。

### 1. 堆的定义

- **大根堆(Max Heap)：**每个结点的值都**大于或等于**其左右孩子的值（即$A[i] \ge A[2i]$且$A[i] \ge A[2i+1]$）。根结点是全局顶部。
    
- **小根堆（Min Heap）：**每个结点的值都**小于或等于**其左右孩子的值。根结点是全局最小的。

### 2. 堆的常见用途

- **堆排序：**空间复杂度$O(1)$，时间复杂度$O(n \log n)$。
    
- **优先队列：**中枢的任务调度。
    
- **Top K 问题：**求海量数据中的前$k$大数（维持一个大小为$k$的小根堆）。

_（注：堆的具体构建堆算法、迭代调整算法将在“排序”章节详细复习，这里只需理解其树形逻辑结构。）_

## 十、经典例题与解题套路推演

### 题目1：完全二叉子结点计算

**题干：**某完全二叉树按遍历编号，已知最后一个结点的编号为100，求其叶子结点个数。 **解答：**完全二叉树中，最后一个结点的父结点为$\lfloor 100/2 \rfloor = 50$。即编号$1 \sim 50$的结点全为分支结点（有孩子）。所以叶子结点是从 51 号开始的，共有$100 - 50 = 50$个。

### 题目2：二叉树性质综合公式法

**题干：**某二叉树有 15 个度为 2 的结点，10 个度为 1 的结点，求该树的总点数。 **答案：**直接使用性质：$n_0 = n_2 + 1 = 15 + 1 = 16$。 累计点数$n = n_0 + n_1 + n_2 = 16 + 10 + 15 = 41$。

## 十一、408高频易错点扫雷（首轮复习警戒线）

1. **混合度为 2 的树与二叉树：**度为 2 的树要求树中必须存在度为 2 的结点（不能是空树或单支树），而二叉树可以是空树，也可以全是度为 1 的结点。且二叉树严格区分左右，普通树不区分。
    
2. **二叉树的非满属性：**二叉树不一定是满的，但叶子一定完全靠完全聚集左。如果遇到编号跳跃（如左孩子空，有右孩子），绝对不是完全但二叉树。
    
3. **遍历唯一性陷阱：**给定先序+后序，**无法**唯一确定二叉树形态。必须有中序参与才能划分左右子树！
    
4. **线索化本质上误区：**线索二叉树是一种**物理结构**（它改变了结点的指针指向和结构体标志），不是逻辑结构。
    
5. **哈夫曼树的左右子树互换：**哈夫曼树并不唯一。对于相同组权值，权值相同时合并顺序不同，或左右子树互换，都会导致不同的树结构，但它们算出来的**WPL一定且最小**。
    
6. **树转换二叉树的形态特征：**任何一棵由森林/树转换而来的二叉树，其**根结点必然没有右孩子**（因为原树根结点没有右兄弟）。
