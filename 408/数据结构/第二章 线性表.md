## 一、线性表的基本概念

### 1. 定义

线性表是由 $n \ge 0$ 个相同类型的有限数据元素组成的序列：

$$L=(a_1,a_2,\dots,a_i,\dots,a_n)$$

* $n$ 为表长，当 $n=0$ 时，称为**空表**。
* $a_1$ 是唯一的“第一个元素”（表头元素）。
* $a_n$ 是唯一的“最后一个元素”（表尾元素）。
* $a_i$ 是第 $i$ 个数据元素，称 $i$ 为数据元素 $a_i$ 在线性表中的**位序**（注意：位序从 1 开始，数组下标从 0 开始）。

### 2. 线性关系（逻辑特性）

在线性表中：

* 存在唯一的表头和表尾元素。
* 除表头元素外，每个元素有且仅有一个**直接前驱**。
* 除表尾元素外，每个元素有且仅有一个**直接后继**。

**本质理解与408考点：** 线性表是一种**逻辑结构**，表示元素之间的一对一相邻关系。它的重点在于元素具有**相同的特性**（占据相同大小的存储空间），并且有**先后次序**。

## 二、顺序表 (Sequential List)

### 1. 顺序表是什么

顺序表是线性表的**顺序存储**实现。  
它在内存中分配一段**地址连续**的存储空间，依次存放线性表中的各个元素。  
**物理相邻 = 逻辑相邻**。

### 2. 结构体定义 (C语言)

408统考中，顺序表分为**静态分配**和**动态分配**两种。

**（1）静态分配（使用定长数组）：**
```c
#define MaxSize 50
typedef struct {
    ElemType data[MaxSize]; // 静态数组存放元素
    int length;             // 当前表长
} SqList;
```
_缺点：_ 空间一旦分配就无法改变，容易溢出或浪费。

**（2）动态分配（使用指针与 `malloc`）：**
```c
#define InitSize 100
typedef struct {
    ElemType *data; // 动态分配数组的基地址
    int MaxSize;    // 当前分配的最大容量
    int length;     // 当前表长
} SeqList;

// 初始化扩容语句示例：
L.data = (ElemType *)malloc(sizeof(ElemType) * InitSize);
```

_考点注意：_ 动态分配虽然叫“动态”，但它的物理空间依然是连续的，本质上还是顺序表，只是借助了堆区的内存机制来实现扩容（扩容时需要重新开辟一片更大的连续空间，并把原数据复制过去，时间复杂度较高）。

### 3. 随机访问特性

如果每个元素占 $l$ 个存储单元，第一个元素地址为 $LOC(a_1)$，则第 $i$ 个元素地址计算公式为：

$$LOC(a_i)=LOC(a_1)+(i-1)l$$

因此，顺序表可以按下标直接访问，查找指定位置元素的**时间复杂度**为：

$$O(1)$$

### 4. 插入操作 (ListInsert)

在第 $i$ ($1 \le i \le length+1$) 个位置插入元素时，需要把第 $i$ 个及其后面的元素依次**从后往前**后移。

- **最好情况：** 插在表尾（$i = length+1$），移动 0 个元素，时间复杂度 $O(1)$。
    
- **最坏情况：** 插在表头（$i = 1$），移动 $n$ 个元素，时间复杂度 $O(n)$。
    
- **平均情况：** 假设在每个位置插入的概率相等 $p_i = \frac{1}{n+1}$，平均移动次数为 $\sum_{i=1}^{n+1} p_i(n-i+1) = \frac{n}{2}$。平均时间复杂度 $O(n)$。

### 5. 删除操作 (ListDelete)

删除第 $i$ ($1 \le i \le length$) 个元素时，需要把后面的元素依次**从前往后**前移。

- **最好情况：** 删表尾（$i = n$），移动 0 个元素，时间复杂度 $O(1)$。
    
- **最坏情况：** 删表头（$i = 1$），移动 $n-1$ 个元素，时间复杂度 $O(n)$。
    
- **平均情况：** 假设删除每个位置元素的概率相等 $p_i = \frac{1}{n}$，平均移动次数为 $\sum_{i=1}^{n} p_i(n-i) = \frac{n-1}{2}$。平均时间复杂度 $O(n)$。

## 三、单链表 (Singly Linked List)

### 1. 单链表结点与结构体定义

链表是线性表的**链式存储**实现，物理上不相邻，逻辑顺序由**指针**维系。
```c
typedef struct LNode {
    ElemType data;       // 数据域
    struct LNode *next;  // 指针域（保存下一个结点的地址）
} LNode, *LinkList;      // LinkList 为指向该结构体的指针类型
```

- **空间特性：** 动态分配，不会浪费空间；但每个结点附加了指针域，**存储密度小于1**。

### 2. 带头结点与不带头结点（408极简辨析）

- **带头结点：** 链表的头指针`L` *指向一个不存真实数据的虚拟结点（头结点）*，**不是首元结点**，`L->next` 才指向第一个真实元素（首元结点）。
    
    - _优点 1：_ 第一个位置的插入和删除操作，与其他位置的处理逻辑一致，无需单独判断。
        
    - _优点 2：_ 无论链表是否为空，头指针 `L` 都不为 `NULL`（空表时 `L->next == NULL`），统一了空表和非空表的处理。
        
- **不带头结点：** `L` 直接指向首元结点。空表时 `L == NULL`。
    
- **考研做题准则：** 默认带头结点。如果大题中没说，可以在答题时加一句“假设链表带头结点”以简化代码。

### 3. 单链表建表（头插法与尾插法）

**（1）头插法 (Head Insert)：**

每次把新结点插在头结点的后面。

- _特性：_ 读入的数据顺序与链表最终生成的顺序**相反**（可用于链表逆置）。
    
- _核心代码：_ `s->next = L->next; L->next = Head; L = s->next;`

**（2）尾插法 (Tail Insert)：**

每次把新结点插在当前链表的表尾。

- _特性：_ 需要维护一个**尾指针 `r`** 始终指向链表的最末尾结点。读入顺序与生成顺序**相同**。
    
- _核心代码：_ `r->next = s; r = s;`（插完后让 r 重新指向新的表尾 s）。

### 4. 单链表查找与按值操作

单链表失去随机存取特性，只能**顺序遍历**。

- **按序号查找 / 按值查找：** 从头开始遍历，时间复杂度均为 $O(n)$。
    
- **求表长：** 必须遍历整个链表（不包括头结点），时间复杂度 $O(n)$。

### 5. 单链表插入与删除的核心技巧

**（1）常规后插操作（在 `p` 之后插入 `s`）：**
```c
s->next = p->next;
p->next = s;       // 顺序绝对不能反！
```
时间复杂度 $O(1)$。

**（2）408神仙操作：指定结点的前插（在 `p` 之前插入 `s`）：**

由于单链表找不到前驱，常规做法是从头遍历找前驱（$O(n)$）。**但有一种 $O(1)$ 的偷梁换柱法**：

1. 将 `s` 插在 `p` 的**后面**：`s->next = p->next; p->next = s;`
    
2. **交换数据域**：`s->data = p->data; p->data = e;`（新数据存入 p，旧 p 的数据挪到 s 里，逻辑上实现了前插）。

**（3）指定结点删除（删除结点 `p` 本身）：**

常规做法找前驱需 $O(n)$。同样可以使用**覆盖法** $O(1)$ 完成（条件：`p` 不是最后一个结点）：
```c
LNode *q = p->next;      // 找到 p 的后继 q
p->data = p->next->data; // 将后继结点的数据覆盖到 p 上
p->next = q->next;       // p 绕过 q 指向 q 的后继
free(q);                 // 释放真实的物理结点 q
```

## 四、双链表、循环链表与静态链表

### 1. 双链表 (Doubly Linked List)

为了克服单链表“找前驱必须从头遍历 ($O(n)$)”的缺点，引入双向指针。
```c
typedef struct DNode {
    ElemType data;
    struct DNode *prior, *next; // 前驱和后继指针
} DNode, *DLinklist;
```

**双链表插入（核心 4 句话）：**

在 `p` 结点之后插入 `s` 结点（注意指针修改顺序，先搞定 s 的两条边）：
```c
s->next = p->next;       // (1)
p->next->prior = s;      // (2) 注意：如果 p 是最后一个结点，这句话会报空指针异常，需加 if(p->next!=NULL) 判断
s->prior = p;            // (3)
p->next = s;             // (4)
```

**双链表删除（核心 2 句话）：**

删除 `p` 的后继结点 `q`：
```c
p->next = q->next;
if (q->next != NULL) {
    q->next->prior = p;
}
free(q);
```

### 2. 循环链表

- **循环单链表：** 尾结点的 `next` 指向头结点 `L`。
    
    - _判空条件：_ `L->next == L`。
        
    - _遍历结束条件：_ `p->next == L`（而不是 `!= NULL`）。
        
    - _使用场景：_ 很多时候循环单链表只设**尾指针 `R`** 不设头指针。这样找尾部元素是 $O(1)$，找头部元素 `R->next->next` 也是 $O(1)$。
        
- **循环双链表：** 头结点的 `prior` 指向表尾结点；表尾结点的 `next` 指向头结点。
    
    - _判空条件：_ `L->next == L && L->prior == L`。

### 3. 静态链表 (Static Linked List)

用**一维数组**借用链表的思想。数组元素包含 `data` 和 `next`（此处 `next` 不是指针，而是游标，即下一个元素的数组下标）。

- 物理连续，逻辑不一定连续。
    
- 插入删除不需要移动元素，只需修改游标。
    
- 必须提前分配好大容量连续空间。
    
- 结束标志：游标设为 `-1`。

## 五、顺序表与链表全面对比考点归纳

|**比较维度**|**顺序表 (SqList)**|**链表 (LinkList)**|
|---|---|---|
|**逻辑结构**|线性结构|线性结构|
|**物理存储**|必须连续|离散散落，按需分配|
|**存储密度**|高 (=1，不存指针)|低 (<1，结点附带指针)|
|**随机访问**|支持，$O(1)$|不支持，必须顺序查 $O(n)$|
|**按值查找**|无序 $O(n)$，有序可用二分 $O(\log n)$|只能 $O(n)$|
|**插入/删除**|需大量移动元素，$O(n)$|只需修改指针，找准位置后 $O(1)$|
|**空间扩容**|静态溢出，动态扩容代价极大|动态分配，从堆区拿，极少溢出|
|**适用场景**|表长稳定，经常按序号查找|频繁插入删除，表长动态变化极大|

## 六、线性表高频算法技巧 (408 大题常客)

### 1. 双指针法（快慢指针）

用于单链表，解决“寻找特定相对位置”问题。

- **寻找链表中间结点：** 快指针 `fast` 每次走两步，慢指针 `slow` 每次走一步。`fast` 到底时，`slow` 正好在中间。
    
- **寻找倒数第 $k$ 个结点：** 让 `fast` 先走 $k$ 步，然后 `fast` 和 `slow` 同时走。当 `fast` 指向 `NULL` 时，`slow` 正好在倒数第 $k$ 个位置。

### 2. 就地逆置法

**空间复杂度必须为 $O(1)$**，不能开辟新数组。

- **单链表逆置（头插法思想）：** 把原链表断开，逐个取下原链表的结点，将其用头插法插入到新链表（原头结点）后面。

### 3. 多路归并法

- **合并两个有序顺序表/链表：** 设置三个指针/下标。依次比较两个表当前的元素，谁小就把谁接在新表的后面。若一个表空了，把另一个表剩下的直接拼接。时间复杂度 $O(m+n)$。

## 七、例题精析：经典单链表逆置

### 题目

将带头结点的单链表 `L` 就地逆置（空间复杂度 $O(1)$）。

### 核心代码与注释

```C
void Reverse(LinkList L) {
    LNode *p = L->next; // p 用来扫描原链表的所有结点
    LNode *r;           // r 用来保存 p 的后继，防断链
    L->next = NULL;     // 第一步：把头结点孤立出来，相当于初始化一个空链表
    
    while (p != NULL) {
        r = p->next;    // 1. 记住 p 的下一个结点，以免后面操作后找不到路
        
        // --- 下面两步是标准的头插法 ---
        p->next = L->next; 
        L->next = p;       
        // -----------------------------
        
        p = r;          // 2. p 指针后移，处理下一个结点
    }
}
```

**做题反思：** 链表题的核心难点是**“防断链”**。只要改变了某个结点的 `next`，一定要提前用一个临时指针 `r` 保存它原本的后继。

## 八、408 高频易错点扫雷

1. **混淆逻辑与物理结构：** 线性表是逻辑概念。遇到选择题选项说“顺序表插入快”，直接打叉。
    
2. **数组越界/空指针异常：** 手写代码时，循环条件经常写错。尤其是 `while(p)` 和 `while(p->next)` 的区别。如果是找前驱操作，通常用 `p->next` 探测。
    
3. **丢失结点：** 插入和删除链表结点时，指针赋值顺序颠倒导致后续链表像风筝断了线一样找不回来。**口诀：先拉住后面的，再放开前面的。**
    
4. **内存泄漏：** 删除了单链表的结点后，光修改指针不够，**必须 `free(p)`**！408阅卷标准中，不写 `free` 会扣 1 分。
    
5. **双链表的非对称性边界：** 双链表插入时，如果在最后一个结点后插入，修改其后继的前驱指针 `p->next->prior = s` 会导致对 `NULL` 取结构体成员，引发段错误。
