## 一、栈 (Stack)

### 1. 栈的定义与基本特性

* **定义：** 栈是只允许在表的一端进行插入和删除的**操作受限**的线性表。
* **特性：** 后进先出 (Last In First Out, LIFO)。
* **基本术语：**
    * **栈顶 (Top)：** 允许进行插入和删除的一端。
    * **栈底 (Bottom)：** 固定的，不允许操作的一端。
* **数学性质（卡特兰数）：** $n$ 个不同元素进栈，出栈序列的合法排列个数为 $\frac{1}{n+1} C_{2n}^{n}$。这是 408 选择题的常考考点。

### 2. 顺序栈 (Sequential Stack)

采用顺序存储结构，利用数组和一个记录栈顶位置的变量来实现。

**（1）常规实现（指针指向当前栈顶元素）：**
```c
#define MaxSize 50
typedef struct {
    ElemType data[MaxSize];
    int top; // 栈顶指针
} SqStack;
```
- **初始化：** `S.top = -1`
    
- **栈空条件：** `S.top == -1`
    
- **栈满条件：** `S.top == MaxSize - 1`
    
- **进栈：** `S.data[++S.top] = x` （先移动指针，再存入数据）
    
- **出栈：** `x = S.data[S.top--]` （先取出数据，再移动指针）

**（2）变体实现（指针指向下一个可插入位置）：**

- **初始化：** `S.top = 0`
    
- **栈空条件：** `S.top == 0`
    
- **进栈：** `S.data[S.top++] = x` （先存入数据，再移动指针）
    
- **出栈：** `x = S.data[--S.top]` （先移动指针，再取出数据）

### 3. 共享栈 (Shared Stack) —— 408 必考高频

利用一维数组空间同时实现两个栈，让两个栈底分别设置在数组的两端，栈顶向中间延伸。

- **结构：** `top0 = -1`（0号栈底），`top1 = MaxSize`（1号栈底）。
    
- **栈满条件：** `top0 + 1 == top1`（两个栈顶指针相邻）。
    
- **优点：** 极大提高空间利用率，只要整个数组不满，就可以继续入栈。

### 4. 链栈 (Linked Stack)

通常使用单链表实现。

- **特点：** 便于多个栈共享存储空间，不存在栈满上溢的情况。
    
- **操作位置：** 规定所有插入和删除操作均在**链表的表头**进行（即头插法和头删法）。
    
- **头结点：** 链栈通常**不带头结点**（直接用头指针充当栈顶指针更方便），若带头结点则在头结点之后操作。时间复杂度均为 O(1)。

## 二、栈的核心应用

### 1. 括号匹配

- **核心算法：** 遇到左括号入栈；遇到右括号，检查栈顶是否为对应的左括号。如果是则弹出栈顶，不是则匹配失败。
    
- **失败的三种情况：**
    
    1. 遇到右括号时，栈已空（右括号单身）。
        
    2. 遇到右括号时，栈顶不是匹配的左括号（类型不匹配）。
        
    3. 表达式扫描完毕时，栈非空（左括号单身）。

### 2. 表达式求值与转换（408 大题/选择题重点）

表达式分为前缀（波兰式）、中缀、后缀（逆波兰式）。

**（1）中缀转后缀（手算方法 - 加括号法）：**

1. 按照运算符优先级对所有的运算单位加括号。
    
2. 将运算符移到对应括号的**后面**。
    
3. 去掉所有括号。

**（2）中缀转后缀（机算方法 - 栈）：**

- **操作数：** 直接输出。
    
- **左括号 `(`：** 直接入栈。
    
- **右括号 `)`：** 依次弹出栈中运算符并输出，直到遇到 `(`，将 `(` 弹出丢弃。
    
- **运算符：** 若栈空或栈顶为 `(` 或优先级**高于**栈顶运算符，直接入栈；否则，依次弹出栈顶优先级**大于等于**当前运算符的运算符并输出，然后将其入栈。

**（3）后缀表达式求值：** 从左往右扫描，遇到操作数压入栈中；遇到运算符，弹出栈顶的**两个**操作数（先弹出的是右操作数，后弹出的是左操作数），计算结果后再压入栈中。

### 3. 递归

- 函数递归调用的底层实现依赖于系统提供的工作栈（隐式栈）。
    
- 每次递归调用时，系统会将**返回地址**、**局部变量**、**实参**压入工作栈。
    
- **空间复杂度：** 递归深度为 n，则空间复杂度通常为 O(n)。过深的递归会导致“栈溢出 (Stack Overflow)”。

## 三、队列 (Queue)

### 1. 队列的定义与基本特性

- **定义：** 只允许在表的一端进行插入（队尾），在另一端进行删除（队头）的线性表。
    
- **特性：** 先进先出 (First In First Out, FIFO)。

### 2. 顺序队列

利用数组实现，设置 `front` 指向队头元素，`rear` 指向队尾元素的下一个位置（也可以指向队尾元素本身，具体看题目设定）。

- **初始化：** `front = rear = 0`
    
- **进队：** `data[rear++] = x`
    
- **出队：** `x = data[front++]`
    
- **致命缺陷：假溢出。** 当 `rear == MaxSize` 时，即使数组前面有空闲位置也无法插入。因此顺序队列必须做成**循环队列**。

### 3. 链式队列

使用带有队头指针和队尾指针的单链表实现。

- **结构：**
```C
typedef struct LinkNode {
    ElemType data;
    struct LinkNode *next;
} LinkNode;
typedef struct {
    LinkNode *front, *rear;
} LinkQueue;
```

- **判空：** `Q.front == Q.rear`（带头结点时）。
    
- **操作：** 出队操作修改 `front->next`，进队操作修改 `rear->next`。若最后一个元素出队，需要重置 `rear = front`。

## 四、循环队列 (Circular Queue)

为了解决假溢出，将顺序队列在逻辑上视为一个环。通过模运算 `%` 实现：`rear = (rear + 1) % MaxSize`。

**408 常考的三种判空/判满方法：**

### 1. 牺牲一个存储单元（最常用）

约定 `rear` 指向队尾元素的下一个位置。

- **初始化：** `front = rear = 0`
    
- **队空：** `front == rear`
    
- **队满：** `(rear + 1) % MaxSize == front`
    
- **队列长度：** `(rear - front + MaxSize) % MaxSize`

### 2. 增设表示元素个数的数据成员 `size`

不牺牲空间，结构体中增加 `int size;`

- **初始化：** `front = rear = 0; size = 0;`
    
- **队空：** `size == 0`
    
- **队满：** `size == MaxSize`
    
- _(判断条件不再依赖 front 和 rear 的相对位置)_

### 3. 增设标记变量 `tag`

不牺牲空间，结构体中增加 `int tag;`。每次进队成功 `tag = 1`，每次出队成功 `tag = 0`。

- **队空：** `front == rear && tag == 0` （因为只有出队才可能导致队空）
    
- **队满：** `front == rear && tag == 1` （因为只有进队才可能导致队满）

## 五、双端队列 (Double-Ended Queue) - 408选择题高频

双端队列是指允许两端都可以进行入队和出队操作的队列。分为两类受限的双端队列：

### 1. 输出受限的双端队列

允许在**两端插入**，但只允许在**一端删除**。 _(常考题型：判断某个输出序列是否合法。技巧：把它当成一个栈，再看多出来的输入端能不能拼凑出目标序列。)_

### 2. 输入受限的双端队列

允许在**一端插入**，但允许在**两端删除**。

## 六、数组与多维数组

数组是线性表的推广。一旦定义，维数和界限不再改变，因此除了初始化和销毁，只有存取和修改操作，不支持动态插入和删除。

### 1. 二维数组按行优先存储

设二维数组 A[M][N]，下标从 0 开始。

LOC(A[i][j])=LOC(A[0][0])+(i×N+j)×L

_解释：元素 A[i][j] 前面有 i 行（每行 N 个元素），在第 i 行里它前面还有 j 个元素。_

### 2. 二维数组按列优先存储

LOC(A[i][j])=LOC(A[0][0])+(j×M+i)×L

_解释：元素 A[i][j] 前面有 j 列（每列 M 个元素），在第 j 列里它前面还有 i 个元素。_

**避坑指南：** 408 中一定要看清题目给的数组下标是从 0 开始还是从 1 开始！如果下标范围是 A[1..m][1..n]，公式会变为 LOC(A[i][j])=LOC+((i−1)×n+(j−1))×L。

## 七、特殊矩阵与稀疏矩阵的压缩存储

压缩存储的原则：多个值相同的元素只分配一个存储空间，零元素不分配空间。 **(重要假设：以下公式默认矩阵元素下标 $a_{i,j}​$从 1 开始，压缩后的一维数组 B[k] 下标从 0 开始。)**

### 1. 对称矩阵

满足 $a_{i,j}​$=$a_{j,i}​$。通常只存下三角区（含主对角线）。

- **元素总数：** n(n+1)​/2
    
- **映射公式 (存下三角, i≥j)：** k=i(i−1)​/2+j−1
    
- *(若访问上三角元素 i<j，因为对称，代入 $a_{j,i​}$ 的下标即可：k=j(j−1)/2​+i−1)*

### 2. 三角矩阵

分为上三角矩阵和下三角矩阵，除了三角区域外，其他区域均为同一个常数 C。 存储方式与对称矩阵类似，只是要在数组的最后多留一个位置存常数 C。数组大小为 n(n+1)/2​+1。

### 3. 三对角矩阵 (带状矩阵)

所有非零元素集中在主对角线及其上下相邻的两条对角线上。即当 ∣i−j∣>1 时，$a_{i,j​}$=0。

- **非零元素总数：** 3n−2 （第一行和最后一行各有 2 个，中间 n−2 行各有 3 个）。
    
- **映射公式：** k=2i+j−3，j=k-2i+3。
    
- **逆向推导公式：** 已知 k，求所在的行标 i=⌊(k+1)/3⌋+1。

### 4. 稀疏矩阵

非零元素个数远小于矩阵元素总数。

- **三元组表：** 将非零元素表示为 `(行号, 列号, 值)` 的形式，依次存放在顺序表中。**失去了随机存取的特性**。
    
- **十字链表法：** 每个非零元素作为一个结点，包含 `row`, `col`, `value`, `right` (指向同行的下一个非零元素), `down` (指向同列的下一个非零元素)。

## 八、408 高频易错点扫雷

1. **栈指针的初值：** `top = -1` 时，先 `++top` 后入栈；`top = 0` 时，先入栈后 `top++`。考试时务必先看清定义！
    
2. **循环队列判空判满：** 默认“牺牲一个单元”法，死记判满公式 `(rear + 1) % MaxSize == front`。若题目明确“引入 size 或 tag 变量”，则不牺牲单元。
    
3. **出栈序列合法性判断：** 选项中通常给一个进栈序列（如 12345），验证出栈序列时，自己画一个栈模拟一下即可。**快速判断法则**：对任意元素，在其之后出栈且比它小的元素，必定是逆序排列的。
    
4. **共享栈的优势：** 共享栈最大的好处是节省存储空间，降低发生上溢的概率，**并没有**降低时间复杂度。
    
5. **矩阵压缩下标偏移：** 是按行优先还是按列优先？矩阵下标从 0 还是从 1 开始？一维数组下标从 0 还是从 1 开始？（这三个条件错一个，公式全错，做题时先在草稿纸上画个 3×3 矩阵推导一下 a2,1​ 验证公式）。

## 九、核心结论清单

- 栈和队列是**受限**的线性表，逻辑结构仍然是**线性结构**。
    
- **合法出栈序列：** 重点掌握卡特兰数公式和规律。
    
- **表达式求值：** 中缀转后缀是必考大题/选择题，注意操作数相对顺序不变，运算符相对顺序改变。
    
- **队列应用：** 层次遍历（树、图）、计算机系统的缓冲区（Spooling）、操作系统进程调度。
    
- **双端队列：** 输入受限与输出受限的合法序列推导。
    
- **特殊矩阵：** 一维数组下标与原矩阵行列坐标的 k=f(i,j) 函数映射关系推导。
