## 一、图的基本概念与核心定理

### 1. 图的严格定义

图 $G$ 由顶点集 $V$ 和边集 $E$ 组成，记为 $G=(V,E)$。
* $V(G)$：顶点集合，**非空**。图不能没有顶点，但可以没有边。
* $E(G)$：边集合，可以为空。
* $|V|$ 表示顶点个数（又称图的阶），$|E|$ 表示边的条数。

### 2. 图的分类与边数极值（408常考计算）

* **无向图与有向图：**
  * 无向图边记为 $(v,w)$。完全无向图：任意两个顶点之间都存在*边*，共 $\frac{n(n-1)}{2}$ 条边。
  * 有向图边记为 $\langle v,w\rangle$。完全有向图：任意两个顶点之间都存在方向相反的*两条边*，共 $n(n-1)$ 条边。
* **简单图与多重图：**
  * 408考研默认讨论**简单图**：*不存在重复边，不存在顶点到自身的边（自环）*。

### 3. 度、入度与出度公式

* **无向图的度 $TD(v)$：**
  * **握手定理（必背）：** 无向图全部顶点的度之和等于边数的 2 倍，即 $\sum TD(v) = 2|E|$。
  * 推论：无向图中度为奇数的顶点个数一定是偶数。
* **有向图的度：**
  * 入度 $ID(v)$(以顶点v为终点的有向边的数量)
  * 出度 $OD(v)$(以顶点v为起点的有向边的数量)
  * 总度 $TD(v) = ID(v) + OD(v)$。
  * **核心等式：** $\sum ID(v) = \sum OD(v) = |E|$。

### 4. 连通性相关概念（极易混淆考点）

* **无向图（连通图与连通分量以及生成树）：**
  * **连通图：** 任意两个顶点都有*路径*存在。
  * **连通分量：** 无向图中的**极大连通子图**（连通子图且包含尽可能多的边）。
  * **极值结论：** 若无向图有 $n$ 个顶点，要保证它一定是连通的，至少需要 $\frac{(n-1)(n-2)}{2} + 1$ 条边（即把 $n-1$ 个点变成完全图，再加一条边连上第 $n$ 个点）。
  * **生成树：** 生成树是一个极小连通子图，它包含原图中的所有 n 个顶点，且为了保持连通且无环，它必须恰好有 n - 1 条边。
* **有向图（强连通图与强连通分量）：**
  * **强连通图：** 任意两个顶点 $v$ 和 $w$，既有 $v \to w$ 的*路径*，也有 $w \to v$ 的*路径*。
  * **强连通分量：** 有向图中的极大强连通子图。
  * **极值结论：** 若有向图有 $n$ 个顶点，要构成强连通图，最少需要 $n$ 条边（构成一个有向环）。
  >在**有向图**中:
	​*强连通（Strongly Connected）*：严格遵守边的方向。图中任意两个顶点 u 和 v 之间，必定既存在从 u 到 v 的有向路径，也存在从 v 到 u 的有向路径。
	​*弱连通（Weakly Connected）*：无视边的方向。只要在底层的无向形态下，图是连通的即可。
### 5.极小连通子图和极大连通子图

- 在图论中，“极小”和“极大”这两个词经常让人混淆，它们分别对应着图论中两个极其重要的概念：**生成树（Spanning Tree）和连通分量（Connected Component）**。
为了让你彻底弄清它们的区别，我们需要明确这里的“极大”和“极小”到底是在限制什么：
#### 5.1 极小连通子图 = 生成树 (Spanning Tree)
 * **“极小”限制的是什么？** 限制的是**边数**。
 * **定义**：它必须包含原图中的**所有 n 个顶点**，并且保持连通。为了达到“极小”，它必须使用尽可能少的边。
 * **结果**：要让 n 个顶点连通，最少需要 **n - 1 条边**。如果再少一条边，图就不连通了；如果多一条边，就会产生环。
 * **结论**：极小连通子图就是生成树。
#### 5.2 极大连通子图 = 连通分量 (Connected Component)
 * **“极大”限制的是什么？** 限制的是**顶点和边**，要求尽可能多地“贪心”包含原图中的部分。
 * **定义**：在无向图中，如果你找到了一个连通的子图，并且你**无法再从原图中加入任何一个新的顶点（及其相连的边）**到这个子图里还能保持连通，那么这个子图就是极大连通子图。
 * **结果**：
   * 如果原图本身就是一个连通图，那么它的极大连通子图只有 1 个，就是**它自己本身**。
   * 如果原图是一个非连通图（比如分成了几个互相独立的小岛），那么每一个独立的连通块都是一个极大连通子图。
 * **结论**：极大连通子图通常被称为连通分量。
### 核心区别总结表
为了方便记忆，你可以参考下表：

| 特性 | 极小连通子图 (生成树) | 极大连通子图 (连通分量) |
| --- | --- | --- |
| **关注点** | 边数最少（刚好够连通） | 范围最大（把能连的都连上） |
| **顶点数量** | **必须包含原图所有顶点** | 包含当前连通块的所有顶点 |
| **边数特征** | 绝对没有环，恰好有 n-1 条边 | 可以有环，包含该连通块内的所有边 |
| **前提条件** | 原图通常必须是连通图 | 原图可以是连通的，也可以是不连通的 |
| **形象比喻** | 修建连接所有城市的**最省钱的高速公路网** | 划分地图上相互独立的**几个国家的领土** |
简单来说：**“极小”是在做减法**（删掉多余的边，破除环路直到不能再删）；**“极大”是在做加法**（把能牵线搭桥的顶点全拉进来，直到不能再加）。

## 二、图的存储结构（物理结构）

### 1. 邻接矩阵 (Adjacency Matrix)

用一个一维数组存顶点，一个二维数组存边。

* **定义式（无权图）：**
  $$A[i][j]=
  \begin{cases}
  1,&(v_i,v_j)\text{ 或 }\langle v_i,v_j\rangle\in E\\
  0,&其他
  \end{cases}$$
* **定义式（带权图 / 网）：**
  $$A[i][j]=
  \begin{cases}
  w_{ij},&\text{若边存在}\\
  0\text{ 或 }\infty,&\text{若 }i=j\text{ 且不允许自环}\\
  \infty,&\text{若边不存在}
  \end{cases}$$
* **核心性质：**
  * **唯一性：** 给定图的顶点编号，邻接矩阵是**唯一**的。
  * **空间复杂度：** $O(|V|^2)$，与边数无关，极度适合稠密图。
  * **无向图：** 矩阵是对称的（可压缩存储）。第 $i$ 行（或列）的非零元素个数就是 $v_i$ 的度。
  * **有向图：** 第 $i$ 行非零元素个数是 $v_i$ 的**出度**；第 $i$ 列非零元素个数是 $v_i$ 的**入度**。
  * **高阶性质（选填）：** 设图的邻接矩阵为 $A$，$A^n$ 的元素 $A^n[i][j]$ 等于从顶点 $i$ 到顶点 $j$ 长度为 $n$ 的路径数目。

### 2. 邻接表 (Adjacency List)

顺序存储与链式存储的结合。为每个顶点建立一个单链表（存边）。

```c
// 边表结点
typedef struct ArcNode {
    int adjvex;              // 该边指向的顶点在数组中的下标
    struct ArcNode *next;    // 指向下一条弧的指针
    int weight;              // 网的边权值
} ArcNode;

// 顶点表结点
typedef struct VNode {
    VertexType data;         // 顶点信息
    ArcNode *first;          // 指向第一条依附该顶点的弧
} VNode, AdjList[MaxVertexNum];
```
- **核心性质：**
    
    - **不唯一性：** 同一个图的邻接表不唯一（取决于边表结点的插入顺序）。
        
    - **空间复杂度：** 无向图 $O(|V|+2|E|)$；有向图 $O(|V|+|E|)$。极度适合稀疏图。
        
    - **度数计算：** 在有向图中，邻接表找**出度**极快，但找**入度**需要遍历全部链表（因此引出“逆邻接表”）。

![](assets/第六章%20图/file-20260526%203.png)

### 3. 逆邻接表 (Inverse Adjacency List)

针对有向图的一种存储结构。其核心逻辑与邻接表完全相反：为每个顶点建立一个单链表，专门用于存储**指向该顶点**的边（即存“入边”）。
```c
// 入边表结点 (与邻接表结构基本一致，但物理含义不同)
typedef struct ArcNode {
    int adjvex;              // 该入边的起点在数组中的下标 (谁指向了我)
    struct ArcNode *next;    // 指向下一条入边的指针
    int weight;              // 网的边权值
} ArcNode;

// 顶点表结点
typedef struct VNode {
    VertexType data;         // 顶点信息
    ArcNode *firstin;        // 指向第一条以该顶点为终点的入边 (注意这里常命名为firstin)
} VNode, InvAdjList[MaxVertexNum];

```
 * **核心性质：**
   * **不唯一性**：同一个图的逆邻接表不唯一（取决于入边结点插入链表的顺序）。
   * **空间复杂度**：与邻接表完全相同，为 O(|V| + |E|)。
   * **度数计算**：完美弥补了邻接表的缺陷。在逆邻接表中，找**入度**极快（只需遍历该顶点的单链表），但找**出度**需要遍历全部链表。
   * **典型应用**：极度适合需要频繁统计顶点入度的算法场景（例如：**拓扑排序**）。

### 4. 十字链表与邻接多重表（只适用于特定图）
为了解决邻接表和逆邻接表的单向局限性，考研/408 体系中引入了这两种专用的链式存储结构。
#### 4.1 十字链表 (Orthogonal List) —— 针对有向图
**核心思想**：将**邻接表**和**逆邻接表**巧妙地整合在一起。每一条有向边（弧）在矩阵中由一个结点表示，每一个顶点也对应一个结点，从而能够同时快速建立出度和入度信息。
```c
// 边表结点（弧结点）
typedef struct ArcNode {
    int tailvex;               // 弧尾在数组中的下标（起点）
    int headvex;               // 弧头在数组中的下标（终点）
    struct ArcNode *hlink;     // 指向弧头相同的下一条弧（入边链表指针）
    struct ArcNode *tlink;     // 指向弧尾相同的下一条弧（出边链表指针）
    int weight;                // 权值
} ArcNode;

// 顶点表结点
typedef struct VNode {
    VertexType data;           // 顶点信息
    ArcNode *firstin;          // 指向第一条以该顶点为终点的弧（入边边表头指针）
    ArcNode *firstout;         // 指向第一条以该顶点为起点的弧（出边边表头指针）
} VNode, GLGraph[MaxVertexNum];

```
 * **核心性质：**
   * **空间复杂度**：$O(|V| + |E|)$。
   * **度数计算**：找**出度**极快（顺着 $firstout \to tlink$ 遍历），找**入度**同样极快（顺着 $firstin \to hlink$ 遍历）。
   * **唯一性**：由于边表结点的插入顺序可以任意，同一个有向图的十字链表结构**不唯一**。

![](assets/第六章%20图/file-20260526%202.png)
#### 4.2 邻接多重表 (Adjacency Multilist) —— 针对无向图
**核心思想**：在用普通的邻接表存储无向图时，一条无向边 ($v_i, v_j$) 必须被迫存储两次（分别挂在 $v_i$ 和 $v_j$ 的单链表下），这给**删除边**或**标记边是否被访问**等操作带来了冗余。邻接多重表实现了**同一条边在整个结构中只出现一个结点**。
```c
// 边表结点
typedef struct EdgeNode {
    int ivex;                  // 边依附的其中一个顶点下标
    struct EdgeNode *ilink;    // 指向下一条依附于顶点ivex的边
    int jvex;                  // 边依附的另一个顶点下标
    struct EdgeNode *jlink;    // 指向下一条依附于顶点jvex的边
    int weight;                // 权值
    int mark;                  // 访问标记位（0表示未访问，1表示已访问）
} EdgeNode;

// 顶点表结点
typedef struct VNode {
    VertexType data;           // 顶点信息
    EdgeNode *firstedge;       // 指向第一条依附于该顶点的边
} VNode, AMLGraph[MaxVertexNum];

```
 * **核心性质：**
   * **空间复杂度**：$O(|V| + |E|)$，相比普通无向图邻接表，边结点数量减少了一半。
   * **边的原子性**：因为一条边只对应一个 EdgeNode，所以在执行删除边、修改边权值、搜索标记（如求最小生成树、每条边只走一次的遍历）时，不需要再去另一个顶点的链表里同步寻找并操作，**极大地简化了边操作的逻辑**。
   * **唯一性**：同一个无向图的邻接多重表结构**不唯一**。

## 三、图的遍历算法

图的遍历难点在于“可能存在环”，必须使用 `visited[]` 数组记录访问状态，防止死循环。

### 1. 深度优先搜索 (DFS - Depth First Search)

类似于树的先根遍历，采用**递归**或**栈**实现。

- **访问过程：** 访问顶点 $v$；置 `visited[v] = true`；从 $v$ 的未被访问的邻接点出发继续递归 DFS。退无可退时回溯。
- **复杂度分析：**
    - **空间：** 需要递归工作栈，最坏为 $O(|V|)$。
    - **时间：** 邻接矩阵为 $O(|V|^2)$；邻接表为 $O(|V|+|E|)$。
- **DFS生成树：** 如果图连通，DFS 会产生一棵生成树；如果图不连通，DFS 会产生生成森林。邻接矩阵的 DFS 树唯一，邻接表的不唯一。

### 2. 广度优先搜索 (BFS - Breadth First Search)

类似于树的层序遍历，采用**队列**实现。

- **访问过程：** 访问 $v$ 并入队；只要队列不空，队首顶点出队，将其所有未访问的邻接点访问并入队。
- **复杂度分析：**
    - **空间：** 需要辅助队列，最坏（如星形图）为 $O(|V|)$。
    - **时间：** 与 DFS 完全相同。
- **核心应用（无权图单源最短路径）：** 利用 BFS 可求无权图（或所有边权值相等的图）中顶点 $u$ 到其他所有顶点的最短路径。距离 $d[w] = d[v] + 1$。

## 四、最小生成树 (MST - Minimum Spanning Tree)

一个连通图的生成树包含图中所有顶点和 $n-1$ 条边。

**最小生成树：** 各边权值之和最小的生成树。

- **MST 的唯一性考点：**
    1. MST 的权值之和总是**唯一且最小**的。
    2. 若图中各边权值互不相等，则 MST 是**唯一**的。
    3. 若图中有权值相等的边，MST 可能不唯一。

### 1. Prim（普里姆）算法

- **思想（加点法）：** 从某一个顶点开始，每次在连接已加入集合 $U$ 的点和未加入集合 $V-U$ 的点之间的边中，挑选一条**权值最小**的边，将其顶点加入 $U$。
- **数据结构：** 需要维护一个 `minDist[]` 数组。
- **时间复杂度：** $O(|V|^2)$。与边数无关，**适合稠密图**。

### 2. Kruskal（克鲁斯卡尔）算法

- **思想（加边法）：** 将所有边按权值从小到大排序。按次序挑边，若选中的边不会在已选的边中构成**回路**，则将其加入 MST；否则舍弃。
- **数据结构：** 使用**并查集 (Disjoint Set)** 来检测是否生成回路。
- **时间复杂度：** $O(|E|\log|E|)$。受边数影响大，**适合稀疏图**。

## 五、最短路径算法

### 1. Dijkstra（迪杰斯特拉）算法 —— 单源最短路径

- **思想（贪心法）：** 将顶点分为已确定最短路径的集合 $S$ 和未确定集合 $V-S$。每次从 $V-S$ 中选出距离源点最近的顶点加入 $S$，并以它为中转点，**松弛（更新）** 其他未确定顶点的距离。
- **状态转移方程：**
    $$dist[j] = \min(dist[j], dist[i] + matrix[i][j])$$
- **前提条件：** 图中**绝对不能包含负权值的边**，否则贪心策略失效。
- **时间复杂度：** 不使用堆优化时为 $O(|V|^2)$。

### 2. Floyd（弗洛伊德）算法 —— 任意两点间最短路径

- **思想（动态规划法）：** 允许图中有负权边，但**不能有包含负权边的环**。
    定义 $A^{(k)}[i][j]$ 为从顶点 $i$ 到 $j$、中间只经过编号不大于 $k$ 的顶点的最短路径长度。
- **状态转移方程：**
    $$A^{(k)}[i][j] = \min(A^{(k-1)}[i][j], A^{(k-1)}[i][k] + A^{(k-1)}[k][j])$$
- **时间复杂度：** 嵌套了三层循环，严格的 $O(|V|^3)$。
- **空间复杂度：** $O(|V|^2)$（通常滚动数组优化掉一维）。

## 六、有向无环图 (DAG) 与拓扑排序

**DAG (Directed Acyclic Graph)：** 没有环的有向图。常用于表示工程或系统的先后制约关系。

### 1. AOV 网 (Activity On Vertex Network)

用**顶点**表示活动，用**有向边**表示活动之间的先后必然关系。

### 2. 拓扑排序 (Topological Sort)

将 DAG 的所有顶点排列成一个线性序列，使得图中任意一对顶点 $u$ 和 $v$，若边 $\langle u,v\rangle$ 存在，则 $u$ 在序列中必定出现在 $v$ 之前。

- **操作过程：**
    1. 找一个**入度为 0** 的顶点，输出它。
    2. 从网中删除该顶点及所有以它为起点的出边（即它所指向的顶点的入度减 1）。
    3. 重复 1、2。

- **核心结论：**
    - 若网中有环，则拓扑排序必定中断（剩余顶点入度均不为 0）。因此拓扑排序可用于**检测有向图是否有环**。
    - 拓扑排序序列通常**不唯一**。
    - 时间复杂度：$O(|V|+|E|)$。

- **逆拓扑排序：** 每次找**出度为 0** 的顶点删除。可用 DFS 算法实现（在 DFS 递归调用退出前输出该顶点，最后结果逆序）。

## 七、关键路径 (Critical Path)

### 1. AOE 网 (Activity On Edge Network)

带权有向无环图，**边**表示活动，**边上的权值**表示活动持续时间，**顶点**表示事件（标志某些活动的完成或开始）。

- **源点（起点）：** 入度为 0 的唯一顶点。
- **汇点（终点）：** 出度为 0 的唯一顶点。

### 2. 四个核心时间参数（大题计算必考）

1. **事件最早发生时间 $ve(k)$：** 从源点到顶点 $k$ 的**最长路径**长度。递推公式（按拓扑序列）：
    $$ve(j) = \max\{ve(i) + weight(i, j)\}$$

2. **事件最迟发生时间 $vl(k)$：** 在不推迟整个工期的前提下，事件 $k$ 允许的最晚发生时间。递推公式（按逆拓扑序列）：
    $$vl(i) = \min\{vl(j) - weight(i, j)\}$$

3. **活动最早开始时间 $e(i)$：** 
* 该活动所在**边起点的事件**最早发生时间。
* *大白话*：一个任务最早什么时候能开工？这完全取决于它的“前置条件”最早什么时候能弄完。
* 最早开始时间是从起点往后看：前置条件一搞定，我马上就干。
* 若活动 $a_i$ 对应边 $\langle j,k\rangle$，则 $e(i) = ve(j)$。

4. **活动最迟开始时间 $l(i)$：** 
* 该活动所在**边终点的事件**最迟发生时间，减去活动持续时间。
* *大白话*：一个任务最晚什么时候必须开工（且不拖累总进度）？这取决于它的“交付死线”，再往前倒推这个任务本身的耗时。
* ​最迟开始时间是从终点往前倒推：看着最后期限，扣除我要花的时间，这就是我摸鱼的底线。
* $l(i) = vl(k) - weight(j, k)$。

### 3. 关键活动与关键路径

- **时间余量 $d(i)$：** $d(i) = l(i) - e(i)$。表示活动可以拖延的时间。
- **关键活动：** $d(i) = 0$ 的活动。
- **关键路径：** 由关键活动组成的从源点到汇点的路径。关键路径上的全长即为工程的最短完成时间。
- **高频易错结论：**
    - 关键路径可能有多条。
    - 缩短某一关键活动的时间，**可能**会使关键路径变短；但如果缩短得太多，该关键活动可能变成非关键活动，关键路径会发生转移。
    - 只有当某活动属于**所有**关键路径时，缩短它才能必然缩短总工期。

## 八、408 高频易错点扫雷（首轮警戒线）

1. **图的遍历唯一性：** 给定图的**逻辑结构**，DFS/BFS 序列不唯一；给定图的**物理结构**（如邻接表或邻接矩阵），DFS/BFS 序列唯一。
2. **极大与极小：**
    - 连通分量是**极大**连通子图（必须包含连通部分的所有顶点和全部相关的边）。
    - 生成树是**极小**连通子图（包含所有顶点，但边数最少，只有 $n-1$ 条）。
3. **连通分量的数量与 DFS：** 对无向图调用 DFS 或 BFS 过程的次数，恰好等于该图连通分量的个数。
4. **MST 考法陷阱：** Prim 算法在树的扩展过程中，始终保持连通性；Kruskal 算法在合并过程中，中间状态可能由多个不连通的树（森林）组成。
5. **Dijkstra 无法处理负权：** 选择题若问哪个算法不能处理负权图，无脑选 Dijkstra。
6. **图论四大应用的时间复杂度对比（必背）：**
    - BFS / DFS / 拓扑排序：$O(|V|+|E|)$ （采用邻接表）
    - Prim / Dijkstra：$O(|V|^2)$
    - Kruskal：$O(|E|\log|E|)$
    - Floyd：$O(|V|^3)$
