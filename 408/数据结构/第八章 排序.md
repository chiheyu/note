## 一、排序的基本概念

### 1. 排序的定义
排序就是重新排列表中的元素，使表中的元素按关键字递增或递减的过程。

### 2. 算法的稳定性（核心考点）
* **定义：** 假设表中存在两个关键字相同的元素 $R_i$ 和 $R_j$，且在排序前 $R_i$ 在 $R_j$ 的前面。如果排序后 $R_i$ 依然在 $R_j$ 的前面，则称该排序算法是**稳定**的；否则是**不稳定**的。
* **本质理解：** 稳定性只讨论“关键字相等”的元素。对于单关键字排序，稳定性无所谓；但对于**多关键字排序**（例如先按总分降序，总分相同按数学成绩降序），稳定性至关重要。

### 3. 内部排序与外部排序
* **内部排序：** 排序期间元素全部存放在**内存**中进行。408 重点考察。
* **外部排序：** 数据量太大，内存无法一次性装入，排序期间需要不断在内、外存之间移动数据。主要涉及**多路归并**。

## 二、插入类排序

核心思想：每次将一个待排序的元素，按其关键字大小插入到前面已经排好序的子序列中。

### 1. 直接插入排序 (Straight Insertion Sort)
* **过程：** 第 $i$ 趟将第 $i$ 个元素插入到前面 $i-1$ 个已排序的元素中。
* **时间复杂度：** 
  * 最好情况（原本就有序）：只需比较 $n-1$ 次，不移动，**$O(n)$**。
  * 最坏情况（逆序）：**$O(n^2)$**。
  * 平均情况：**$O(n^2)$**。
* **空间复杂度：** 需要一个辅助变量做哨兵或暂存，**$O(1)$**。
* **稳定性：** **稳定**。
* **适用性：** 适用于顺序存储和链式存储的线性表。
* **408考点：** 直接插入排序每一趟**不能**保证一个元素到达最终位置。
* **适用性：** 适用于顺序存储和链式存储的线性表。
```C
void insertSort(int arr[], int n) {
    for (int i = 1; i < n; i++) {
        int temp = arr[i]; // 暂存待插入的元素
        int j = i - 1;
        // 从后往前查找插入位置，边找边向后移动元素
        while (j >= 0 && arr[j] > temp) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = temp; // 插入到正确位置
    }
}

```

### 2. 折半插入排序 (Binary Insertion Sort)
* **过程：** 在“找插入位置”这一步，利用折半查找法代替顺序查找。
* **性能分析：** 
  * 仅仅是减少了**比较次数**，比较次数约为 $O(n \log n)$。
  * 但是**并没有减少移动次数**，元素的移动次数依然是 $O(n^2)$。
* **时间复杂度：** 依然为 **$O(n^2)$**。
* **稳定性：** **稳定**。
* **适用性：** 仅适用于顺序存储的线性表。
```C
void binaryInsertSort(int arr[], int n) {
    for (int i = 1; i < n; i++) {
        int temp = arr[i];
        int low = 0, high = i - 1;
        // 折半查找插入位置
        while (low <= high) {
            int mid = low + (high - low) / 2;
            if (arr[mid] > temp) {
                high = mid - 1;
            } else {
                low = mid + 1;
            }
        }
        // 统一后移元素
        for (int j = i - 1; j >= low; j--) {
            arr[j + 1] = arr[j];
        }
        arr[low] = temp; // 插入元素
    }
}
```

### 3. 希尔排序 (Shell Sort / 缩小增量排序)
* **过程：** 先追求表中元素部分有序，再逐渐逼近全局有序。选取一个步长增量 $d$，将相距 $d$ 的元素分为一组，在组内进行直接插入排序；然后缩小 $d$，重复上述过程，直到 **$d=1$**（最后一趟就是一次完整的直接插入排序）。
* **时间复杂度：** 依赖于增量序列的选择。最坏情况下为 $O(n^2)$，在某个特定范围内约为 $O(n^{1.3})$。
* **空间复杂度：** **$O(1)$**。
* **稳定性：** **不稳定**（相同的元素被分到不同组时，相对位置可能改变）。
* **适用性：** 仅适用于顺序存储的线性表。
```C
void shellSort(int arr[], int n) {
    // 增量每次减半
    for (int d = n / 2; d > 0; d /= 2) {
        // 对各个分组进行直接插入排序
        for (int i = d; i < n; i++) {
            int temp = arr[i];
            int j = i - d;
            while (j >= 0 && arr[j] > temp) {
                arr[j + d] = arr[j];
                j -= d;
            }
            arr[j + d] = temp;
        }
    }
}
```

## 三、交换类排序

核心思想：根据序列中两个元素关键字的比较结果，交换这两个元素。

### 1. 冒泡排序 (Bubble Sort)
* **过程：** 从后往前（或从前往后）两两比较相邻元素的值，若为逆序则交换。一趟冒泡会把一个最小（或最大）的元素“浮”到序列的最终位置。
* **优化（必考）：** 增加一个标志位 `flag`。如果在某一趟冒泡中**没有发生任何交换**，说明序列已经全局有序，直接提前结束算法。
* **时间复杂度：** 
  * 最好情况（有序）：第 1 趟比较后未交换，直接退出，**$O(n)$**。
  * 最坏情况（逆序）：**$O(n^2)$**。
  * 平均情况：**$O(n^2)$**。
* **空间复杂度：** **$O(1)$**。
* **稳定性：** **稳定**。
* **408考点：** 冒泡排序每趟产生的有序子序列一定是全局最小/大的；且其排序趟数**与初始状态有关**。
* **适用性：** 适用于顺序存储和链式存储的线性表。
```C
void bubbleSort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        bool flag = false; // 必考的优化标志位
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                // 交换元素
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
                flag = true; // 发生了交换
            }
        }
        if (!flag) {
            break; // 本趟未发生交换，直接退出
        }
    }
}
```

### 2. 快速排序 (Quick Sort) - 408 最重要算法
* **过程（分治法）：** 在待排序表任取一个元素作为枢轴 `pivot`（通常取首元素）。通过一趟排序将表划分为独立的两部分：左边所有元素 $< pivot$，右边所有元素 $\ge pivot$。此时 $pivot$ 放到了它的**最终位置**。然后对左右子表递归执行该过程。
* **时间复杂度：** 
  * 最好情况（每次划分都很均匀）：**$O(n \log n)$**。
  * 最坏情况（表原本就有序或逆序）：退化为单链表，每次划分只分出一个元素，**$O(n^2)$**。
  * 平均情况：**$O(n \log n)$**。==快排是所有内部排序中平均性能最优的。==
* **空间复杂度（递归栈）：** 
  * 最好/平均：**$O(\log n)$**。
  * 最坏：**$O(n)$**。
* **稳定性：** **不稳定**。
* **408考点：** 
  1. 快排的趟数（递归深度）**与初始状态有关**。
  2. 每一趟必然能确定**至少一个**（即枢轴）元素的最终位置。
* **适用性：** 仅适用于顺序存储的线性表。
```C
// 划分函数
int partition(int arr[], int low, int high) {
    int pivot = arr[low]; // 通常取首元素作为枢轴
    while (low < high) {
        while (low < high && arr[high] >= pivot) high--;
        arr[low] = arr[high]; // 将比枢轴小的元素移到左端
        while (low < high && arr[low] <= pivot) low++;
        arr[high] = arr[low]; // 将比枢轴大的元素移到右端
    }
    arr[low] = pivot; // 枢轴到达最终位置
    return low;
}

// 快排主函数
void quickSort(int arr[], int low, int high) {
    if (low < high) {
        int pivotPos = partition(arr, low, high);
        quickSort(arr, low, pivotPos - 1); // 递归处理左子表
        quickSort(arr, pivotPos + 1, high); // 递归处理右子表
    }
}
```

## 四、选择类排序

核心思想：每一趟在后面 $n-i$ 个待排序元素中选取关键字最小（或最大）的元素，作为有序子序列的第 $i$ 个元素。

### 1. 简单选择排序 (Simple Selection Sort)
* **过程：** 每趟直接扫描未排序部分，挑出最小的元素，和未排序部分的第一个元素交换。
* **时间复杂度：** 无论初始状态如何，第 $i$ 趟总是需要比较 $n-i$ 次。总比较次数恒为 $n(n-1)/2$。所以最好、最坏、平均时间复杂度均为 **$O(n^2)$**。
* **空间复杂度：** **$O(1)$**。
* **稳定性：** **不稳定**（易错点：比如数组 `[2, 2, 1]`，第一趟 1 会和第一个 2 交换，导致两个 2 的相对位置发生改变）。
* **适用性：** 仅适用于顺序存储和链式存储的线性表，尤其适合关键字较少的情况。
```C
void selectSort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int minIdx = i; // 记录最小元素的索引
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIdx]) {
                minIdx = j;
            }
        }
        // 如果最小元素不是当前的第 i 个元素，则交换
        if (minIdx != i) {
            int temp = arr[i];
            arr[i] = arr[minIdx];
            arr[minIdx] = temp;
        }
    }
}
```

### 2. 堆排序 (Heap Sort)
将一维数组视为一棵**完全二叉树**，常用于解决$Top-K$问题。
* **建堆操作（重点）：**
  从最后一个**非叶子结点**（即 $\lfloor n/2 \rfloor$）开始，从后往前，依次进行“向下调整 (SiftDown)”。
  *结论：* 建堆的时间复杂度与树高成正比，为 **$O(n)$**。
* **排序过程：** （升序排序使用**大根堆**）输出堆顶元素（将其与堆底元素交换），然后将剩余的 $n-1$ 个元素重新向下调整为大根堆，重复执行。
* **时间复杂度：** 建堆 $O(n)$ + 排序 $O(n \log n)$ = 总时间复杂度恒为 **$O(n \log n)$**。
* **空间复杂度：** 原地排序，**$O(1)$**。
* **稳定性：** **不稳定**。
* **插入与删除：** 
  * 插入：放到数组末尾，进行**向上调整**。
  * 删除：用数组末尾元素顶替堆顶，进行**向下调整**。
* **适用性：** 仅适用于顺序存储的线性表。
```C
// 向下调整函数 (建立大根堆)
void siftDown(int arr[], int k, int n) {
    int temp = arr[k];
    // i 初始为左孩子结点下标 (注意这里是0-indexed的数组)
    for (int i = 2 * k + 1; i < n; i = 2 * i + 1) {
        if (i + 1 < n && arr[i] < arr[i + 1]) {
            i++; // 选取较大的子结点
        }
        if (temp >= arr[i]) {
            break; // 调整结束
        } else {
            arr[k] = arr[i]; // 将较大的子结点向上移动
            k = i;
        }
    }
    arr[k] = temp;
}

// 堆排序主函数
void heapSort(int arr[], int n) {
    // 1. 从最后一个非叶子结点开始建堆
    for (int i = n / 2 - 1; i >= 0; i--) {
        siftDown(arr, i, n);
    }
    // 2. 排序过程：交换堆顶与堆底元素，然后调整堆
    for (int i = n - 1; i > 0; i--) {
        int temp = arr[0];
        arr[0] = arr[i];
        arr[i] = temp;
        siftDown(arr, 0, i); // 将剩余的 i 个元素重新调整为大根堆
    }
}
```

## 五、归并排序 (Merge Sort)

### 1. 基本思想（分治法）
将两个或两个以上的有序表组合成一个新的有序表。408 默认考察**二路归并**。
* **过程：** 将 $n$ 个元素看成 $n$ 个长度为 1 的有序子表；两两归并，得到 $\lceil n/2 \rceil$ 个长度为 2 的子表；重复直到合成一个长度为 $n$ 的有序表。
* **归并趟数：** $\lceil \log_2 n \rceil$ 趟。每一趟的时间复杂度为 $O(n)$。

### 2. 性能分析
* **时间复杂度：** 无论初始状态如何，总是 **$O(n \log n)$**。
* **空间复杂度：** 需要一个与原数组等大的辅助数组用来执行 `Merge` 操作，所以是 **$O(n)$**。
* **稳定性：** 每次比较时，若遇到相等元素，优先把左边子表的元素放入新表，所以是**稳定**的。
* **适用性：** 适用于顺序存储和链式存储的线性表，链式结构尤其适合。
```C
// 将两个有序子序列合并为一个有序序列
void merge(int arr[], int tempArr[], int left, int mid, int right) {
    int i = left;      // 左子表起点
    int j = mid + 1;   // 右子表起点
    int k = left;      // 辅助数组的写入指针

    // 两两比较，小的优先放入辅助数组 (保证稳定性)
    while (i <= mid && j <= right) {
        if (arr[i] <= arr[j]) {
            tempArr[k++] = arr[i++];
        } else {
            tempArr[k++] = arr[j++];
        }
    }
    // 处理剩余元素
    while (i <= mid) tempArr[k++] = arr[i++];
    while (j <= right) tempArr[k++] = arr[j++];
    // 将辅助数组的内容拷贝回原数组
    for (int p = left; p <= right; p++) {
        arr[p] = tempArr[p];
    }
}

// 归并排序主函数 (递归分治)
void mergeSort(int arr[], int tempArr[], int left, int right) {
    if (left < right) {
        int mid = left + (right - left) / 2;
        mergeSort(arr, tempArr, left, mid);      // 划分左半部分
        mergeSort(arr, tempArr, mid + 1, right); // 划分右半部分
        merge(arr, tempArr, left, mid, right);   // 合并
    }
}
```

## 六、基数排序 (Radix Sort)

基数排序是**非比较型**排序算法，借助“分配”和“收集”两种操作对单逻辑关键字进行排序。

### 1. 核心思想
假设每个元素的关键字由 $d$ 位组成（例如百位、十位、个位，此时 $d=3$），每位有 $r$ 种可能（例如十进制数字，有 0-9，此时 $r=10$）。
* **最低位优先 (LSD)：** 从个位开始，先按个位分配到 10 个队列（桶）中，再收集；然后按十位分配、收集；最后按百位分配、收集。

### 2. 性能分析
* **时间复杂度：** 需要进行 $d$ 趟分配和收集。一趟分配需要 $O(n)$，一趟收集需要 $O(r)$。总时间复杂度为 **$O(d(n+r))$**。与初始序列状态无关。
* **空间复杂度：** 需要 $r$ 个队列指针（队头和队尾），**$O(r)$**。
* **稳定性：** 每次分配收集都是按顺序进行的，**稳定**。
* **适用性：** 适用于顺序存储和链式存储的线性表。
```C
#include <stdio.h>
#include <stdlib.h>

// 辅助函数：找出数组中的最大值，用于确定循环的趟数（即最大位数 d）
int getMax(int arr[], int n) {
    int maxVal = arr[0];
    for (int i = 1; i < n; i++) {
        if (arr[i] > maxVal) {
            maxVal = arr[i];
        }
    }
    return maxVal;
}

// 基数排序 (LSD)主函数
void radixSort(int arr[], int n) {
    if (n <= 1) return;

    // 找出最大值以确定最高位数
    int maxVal = getMax(arr, n);

    // 动态申请辅助数组，用于在“收集”阶段暂存排好序的数据
    // 空间复杂度 O(n) 用于临时存储，另外 count 数组的空间是 O(r)
    int *output = (int *)malloc(n * sizeof(int));
    if (output == NULL) {
        return; // 内存分配失败处理
    }

    // exp 表示当前处理的位 (1(个位), 10(十位), 100(百位)...)
    for (int exp = 1; maxVal / exp > 0; exp *= 10) {
        // r个队列(桶)，因为是十进制数字，所以 r=10，初始化为0
        int count[10] = {0}; 

        // 1. 分配：统计各个桶中的元素个数
        for (int i = 0; i < n; i++) {
            int digit = (arr[i] / exp) % 10;
            count[digit]++;
        }

        // 累加计算前缀和，这一步用来确定每个元素在 output 数组中的实际位置
        for (int i = 1; i < 10; i++) {
            count[i] += count[i - 1];
        }

        // 2. 收集：从后往前遍历原数组放入 output，以保证排序的【稳定性】
        for (int i = n - 1; i >= 0; i--) {
            int digit = (arr[i] / exp) % 10;
            // count[digit] - 1 就是该元素放入 output 的确切下标
            output[count[digit] - 1] = arr[i];
            count[digit]--;
        }

        // 将本趟收集好的数据拷贝回原数组
        for (int i = 0; i < n; i++) {
            arr[i] = output[i];
        }
    }

    // 释放动态分配的内存，防止内存泄漏
    free(output);
}
```

## 七、外部排序（选学核心）

数据量极大，必须在内存和外存之间进行倒腾。核心思想是**多路归并排序**。

### 1. 核心步骤
1. **生成归并段：** 根据内存大小，每次读入一块数据，在内存中进行内部排序，然后写回外存，形成若干个初始归并段。
2. **多路归并：** 对这些初始归并段进行 $k$ 路归并，直到合成一个大归并段。

### 2. 考点突破
* **影响外部排序时间的因素：** 主要是**外存读写（I/O）次数**。
* **败者树 (Loser Tree)：** 用于在 $k$ 路归并时，快速从 $k$ 个元素中选出最小者。它可以使选出最小元素的比较次数与 $k$ 无关（仅与树高 $\log_2 k$ 有关）。
* **置换-选择排序：** 用于生成更长的初始归并段，减少初始归并段的个数，从而减少 I/O 次数。
* **最佳归并树：** 若初始归并段长度不同，如何安排归并顺序使得总 I/O 次数最少？转化为**哈夫曼树 (Huffman Tree)** 的构造问题（权值就是归并段的长度）。如果归并段数量不满足严格 $k$ 叉树的要求，需要补充长度为 0 的虚段。

| **希尔排序** | - | $O(n^2)$ | - | $O(1)$ | 不稳定 | 无关 |
| **快速排序** | $O(n \log n)$| $O(n^2)$ | $O(n \log n)$| $O(\log n)$ | 不稳定 | **有关** |
| **堆排序** | $O(n \log n)$| $O(n \log n)$| $O(n \log n)$| $O(1)$ | 不稳定 | 无关 |
| **归并排序** | $O(n \log n)$| $O(n \log n)$| $O(n \log n)$| **$O(n)$** | 稳定 | 无关 |
| **基数排序** | $O(d(n+r))$ | $O(d(n+r))$ | $O(d(n+r))$ | $O(r)$ | 稳定 | 无关 |

### 2. 必背结论清单
* **时间复杂度与初始状态的关系：** 
  * 时间复杂度与初始状态**无关**的：简单选择、归并、堆、基数。
  * 时间复杂度与初始状态**有关**的：直接插入、冒泡、快速。
* **每趟能确定一个最终位置的算法：** 冒泡、快速、简单选择、堆排序。（这四个算法执行 $k$ 趟后，必有 $k$ 个元素就位。考研常通过“写出前三趟的结果”来反推使用了什么算法）。
* **比较次数的考点：**
  * **简单选择排序**的比较次数恒为 $n(n-1)/2$，与初始状态无关。
  * **直接插入排序**的比较次数与初始状态密切相关（最好 $n-1$，最坏 $n(n-1)/2$）。
* **元素移动次数的考点：**
  * 若初始序列正序（最好），直接插入排序和冒泡排序的元素移动次数均为 **0**。
* **适用场景选型：**
  * 若 $n$ 较小，且要求稳定：**直接插入**。
  * 若 $n$ 较小，不要求稳定：**简单选择**。
  * 若 $n$ 极大，内存够，不要求稳定：**快速排序**（最常用）。
  * 若 $n$ 极大，内存紧缺，不要求稳定：**堆排序**（空间仅 $O(1)$）。
  * 若 $n$ 极大，且要求稳定：**归并排序**。
  * 若 $n$ 极大，但关键字范围小且位数少：**基数排序**。
