## 一、图的基本概念与核心定理

### 1. 图的严格定义

图 $G$ 由顶点集 $V$ 和边集 $E$ 组成，记为 $G=(V,E)$。
* $V(G)$：顶点集合，**非空**。图不能没有顶点，但可以没有边。
* $E(G)$：边集合，可以为空。
* $|V|$ 表示顶点个数（又称图的阶），$|E|$ 表示边的条数。

### 2. 图的分类与边数极值（408常考计算）

* **无向图与有向图：**
  * 无向图边记为 $(v,w)$。完全无向图：任意两个顶点之间都存在边，共 $\frac{n(n-1)}{2}$ 条边。
  * 有向图边记为 $\langle v,w\rangle$。完全有向图：任意两个顶点之间都存在方向相反的两条边，共 $n(n-1)$ 条边。
* **简单图与多重图：**
  * 408考研默认讨论**简单图**：不存在重复边，不存在顶点到自身的边（自环）。

### 3. 度、入度与出度公式

* **无向图的度 $TD(v)$：**
  * **握手定理（必背）：** 无向图全部顶点的度之和等于边数的 2 倍，即 $\sum TD(v) = 2|E|$。
  * 推论：无向图中度为奇数的顶点个数一定是偶数。
* **有向图的度：**
  * 入度 $ID(v)$，出度 $OD(v)$，总度 $TD(v) = ID(v) + OD(v)$。
  * **核心等式：** $\sum ID(v) = \sum OD(v) = |E|$。

### 4. 连通性相关概念（极易混淆考点）

* **无向图（连通图与连通分量）：**
  * **连通图：** 任意两个顶点都有路径存在。
  * **连通分量：** 无向图中的**极大连通子图**（连通子图且包含尽可能多的边）。
  * **极值结论：** 若无向图有 $n$ 个顶点，要保证它一定是连通的，至少需要 $\frac{(n-1)(n-2)}{2} + 1$ 条边（即把 $n-1$ 个点变成完全图，再加一条边连上第 $n$ 个点）。
* **有向图（强连通图与强连通分量）：**
  * **强连通图：** 任意两个顶点 $v$ 和 $w$，既有 $v \to w$ 的路径，也有 $w \to v$ 的路径。
  * **强连通分量：** 有向图中的极大强连通子图。
  * **极值结论：** 若有向图有 $n$ 个顶点，要构成强连通图，最少需要 $n$ 条边（构成一个有向环）。

## 二、图的存储结构（物理结构）

### 1. 邻接矩阵 (Adjacency Matrix)

用一个一维数组存顶点，一个二维数组存边。

* **定义式（无权图）：**
  $$A[i][j]=
  \begin{cases}
  1,&(v_i,v_j)\text{ 或 }\langle v_i,v_j\rangle\in E\\
  0,&其他
  \end{cases}$$
* **定义式（带权图 / 网）：**
  $$A[i][j]=
  \begin{cases}
  w_{ij},&\text{若边存在}\\
  0\text{ 或 }\infty,&\text{若 }i=j\text{ 且不允许自环}\\
  \infty,&\text{若边不存在}
  \end{cases}$$
* **核心性质：**
  * **唯一性：** 给定图的顶点编号，邻接矩阵是**唯一**的。
  * **空间复杂度：** $O(|V|^2)$，与边数无关，极度适合稠密图。
  * **无向图：** 矩阵是对称的（可压缩存储）。第 $i$ 行（或列）的非零元素个数就是 $v_i$ 的度。
  * **有向图：** 第 $i$ 行非零元素个数是 $v_i$ 的**出度**；第 $i$ 列非零元素个数是 $v_i$ 的**入度**。
  * **高阶性质（选填）：** 设图的邻接矩阵为 $A$，$A^n$ 的元素 $A^n[i][j]$ 等于从顶点 $i$ 到顶点 $j$ 长度为 $n$ 的路径数目。

### 2. 邻接表 (Adjacency List)

顺序存储与链式存储的结合。为每个顶点建立一个单链表（存边）。

```c
// 边表结点
typedef struct ArcNode {
    int adjvex;              // 该边指向的顶点在数组中的下标
    struct ArcNode *next;    // 指向下一条弧的指针
    int weight;              // 网的边权值
} ArcNode;

// 顶点表结点
typedef struct VNode {
    VertexType data;         // 顶点信息
    ArcNode *first;          // 指向第一条依附该顶点的弧
} VNode, AdjList[MaxVertexNum];
```
- **核心性质：**
    
    - **不唯一性：** 同一个图的邻接表不唯一（取决于边表结点的插入顺序）。
        
    - **空间复杂度：** 无向图 $O(|V|+2|E|)$；有向图 $O(|V|+|E|)$。极度适合稀疏图。
        
    - **度数计算：** 在有向图中，邻接表找**出度**极快，但找**入度**需要遍历全部链表（因此引出“逆邻接表”）。

### 3. 十字链表与邻接多重表（只适用于特定图）

- **十字链表（针对有向图）：** 完美解决邻接表找入度难的问题。每个顶点和每条弧都有一个结点。空间复杂度 $O(|V|+|E|)$。
    
- **邻接多重表（针对无向图）：** 完美解决邻接矩阵中一条边被存两次，导致删除边操作很麻烦的问题。同一条边在邻接多重表中只有一个结点。空间复杂度 $O(|V|+|E|)$。

## 三、图的遍历算法

图的遍历难点在于“可能存在环”，必须使用 `visited[]` 数组记录访问状态，防止死循环。

### 1. 深度优先搜索 (DFS - Depth First Search)

类似于树的先根遍历，采用**递归**或**栈**实现。

- **访问过程：** 访问顶点 $v$；置 `visited[v] = true`；从 $v$ 的未被访问的邻接点出发继续递归 DFS。退无可退时回溯。
    
- **复杂度分析：**
    
    - **空间：** 需要递归工作栈，最坏为 $O(|V|)$。
        
    - **时间：** 邻接矩阵为 $O(|V|^2)$；邻接表为 $O(|V|+|E|)$。
        
- **DFS生成树：** 如果图连通，DFS 会产生一棵生成树；如果图不连通，DFS 会产生生成森林。邻接矩阵的 DFS 树唯一，邻接表的不唯一。

### 2. 广度优先搜索 (BFS - Breadth First Search)

类似于树的层序遍历，采用**队列**实现。

- **访问过程：** 访问 $v$ 并入队；只要队列不空，队首顶点出队，将其所有未访问的邻接点访问并入队。
    
- **复杂度分析：**
    
    - **空间：** 需要辅助队列，最坏（如星形图）为 $O(|V|)$。
        
    - **时间：** 与 DFS 完全相同。
        
- **核心应用（无权图单源最短路径）：** 利用 BFS 可求无权图（或所有边权值相等的图）中顶点 $u$ 到其他所有顶点的最短路径。距离 $d[w] = d[v] + 1$。

## 四、最小生成树 (MST - Minimum Spanning Tree)

一个连通图的生成树包含图中所有顶点和 $n-1$ 条边。

**最小生成树：** 各边权值之和最小的生成树。

- **MST 的唯一性考点：**
    
    1. MST 的权值之和总是**唯一且最小**的。
        
    2. 若图中各边权值互不相等，则 MST 是**唯一**的。
        
    3. 若图中有权值相等的边，MST 可能不唯一。

### 1. Prim（普里姆）算法

- **思想（加点法）：** 从某一个顶点开始，每次在连接已加入集合 $U$ 的点和未加入集合 $V-U$ 的点之间的边中，挑选一条**权值最小**的边，将其顶点加入 $U$。
    
- **数据结构：** 需要维护一个 `minDist[]` 数组。
    
- **时间复杂度：** $O(|V|^2)$。与边数无关，**适合稠密图**。

### 2. Kruskal（克鲁斯卡尔）算法

- **思想（加边法）：** 将所有边按权值从小到大排序。按次序挑边，若选中的边不会在已选的边中构成**回路**，则将其加入 MST；否则舍弃。
    
- **数据结构：** 使用**并查集 (Disjoint Set)** 来检测是否生成回路。
    
- **时间复杂度：** $O(|E|\log|E|)$。受边数影响大，**适合稀疏图**。

## 五、最短路径算法

### 1. Dijkstra（迪杰斯特拉）算法 —— 单源最短路径

- **思想（贪心法）：** 将顶点分为已确定最短路径的集合 $S$ 和未确定集合 $V-S$。每次从 $V-S$ 中选出距离源点最近的顶点加入 $S$，并以它为中转点，**松弛（更新）** 其他未确定顶点的距离。
    
- **状态转移方程：**
    
    $$dist[j] = \min(dist[j], dist[i] + matrix[i][j])$$
    
- **前提条件：** 图中**绝对不能包含负权值的边**，否则贪心策略失效。
    
- **时间复杂度：** 不使用堆优化时为 $O(|V|^2)$。

### 2. Floyd（弗洛伊德）算法 —— 任意两点间最短路径

- **思想（动态规划法）：** 允许图中有负权边，但**不能有包含负权边的环**。
    
    定义 $A^{(k)}[i][j]$ 为从顶点 $i$ 到 $j$、中间只经过编号不大于 $k$ 的顶点的最短路径长度。
    
- **状态转移方程：**
    
    $$A^{(k)}[i][j] = \min(A^{(k-1)}[i][j], A^{(k-1)}[i][k] + A^{(k-1)}[k][j])$$
    
- **时间复杂度：** 嵌套了三层循环，严格的 $O(|V|^3)$。
    
- **空间复杂度：** $O(|V|^2)$（通常滚动数组优化掉一维）。

## 六、有向无环图 (DAG) 与拓扑排序

**DAG (Directed Acyclic Graph)：** 没有环的有向图。常用于表示工程或系统的先后制约关系。

### 1. AOV 网 (Activity On Vertex Network)

用**顶点**表示活动，用**有向边**表示活动之间的先后必然关系。

### 2. 拓扑排序 (Topological Sort)

将 DAG 的所有顶点排列成一个线性序列，使得图中任意一对顶点 $u$ 和 $v$，若边 $\langle u,v\rangle$ 存在，则 $u$ 在序列中必定出现在 $v$ 之前。

- **操作过程：**
    
    1. 找一个**入度为 0** 的顶点，输出它。
        
    2. 从网中删除该顶点及所有以它为起点的出边（即它所指向的顶点的入度减 1）。
        
    3. 重复 1、2。

- **核心结论：**
    
    - 若网中有环，则拓扑排序必定中断（剩余顶点入度均不为 0）。因此拓扑排序可用于**检测有向图是否有环**。
        
    - 拓扑排序序列通常**不唯一**。
        
    - 时间复杂度：$O(|V|+|E|)$。

- **逆拓扑排序：** 每次找**出度为 0** 的顶点删除。可用 DFS 算法实现（在 DFS 递归调用退出前输出该顶点，最后结果逆序）。

## 七、关键路径 (Critical Path)

### 1. AOE 网 (Activity On Edge Network)

带权有向无环图，**边**表示活动，**边上的权值**表示活动持续时间，**顶点**表示事件（标志某些活动的完成或开始）。

- **源点（起点）：** 入度为 0 的唯一顶点。
    
- **汇点（终点）：** 出度为 0 的唯一顶点。

### 2. 四个核心时间参数（大题计算必考）

1. **事件最早发生时间 $ve(k)$：** 从源点到顶点 $k$ 的**最长路径**长度。递推公式（按拓扑序列）：
    
    $$ve(j) = \max\{ve(i) + weight(i, j)\}$$

2. **事件最迟发生时间 $vl(k)$：** 在不推迟整个工期的前提下，事件 $k$ 允许的最晚发生时间。递推公式（按逆拓扑序列）：
    
    $$vl(i) = \min\{vl(j) - weight(i, j)\}$$

3. **活动最早开始时间 $e(i)$：** 该活动所在**边起点的事件**最早发生时间。若活动 $a_i$ 对应边 $\langle j,k\rangle$，则 $e(i) = ve(j)$。

4. **活动最迟开始时间 $l(i)$：** 该活动所在**边终点的事件**最迟发生时间，减去活动持续时间。$l(i) = vl(k) - weight(j, k)$。

### 3. 关键活动与关键路径

- **时间余量 $d(i)$：** $d(i) = l(i) - e(i)$。表示活动可以拖延的时间。
- **关键活动：** $d(i) = 0$ 的活动。
- **关键路径：** 由关键活动组成的从源点到汇点的路径。关键路径上的全长即为工程的最短完成时间。
- **高频易错结论：**
    - 关键路径可能有多条。
    - 缩短某一关键活动的时间，**可能**会使关键路径变短；但如果缩短得太多，该关键活动可能变成非关键活动，关键路径会发生转移。
    - 只有当某活动属于**所有**关键路径时，缩短它才能必然缩短总工期。

## 八、408 高频易错点扫雷（首轮警戒线）

1. **图的遍历唯一性：** 给定图的**逻辑结构**，DFS/BFS 序列不唯一；给定图的**物理结构**（如邻接表或邻接矩阵），DFS/BFS 序列唯一。
    
2. **极大与极小：**
    
    - 连通分量是**极大**连通子图（必须包含连通部分的所有顶点和全部相关的边）。
        
    - 生成树是**极小**连通子图（包含所有顶点，但边数最少，只有 $n-1$ 条）。
        
3. **连通分量的数量与 DFS：** 对无向图调用 DFS 或 BFS 过程的次数，恰好等于该图连通分量的个数。
    
4. **MST 考法陷阱：** Prim 算法在树的扩展过程中，始终保持连通性；Kruskal 算法在合并过程中，中间状态可能由多个不连通的树（森林）组成。
    
5. **Dijkstra 无法处理负权：** 选择题若问哪个算法不能处理负权图，无脑选 Dijkstra。
    
6. **图论四大应用的时间复杂度对比（必背）：**
    
    - BFS / DFS / 拓扑排序：$O(|V|+|E|)$ （采用邻接表）
        
    - Prim / Dijkstra：$O(|V|^2)$
        
    - Kruskal：$O(|E|\log|E|)$
        
    - Floyd：$O(|V|^3)$
