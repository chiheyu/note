## 一、串的基本概念

### 1. 串的定义

串 (String) 是由零个或多个字符组成的有限序列，通常记为：
$$S='a_1a_2\cdots a_n'$$
其中 $S$ 为串名，单引号内的字符序列为串值，$n$ 为串长。

- **空串：** 长度为 0 的串，记为 `""`。
- **空格串：** 由一个或多个空格字符组成的串，长度不为 0。
- **子串：** 串中任意连续字符组成的子序列。
- **主串：** 包含某个子串的串。
- **子串位置：** 子串第一个字符在主串中的位置。408 题目中常默认位置从 1 开始，但写程序时数组下标常从 0 开始，必须看清题设。

**本质理解：** 串是一种特殊的线性表，其数据元素限定为字符。与普通线性表相比，串的常考重点不是单个字符的插入删除，而是整体匹配、查找和模式串处理。

---

## 二、串的存储结构

### 1. 定长顺序存储

用一组地址连续的存储单元存放串值，通常需要额外记录串长。

```c
#define MAXLEN 255
typedef struct {
    char ch[MAXLEN + 1]; // 采用 1 起始位序时，ch[0] 可空置
    int length;
} SString;
```

- **优点：** 支持随机访问，定位第 $i$ 个字符时间复杂度为 $O(1)$。
- **缺点：** 最大长度固定，容易发生截断或空间浪费。

### 2. 堆分配存储

在堆区动态分配连续空间存放串值。

```c
typedef struct {
    char *ch;
    int length;
} HString;
```

- **优点：** 串长可动态变化，空间利用率更高。
- **缺点：** 仍然要求物理空间连续，扩容时可能需要重新分配和复制。

### 3. 块链存储

用链表存储串，每个结点可以存放一个字符，也可以存放多个字符。

- **结点大小为 1：** 插入删除方便，但存储密度低。
- **结点大小大于 1：** 存储密度提高，但可能出现结点内部未填满的浪费。

---

## 三、串的基本操作

常见基本操作包括：

- `StrAssign(&T, chars)`：赋值操作，将字符串常量赋给串 T。
- `StrCopy(&T, S)`：复制操作，由串 S 复制得到串 T。
- `StrEmpty(S)`：判空操作。
- `StrLength(S)`：求串长。
- `ClearString(&S)`：清空串。
- `DestroyString(&S)`：销毁串。
- `Concat(&T, S1, S2)`：串联接，用 T 返回由 S1 和 S2 联接而成的新串。
- `SubString(&Sub, S, pos, len)`：求子串，用 Sub 返回 S 中从 pos 开始、长度为 len 的子串。
- `Index(S, T)`：定位操作，返回子串 T 在主串 S 中第一次出现的位置。

**易错点：** `pos` 若按位序理解，通常从 1 开始；若按数组下标理解，通常从 0 开始。手算题和代码题的起始下标可能不同。

## 四、朴素模式匹配算法

### 1. 问题描述

给定主串 S 和模式串 T，寻找 T 在 S 中第一次出现的位置。

### 2. 基本思想

从主串的每一个可能起点开始，逐个字符与模式串比较：

1. 若当前字符相等，则继续比较下一对字符。
2. 若当前字符不等，则主串起点后移一位，模式串重新从第一个字符开始比较。
3. 若模式串所有字符均匹配成功，则找到匹配位置。

### 3. 时间复杂度

设主串长度为 $n$，模式串长度为 $m$。

- **最好情况：** 每次第一个字符就匹配失败，时间复杂度 $O(n)$。
- **最坏情况：** 每个起点都比较到模式串末尾附近才失败，时间复杂度 $O(nm)$。

## 五、KMP 算法

### 1. 核心思想

KMP 算法在匹配失败时，不回退主串指针，而是利用模式串自身的前后缀信息移动模式串，从而避免重复比较。

**关键结论：** 主串指针 `i` 不回退，模式串指针 `j` 根据 `next` 数组回退。

### 2. 前缀、后缀与部分匹配

对模式串的某个前缀子串：

- **前缀：** 不包含最后一个字符的所有头部子串。
- **后缀：** 不包含第一个字符的所有尾部子串。
- **最长相等前后缀长度：** 当前已匹配部分中，最长的“真前缀 = 真后缀”的长度。

KMP 的本质就是把已经匹配过的信息转化为下一次比较的位置。

### 3. `next` 数组的含义

`next[j]` 表示当模式串第 $j$ 个字符匹配失败时，模式串指针应回退到的位置。

408 中常见的 `next` 数组有两种写法：

- **位序从 1 开始：** `next[1] = 0`。
- **数组下标从 0 开始：** 常写作 `next[0] = -1`。

两种写法本质相同，但下标整体平移了 1 位。做题时必须先看题目给出的定义，不能混用。

### 4. KMP 匹配过程

```c
int Index_KMP(SString S, SString T, int next[]) {
    int i = 1, j = 1;
    while (i <= S.length && j <= T.length) {
        if (j == 0 || S.ch[i] == T.ch[j]) {
            ++i;
            ++j;
        } else {
            j = next[j];
        }
    }
    if (j > T.length) {
        return i - T.length;
    }
    return 0;
}
```

**注意：** 上述模板采用位序从 1 开始的写法，所以返回值也是从 1 开始的位置。

### 5. `nextval` 数组优化

当 `T[j] == T[next[j]]` 时，模式串回退后仍然会发生同样的失败比较，因此可以继续回退，得到优化后的 `nextval` 数组。

规则可理解为：
- 若 `T[j] != T[next[j]]`，则 `nextval[j] = next[j]`；
- 若 `T[j] == T[next[j]]`，则 `nextval[j] = nextval[next[j]]`。

`nextval` 只减少无效比较次数，不改变 KMP 的整体时间复杂度。

## 六、算法复杂度对比

| 算法 | 主串是否回退 | 预处理 | 最坏时间复杂度 |
| --- | --- | --- | --- |
| 朴素模式匹配 | 回退 | 无 | $O(nm)$ |
| KMP | 不回退 | `next` 数组 | $O(n+m)$ |

## 七、408 高频易错点扫雷

1. **空串与空格串不同：** 空串长度为 0，空格串长度至少为 1。
2. **子串必须连续：** 不连续的字符序列是子序列，不是子串。
3. **位序和下标要分清：** 串的位置常从 1 开始，C 语言数组下标常从 0 开始。
4. **朴素匹配会回退主串指针：** KMP 的关键优势是主串指针不回退。
5. **`next` 数组定义不唯一：** `next[1]=0` 与 `next[0]=-1` 是两套不同下标体系，不能直接混抄。
6. **KMP 不是不比较字符：** 它只是利用模式串信息减少重复比较，失败时移动的是模式串。
7. **`nextval` 是优化不是新算法：** 它优化的是 `next` 回退后仍会立即失败的情况。

---

## 八、核心结论清单

- 串是数据元素为字符的特殊线性表。
- 串的主要考点是模式匹配，尤其是 KMP 算法。
- 朴素模式匹配最坏时间复杂度为 $O(nm)$。
- KMP 通过 `next` 数组避免主串指针回退，时间复杂度为 $O(n+m)$。
- 做 KMP 题前先确认下标体系：位序从 1 开始还是数组下标从 0 开始。
