## 一、数据结构核心概念体系

### 1. 数据、数据元素、数据项、数据对象
* **数据 (Data)：** 能被计算机识别、存储和处理的符号的集合（包括数字、字符、图像、音频等）。
* **数据元素 (Data Element)：** 数据的**基本单位**。在计算机程序中通常作为一个整体进行考虑和处理。比如学生表中的“一名学生的一条记录”。
* **数据项 (Data Item)：** 构成数据元素的不可分割的**最小单位**。比如一名学生记录中的“姓名”、“学号”。
* **数据对象 (Data Object)：** 具有**相同性质**的数据元素的集合，是数据的一个子集。比如整数集合 $N = \{0, \pm 1, \pm 2, \dots\}$。

**本质理解：** 数据结构研究的是**一堆数据之间有什么关系，以及计算机怎样高效保存和操作它们**。
包含关系宏观感受：数据 > 数据对象 > 数据元素 > 数据项。

### 2. 数据类型与抽象数据类型 (ADT)
* **数据类型 (Data Type)：** 一个值的集合和定义在此集合上的一组操作的总称。
    * 原子类型：其值不可再分（如 C 语言的 `int`, `float`）。
    * 结构类型：其值可以再分解为若干成分（如 `struct`）。
* **抽象数据类型 (Abstract Data Type, ADT)：** 是一个数学模型以及定义在该模型上的一组操作。
    * **核心思想：** 数据抽象与信息隐蔽（封装）。它只关心逻辑结构和运算的数学抽象特性，**不关心在计算机内部如何表示和实现**。
    * **定义格式：** 通常包含数据对象、数据关系和基本操作三部分。

### 3. 数据结构的三层次（核心考点）
数据结构 = 逻辑结构 + 存储结构 + 数据运算。

* **逻辑结构：** 从数学和逻辑的角度看数据元素之间的关系。与数据的存储无关，是独立于计算机的。
* **存储结构（物理结构）：** 数据结构在计算机内存中的表示（又称映像）。包含数据元素的表示和关系的表示。
* **数据运算：** 施加在数据上的运算（如插入、删除、查找、排序）。运算的**定义**针对逻辑结构，运算的**实现**针对存储结构。

## 二、逻辑结构分类（“是什么关系”）

逻辑结构主要分为两大类：**线性结构**和**非线性结构**。

### 1. 集合结构（非线性）
元素之间除了“属于同一个集合”外，没有其他关系。
* **特点：** 结构最松散，通常用于辅助说明或查找问题。

### 2. 线性结构
元素之间存在**一对一**的线性关系。
* **特点：** 除第一个元素外，每个元素有且仅有一个直接前驱；除最后一个元素外，每个元素有且仅有一个直接后继。
* **典型代表：** 线性表、栈、队列、数组、串。

### 3. 树形结构（非线性）
元素之间存在**一对多**的层次关系。
* **特点：** 具有明确的根和分支结构。
* **典型代表：** 普通树、二叉树、B树、堆。

### 4. 图状结构或网状结构（非线性）
元素之间存在**多对多**的任意关系。
* **特点：** 每个元素的前驱和后继的数量都不限。
* **典型代表：** 有向图、无向图、交通网络。

**408高频提醒：** 整门 408 数据结构的核心主线就是按逻辑结构演进的：从“一条线（线性表/栈/队列）”学到“一棵树（二叉树/多叉树）”，再学到“一张网（图）”。

## 三、四大存储结构（“怎么存”）

408 大纲要求全面掌握以下四种物理存储结构：

### 1. 顺序存储
把逻辑上相邻的元素，存放在**物理地址也相邻**的存储单元中。
* **优点：** 可以实现**随机存取**（按下标直接访问，时间复杂度为 $O(1)$）；不额外占用空间存放结点间的逻辑关系。
* **缺点：** 插入、删除常常需要移动大量元素，时间复杂度为 $O(n)$；只能使用相邻的一整块存储单元，容易产生内存碎片或造成空间浪费。

### 2. 链式存储
不要求逻辑上相邻的元素在物理上也相邻。每个结点借助**指针**来表示逻辑关系。
* **优点：** 插入、删除时只需要修改指针，不必整体搬家，非常灵活；动态分配，不会产生大块内存浪费。
* **缺点：** 不能随机访问，只能顺序存取（找第 $i$ 个元素需要从头遍历，时间复杂度为 $O(n)$）；指针本身会额外消耗存储空间（降低了存储密度）。

### 3. 索引存储
在存储元素信息的同时，还建立附加的**索引表**。索引表中的每项称为索引项，一般形式为：`(关键字, 地址)`。
* **优点：** 检索速度极快，便于数据更新。
* **缺点：** 附加的索引表需要占用额外的存储空间；增加和删除数据时也要同步修改索引表，花费较多时间。

### 4. 散列存储 (Hash)
根据元素的关键字直接计算出该元素的物理存储地址（又称哈希存储）。
* **优点：** 检索、增加和删除结点的操作都极快，理想情况下时间复杂度为 $O(1)$。
* **缺点：** 若散列函数设计不好，容易出现“冲突（碰撞）”现象；只支持通过关键字的精确查找，不支持范围查找。

## 四、算法的基本概念与评价指标

### 1. 算法是什么
算法是对特定问题求解步骤的一种描述，它是指令的有限序列。
（注：程序不等于算法，程序可以无限循环运行，如操作系统，但算法必须在有限步内结束）。

### 2. 算法的五个基本特性（必须同时满足）
* **有穷性：** 执行有限步后必须结束，且每一步都在有限时间内完成。
* **确定性：** 每条指令都有确切含义，没有二义性。相同输入只能得到相同输出。
* **可行性：** 每一步都能通过已实现的基本运算执行有限次来实现。
* **输入：** 有零个或多个输入。
* **输出：** 有一个或多个输出。没有输出的算法是没有意义的。

### 3. 好的算法应达到的目标（设计要求）
* **正确性 (Correctness)：** 能够正确地解决实际问题。
* **可读性 (Readability)：** 便于人类阅读、理解和交流。
* **健壮性 (Robustness)：** 当输入非法数据时，算法能适当地做出反应或进行容错处理，而不会产生莫名其妙的输出或系统崩溃。
* **高效率与低存储量需求：** 执行速度快（时间复杂度低），且占用额外内存少（空间复杂度低）。

## 五、算法效率的度量：时间复杂度

时间复杂度考量的是**核心操作次数按数据规模 $n$ 变大时的增长率**。

### 1. 渐进符号 (408考研常客)
* $O(f(n))$：算法运行时间的**上界**（最坏情况），408 默认考察。
* $\Omega(f(n))$：算法运行时间的**下界**（最好情况）。
* $\Theta(f(n))$：算法运行时间的**确界**（同阶，最准确的描述）。

### 2. 复杂度排序（必须烂熟于心）
$$O(1) < O(\log n) < O(n) < O(n\log n) < O(n^2) < O(n^3) < O(2^n) < O(n!) < O(n^n)$$

### 3. 复杂度运算法则
* **加法规则：** $O(f(n)) + O(g(n)) = O(\max(f(n), g(n)))$。常用于顺序执行的独立代码块。
* **乘法规则：** $O(f(n)) \times O(g(n)) = O(f(n) \times g(n))$。常用于嵌套循环。

### 4. 经典代码分析模型
**模型 A：对数型循环**
```c
for (int i = 1; i <= n; i *= 2) {
    x++;
}
```
_分析：_ 每次 $i$ 乘 2，设循环 $k$ 次后有 $2^k > n$，则 $k = \log_2 n$。 
_结论：_ 时间复杂度为 $O(\log n)$。
**模型 B：开方型循环**
```c
for (int i = 0; i * i < n; i++) {
    x++;
}
```
_分析：_ 设循环 $k$ 次，结束条件是 $k^2 \ge n$，即 $k = \sqrt{n}$。 
_结论：_ 时间复杂度为 $O(\sqrt{n})$。
**模型 C：等差数列型双层嵌套**
```
for (int i = 0; i < n; i++) {
    for (int j = 0; j < i; j++) {
        x++;
    }
}
```

_分析：_ 内层循环执行次数依次为 $0, 1, 2, \dots, n-1$。总次数是等差数列求和 $S = \frac{n(n-1)}{2}$，最高次幂为 $n^2$。
_结论：_ 时间复杂度为 $O(n^2)$。

## 六、空间复杂度

空间复杂度研究算法**运行过程中所需要的额外工作空间**随规模 $n$ 的增长情况，记为 $S(n) = O(f(n))$。

### 1. 原地工作 (In-place)

如果算法执行时所需的辅助空间相对于输入数据量而言是个常数，即 $S(n) = O(1)$，则称该算法是**原地工作**的。

### 2. 常见空间占用分析

- 只使用了几个简单的计数器/指针等局部变量：空间复杂度 $O(1)$。
    
- 内部声明了一维数组 `int a[n]` 或使用 `malloc` 动态分配了 $n$ 个空间：空间复杂度 $O(n)$。
    
- 内部声明了二维矩阵：空间复杂度 $O(n^2)$。
    
- **递归算法的空间复杂度（重点易错）：** 必须考虑递归函数调用的系统栈空间开销。空间复杂度 = 递归调用的最大深度 $\times$ 每次调用的栈空间。例如，深度为 $n$ 的单分支递归通常空间复杂度为 $O(n)$。

## 七、408 首轮复习高频考法与陷阱

### 1. 辨析题陷阱：逻辑 vs 存储

- **死记：** 线性表、栈、队列、树、图 都是**逻辑结构**。
    
- **死记：** 顺序表、单链表、哈希表、邻接矩阵 都是**存储结构**。
    
- **陷阱题：** “循环队列是逻辑结构还是存储结构？” —— 循环队列是队列的一种顺序**存储结构**实现！
    
- **陷阱题：** “栈是顺序存储还是链式存储？” —— 栈是逻辑结构，既可以用顺序存储（顺序栈），也可以用链式存储（链栈）。
    

### 2. 复杂度题目速解法

在 408 选择题中遇到求时间复杂度的伪代码步骤：

1. 找到最内层循环中执行次数最多的**基本操作语句**。
    
2. 找出决定循环结束的**核心控制变量**。
    
3. 写出该变量随每次迭代变化的数学公式，令其达到边界条件，求解次数（通常只保留最高阶项）。
    

### 3. 数据存储结构的选择策略

- 若需频繁按序号**查找**（例如二分查找）：必须选择**顺序存储**（数组）。链式存储由于不支持随机访问，无法进行高效的二分查找。
    
- 若需频繁进行**插入和删除**操作：优先考虑**链式存储**，避免大量移动元素。
    
- 存储空间预判：如果事先难以估计数据规模的最大容量，优先选用**动态的链式存储**；如果数据规模固定且要求空间无额外开销（高存储密度），优先选用**顺序存储**。

## 八、第一章核心结论清单总结

- **数据结构三要素：** 逻辑结构、物理结构（存储结构）、数据运算。
    
- **四种逻辑结构：** 集合、线性、树、图。
    
- **四种存储结构：** 顺序、链式、索引、散列。
    
- **算法的五大特性：** 有穷性、确定性、可行性、输入、输出。
    
- $O(1)$ 不代表只执行了 1 条语句，而是指语句执行次数不随数据规模 $n$ 的变化而变化，是一个常数级别。
    
- 算法题第一反应：先判断输入规模 $n$，再数主要操作；遇到递归先算最大调用深度。
