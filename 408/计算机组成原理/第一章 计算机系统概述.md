## 一、计算机系统层次结构与组成（“宏观全景”）

### 1. 硬件与软件的等效性
计算机系统由**硬件系统**和**软件系统**共同组成。
* **硬件 (Hardware)：** 计算机的实体，如主机、外设等。是计算机系统的物质基础。
* **软件 (Software)：** 由具有各类特殊功能的程序组成。分为**系统软件**（如 OS、DBMS、编译器）和**应用软件**（如微信、Word）。
* **软硬件逻辑等效性：** 某功能既能由软件实现（较慢，但成本低、灵活），也能由硬件实现（极快，但成本高、固化）。在计算机体系结构设计中，软硬件功能的划分是一个核心权衡点。

### 2. 计算机系统的多级层次结构（核心考点）
从底层硬件到高层软件，计算机系统可视为一个多级虚拟机的组合：
* **第 0 级（硬联逻辑级）：** 物理硬件，由门电路、触发器等逻辑电路组成。
* **第 1 级（微程序机器级）：** 物理机，将机器指令解释为微指令。
* **第 2 级（传统机器语言级）：** 物理机，执行机器指令（ISA 架构规定的指令）。**（以上为硬件，以下为软件）**
* **第 3 级（操作系统级）：** 虚拟机，提供广义指令（系统调用）。
* **第 4 级（汇编语言级）：** 虚拟机，执行汇编语言，需经过**汇编程序**翻译。
* **第 5 级（高级语言级）：** 虚拟机，执行 C/C++、Java 等，需经过**编译程序**或**解释程序**。

**408高频提醒：** ISA（指令集体系结构）是软件和硬件之间的**接口**。下层硬件负责实现 ISA，上层软件基于 ISA 进行编程。

## 二、计算机硬件的五大部件与工作原理

### 1. 冯·诺依曼机的基本思想（三大核心）
1. 计算机硬件系统由**运算器、存储器、控制器、输入设备和输出设备**五大部件组成。
2. **指令和数据以同等地位存放于存储器内**，并可按地址寻访。（两者在形式上都是二进制位串，CPU 靠取指周期还是执行周期来区分它们）。
3. 指令和数据均用**二进制代码**表示。
4. 指令由**操作码**和**地址码**组成。
5. **存储程序（最核心）：** 将事先编好的程序和数据存入主存，计算机接通电源后，自动逐条取出指令并执行。
6. 以**运算器**为中心（现代计算机已演变为以**存储器**为中心）。

### 2. 硬件五大核心部件细化
* **存储器 (Memory)：** 分为内部存储器（主存）和外部存储器（辅存）。CPU 只能直接访问主存。
  * **MAR (Memory Address Register, 存储器地址寄存器)：** 存放欲访问的存储单元地址。**MAR 的位数决定了主存的最大寻址空间**。如 MAR 为 32 位，则最大寻址空间为 $2^{32}$。
  * **MDR (Memory Data Register, 存储器数据寄存器)：** 存放从主存读出或写入主存的数据。**MDR 的位数通常等于存储字长**。
* **运算器 (ALU)：** 核心是算术逻辑单元 (ALU)。包含累加器 (ACC)、乘商寄存器 (MQ)、操作数寄存器 (X) 以及程序状态字寄存器 (PSW/标志寄存器)。
* **控制器 (CU)：** 计算机的指挥中心。
  * **PC (Program Counter, 程序计数器)：** 存放**下一条**要执行指令的地址。具有自动加 1 功能。
  * **IR (Instruction Register, 指令寄存器)：** 存放**当前**正在执行的指令。
  * **CU (Control Unit, 控制单元)：** 分析指令并发出各种微操作命令序列。

**本质理解：** CPU = 运算器 + 控制器。主机 = CPU + 主存。

## 三、程序的翻译与执行过程

### 1. 从源程序到可执行文件的四个阶段（以 C 语言为例）
我们写的 `hello.c` 不能被机器直接执行，需要经过完整的“翻译”链条：
1. **预处理 (Preprocessing)：** 处理 `#include`、`#define` 等预处理指令，删除注释，生成 `.i` 文件。
2. **编译 (Compilation)：** 进行词法分析、语法分析、语义分析及优化后，将高级语言**翻译成汇编代码**，生成 `.s` 文件。
3. **汇编 (Assembly)：** 将汇编代码**翻译成机器指令**（二进制编码），生成可重定位目标文件 `.o` 文件。
4. **链接 (Linking)：** 将多个目标文件及标准库函数结合在一起，生成最终的**可执行文件**。

### 2. 指令执行的基本过程
程序的运行本质上是 CPU 不断地执行指令的过程。一条指令的完整生命周期（指令周期）：
1. **取指令 (Fetch)：** 根据 PC 的值，从主存中取出指令放入 IR，同时 PC 自动指向下一条指令。
2. **分析指令 (Decode)：** CU 识别 IR 中的操作码，确定指令类型。
3. **执行指令 (Execute)：** CU 向运算器、存储器等发出控制信号，完成指令规定的操作。
4. **写回/保存结果 (Store)：** 将运算结果写回寄存器或内存。

## 四、计算机性能指标（必考计算题核心）

### 1. 字长的三个概念（极易混淆）
* **机器字长：** CPU 一次能处理的**整数数据**（定点数）的二进制位数。通常等于 ALU 的宽度或通用寄存器的宽度（如 32 位或 64 位机器）。
* **指令字长：** 一个指令字中包含的二进制代码的位数。
* **存储字长：** 一个存储单元中存放的二进制代码的位数（通常等于 MDR 的位数）。
*(注：指令字长一般是存储字长的整数倍，若指令字长等于存储字长的两倍，则需两次访存才能取出一整条指令。)*

### 2. 吞吐量与响应时间
* **吞吐量 (Throughput)：** 系统在单位时间内处理请求的数量。主要取决于主存的存取周期。
* **响应时间 (Response Time)：** 从用户提交请求到系统首次产生响应并获得它所需要的结果的等待时间。

### 3. CPU 时钟与主频
* **时钟周期 (Clock Cycle)：** 计算机中最基本的、最小的时间单位。CPU 的时钟信号节拍。
* **主频 (Clock Rate, $f$)：** 机器内部主时钟的频率，即每秒有多少个时钟周期。单位是 Hz。
  $$主频 = \frac{1}{时钟周期}$$

### 4. CPI 与 CPU 执行时间（重中之重）
* **CPI (Cycles Per Instruction)：** 执行**一条**指令所需的平均时钟周期数。
* **CPU 执行时间：** 运行一个程序所花费的实际 CPU 时间。
  $$CPU执行时间 = 指令条数 \times CPI \times 时钟周期 = \frac{指令条数 \times CPI}{主频}$$

### 5. 宏观性能指标 MIPS 与 FLOPS
* **MIPS (Million Instructions Per Second)：** 每秒执行多少百万条指令。
  $$MIPS = \frac{指令条数}{执行时间 \times 10^6} = \frac{主频}{CPI \times 10^6}$$
* **FLOPS (Floating-point Operations Per Second)：** 每秒浮点运算次数。用来衡量科学计算能力。
  * MFLOPS ($10^6$), GFLOPS ($10^9$), TFLOPS ($10^{12}$), PFLOPS ($10^{15}$), EFLOPS ($10^{18}$), ZFLOPS ($10^{21}$)。

### 6. 阿姆达尔定律 (Amdahl's Law)
用于评估系统中某一部件改进后，对整个系统性能提升的理论上限。
* 假设系统改进前的总执行时间为 $T_{old}$。
* 改进部分在原系统执行时间中所占的比例为 $f$（可改进比例）。
* 改进部分性能提升的倍数为 $k$（加速比）。
$$加速比(Speedup) = \frac{T_{old}}{T_{new}} = \frac{1}{(1-f) + \frac{f}{k}}$$
**结论：** 无论某一部件提升多快（$k \to \infty$），整体性能提升受限于不可改进部分 $(1-f)$。即“木桶效应”。

## 五、408 经典计算例题拆解

### 题目 1：综合性能评估
某程序有 $10^9$ 条指令，其中 A 类指令占 40%，CPI 为 2；B 类指令占 60%，CPI 为 3。CPU 主频为 2GHz，求程序的 CPI、MIPS 和 CPU 执行时间。

### 解答步骤
1. **求平均 CPI：**
   $$CPI = 40\% \times 2 + 60\% \times 3 = 0.8 + 1.8 = 2.6$$
2. **求 CPU 执行时间：**
   $$CPU执行时间 = \frac{指令条数 \times CPI}{主频} = \frac{10^9 \times 2.6}{2 \times 10^9} = 1.3 \text{ 秒}$$
3. **求 MIPS：**
   $$MIPS = \frac{主频}{CPI \times 10^6} = \frac{2 \times 10^9}{2.6 \times 10^6} \approx 769.2$$

## 六、首轮复习高频考法与陷阱防范

1. **陷阱：主频高 = 速度快？**
   * **错！** CPU 执行时间受指令条数、CPI 和主频三个因素共同制约。主频高的机器，其架构可能导致平均 CPI 变大，或者编译器生成的指令条数更多，导致整体时间反而变长。
2. **陷阱：MIPS 可以准确跨架构比较性能？**
   * **错！** 不同 ISA 的机器（如 x86 的 CISC 和 ARM 的 RISC），完成同样功能所需的指令条数和指令复杂度完全不同。MIPS 只能用于比较**指令集相同**的机器。
3. **概念辨析：翻译程序 vs 编译程序 vs 解释程序**
   * **翻译程序：** 是编译、解释、汇编程序的统称。
   * **编译程序：** 一次性将高级语言翻译成目标程序（机器代码），执行时脱离源程序，**运行速度快**。
   * **解释程序：** 将高级语言语句逐条翻译并立即执行，**不生成目标程序**，每次运行都需要重新翻译，**运行速度慢，但跨平台性好**（如 Python, JavaScript）。
4. **位/字节计算混淆：**
   * 数据通信（带宽）中的 K、M、G、T 是 $10^3, 10^6, 10^9, 10^{12}$。
   * 存储容量计算中的 K、M、G、T 是 $2^{10}, 2^{20}, 2^{30}, 2^{40}$。
   * $1 \text{ Byte (B)} = 8 \text{ bits (b)}$。考题中给的常是位宽（bits），要求求容量（Bytes）时切记除以 8。

## 七、第一章核心结论清单总结

* **冯·诺依曼三大支柱：** 存储程序、二进制表示、指令数据同等存放。
* **硬件结构公式：** CPU = 运算器(ALU/ACC/PSW) + 控制器(CU/PC/IR)。主机包含主存，不包含外存。
* **核心寄存器定位：** PC 和 IR 在 CPU 的控制器中；MAR 和 MDR 逻辑上属于主存，但现代计算机通常将其集成在 CPU 芯片内。
* **程序执行时间 Iron Law (铁律)：** $T = N \times CPI / f$。性能优化（如流水线技术）就是在这三个变量上做文章。
* **编译四个阶段不可逆：** 预处理 $\to$ 编译 $\to$ 汇编 $\to$ 链接。
