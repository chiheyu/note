## 一、数据链路层解决什么问题与基本功能

#### 1. 核心概念
* **结点：** 主机、路由器。
* **链路 (Link)：** 网络中两个结点之间的**物理通道**（无源的点到点物理线路段）。
* **数据链路 (Data Link)：** 网络中两个结点之间的**逻辑通道**，把实现控制数据传输的**协议的硬件和软件**加到链路上就构成了数据链路。
* **传输单位：** 帧 (Frame)。
* **本质任务：** 将物理层提供的可能出错的物理连接改造为逻辑上无差错的数据链路。

#### 2. 三个基本问题（数据链路层必备功能）
1. **封装成帧：** 将网络层交下来的 IP 数据报添加首部和尾部，封装成帧。首部和尾部包含重要的控制信息。
2. **透明传输：** 不管所传数据是什么样的比特组合，都应当能在链路上传送。如果数据中出现了与帧定界符相同的比特串，必须采取措施屏蔽（字符填充/比特填充）。
3. **差错检测：** 接收方必须能检测出帧在传输过程中是否出现了比特差错（1变0，0变1）。

## 二、组帧 (Framing) 技术

组帧的目的是让接收方能从比特流中准确划分出帧的起始和终止。

### 1. 字符计数法
* 在帧头部使用一个计数字段，标明帧内字符数。
* **致命缺点：** 一旦计数字段出错，接收方将无法正确划分后续所有帧，导致**灾难性失去同步**。

### 2. 字符填充法（面向字节）
* 使用特定的控制字符（如 `SOH` 表示首，`EOT` 表示尾）作为定界符。
* 当数据部分出现 `EOT` 或 `SOH` 时，在其前面插入转义字符 `ESC`。

### 3. 零比特填充法（面向比特，重中之重）
* **规则：** 使用 `01111110` 作为帧定界符。
* **发送方（“5 个 1 塞 1 个 0”）：** 只要发现数据流中有连续 5 个 1，就立即插入一个 0。
* **接收方（“5 个 1 删 1 个 0”）：** 只要发现连续 5 个 1，就把其后的一个 0 删除。
* **优点：** 硬件实现容易，适用任意长度比特流，是**目前最常用的方法**（如 HDLC 协议）。

### 4. 违规编码法
* 利用物理层编码的违规状态来定界。例如曼彻斯特编码中，只用“高-低”和“低-高”，可以把“高-高”或“低-低”作为定界符。局域网标准常用。

## 三、差错控制 (Error Control)

数据链路层只提供**检错**（丢弃错误帧），通常不提供纠错（部分无线网络除外）。

### 1. 奇偶校验码
只能检测出**奇数个**比特错误，无法检出偶数个，也无法定位和纠正。

### 2. 循环冗余校验 (CRC)（必考计算题理论）
* **基本思想：** 发送方和接收方约定一个生成多项式 $G(x)$。发送方用数据比特流去除以 $G(x)$，将得到的**余数**作为帧检验序列 (FCS) 附加在数据帧后面。接收方收到后，用带有 FCS 的帧去除以 $G(x)$，若余数为 0，则认为无差错。
* **模 2 运算：** 加减法不进位/借位，完全等价于**异或 (XOR)** 运算。相同为 0，不同为 1。
* **FCS 位数：** 等于生成多项式 $G(x)$ 的最高阶数 $r$。
* **408高频提醒：** **CRC 只能做到“无差错接受”（凡是接收下来的帧都认为没有差错），但它不是“可靠传输”。** 可靠传输还需要确认和重传机制。

## 四、流量控制与可靠传输机制（核心重中之重）

数据链路层的流量控制是**点对点**的（相邻结点），而传输层（TCP）的流量控制是**端到端**的。

### 1. 停止-等待协议 (Stop-and-Wait)
* **机制：** 发送方每发送一帧，就必须等待接收方的确认应答（ACK）才能发送下一帧。
* **特点：** 窗口大小：发送窗口 $W_T = 1$，接收窗口 $W_R = 1$。
* **缺点：** 信道利用率极低（大部分时间在等待传播时延）。

### 2. 后退 N 帧协议 (GBN, Go-Back-N)
* **机制：** 发送方可以连续发送多个帧。接收方只**按序接收**，并采用**累积确认**（发送 ACK n，表示 n 号及之前的帧已全部正确收到）。
* **出错处理：** 如果丢失了第 $n$ 帧，即使接收方收到了 $n+1, n+2$ 帧，也会丢弃它们。发送方超时后，必须**重传第 $n$ 帧及其后面的所有帧**。
* **窗口限制：** 若采用 $n$ 个比特对帧编号，则发送窗口大小必须满足：**$1 < W_T \le 2^n - 1$**。接收窗口 $W_R = 1$。
* **优点：** 提高了信道利用率。
* **缺点：** 重传代价大，适用于信道质量好的网络。

### 3. 选择重传协议 (SR, Selective Repeat)
* **机制：** 发送方连续发送多个帧。接收方有**缓存**，可接收**失序但正确**的帧，并采用**单独确认**（收到哪个就确认哪个）。
* **出错处理：** 发送方只重传没有收到确认的帧。
* **窗口限制：** 发送窗口通常等于接收窗口，且必须满足：**$W_T + W_R \le 2^n$ 且 $W_T = W_R \le 2^{n-1}$**。
* **优点：** 减少了无谓的重传，效率最高，适用于信道质量较差的网络。

## 五、介质访问控制 (MAC 子层)

决定广播信道中信道分配的协议。

### 1. 静态划分信道（信道复用）
* **频分 FDM / 时分 TDM / 波分 WDM / 码分 CDM**（通常放在物理层讨论，但本质是介质访问控制）。不会发生冲突。

### 2. 动态分配信道 —— 随机访问介质访问控制（核心）
用户随机发送数据，容易产生冲突。
* **ALOHA 协议：** 想发就发，冲突了就随机等待一段时间再发。纯 ALOHA 效率极低（18.4%），时隙 ALOHA 效率提高一倍（36.8%）。
* **CSMA (载波监听多路访问)：** 发送前先监听信道。“先听后发”。分为 1-坚持、非坚持、p-坚持。

#### 3. CSMA/CD 协议（载波监听多路访问/碰撞检测 —— 传统以太网）
* **工作过程：** “先听后发，边发边听，冲突停发，随机重发”。
* **争用期 (冲突窗口)：** 端到端传播时延 $\tau$ 的两倍，即 **$2\tau$**。发送方如果在发送数据的前 $2\tau$ 时间内没有检测到碰撞，那么这次发送就不会发生碰撞。
* **最小帧长公式（必考重点）：**
  $$最小帧长 = 争用期 \times 数据传输速率 = 2\tau \times 带宽$$
  如果发送的帧小于最小帧长，必须进行填充。以太网规定最小帧长为 **64 字节**。
* **截断二进制指数退避算法：** 发生冲突后，重传前退避的时间随机取自 $\{0, 1, \dots, 2^k - 1\} \times 2\tau$，其中 $k = \min(\text{重传次数}, 10)$。重传 16 次仍失败则报错丢弃。

#### 4. CSMA/CA 协议（载波监听多路访问/碰撞避免 —— 802.11 无线局域网）
* **为什么不用 CD：** 无线电波衰减大，难以实现 360 度全方位冲突检测；存在**隐蔽站问题**。
* **机制：** 发送前先听，空闲则等待 DIFS 后发送。使用 RTS（请求发送）和 CTS（允许发送）控制帧来预约信道，解决隐蔽站问题。

### 3. 动态分配信道 —— 轮询访问介质访问控制
* **令牌传递协议：** 令牌（一个特殊的控制帧）在环形网中按顺序传递。拿到令牌的站才能发送数据。适合**负载重**、通信量大的网络，不会发生冲突（如令牌环网）。

## 六、局域网与以太网 (Ethernet)

### 1. 局域网基本特性
* **拓扑结构：** 星型、总线型、环型。
* **IEEE 802 标准：** 将数据链路层拆分为两个子层：
  * **LLC (逻辑链路控制) 子层：** 向上层提供服务，与传输媒体无关。
  * **MAC (介质访问控制) 子层：** 与物理媒体直接相关，负责帧的组装和介质访问控制。

### 2. MAC 地址
* 硬件地址，固化在网卡 (NIC) 的 ROM 中。共 **48 位 (6 字节)**。
* 局域网内数据传输的最终寻址依据。

### 3. 以太网的 V2 帧格式（高频考点）
* **前导码：** 8字节。其中7字节为前同步码（实现时钟同步），1字节为帧开始定界符（10101011）。**前导码不计算在帧长内！**
* **目的 MAC (6B) + 源 MAC (6B) + 类型 (2B) + 数据 (46B~1500B) + FCS (4B)。**
* **最小帧长：** 64B。故数据部分最小为 $64 - 18 = 46\text{B}$。不足则填充。
* **最大帧长：** 1518B（即最大数据载荷 MTU 为 1500B）。

### 4. 虚拟局域网 (VLAN)
* **本质：** VLAN 是一个逻辑上的广播域。它可以将局域网内的设备从逻辑上划分成一个个网段。
* **作用：** **隔离广播域**，提高安全性，简化网络管理。
* **802.1Q 帧：** 在以太网 V2 帧的源 MAC 地址和类型字段之间，插入了 **4 字节的 VLAN 标签**。

## 七、广域网与数据链路层设备

### 1. PPP 协议 (Point-to-Point Protocol)
* **应用场景：** 目前使用最广泛的点对点链路层协议（如拨号上网、路由器之间连接）。
* **特点：** **只支持全双工**链路，**不可靠**（不使用序号和确认），**面向字节**。
* **组成：**
  * 封装成帧的方法。
  * **LCP (链路控制协议)：** 用于建立、配置和测试数据链路连接。
  * **NCP (网络控制协议)：** 为网络层协议建立和配置逻辑连接（如 IPCP 用于分配 IP 地址）。
* **透明传输：** 同步传输链路用零比特填充，异步传输链路用字符填充。

### 2. 以太网交换机 (Switch)
* **本质：** 多端口网桥。工作在数据链路层。
* **工作原理：** 根据以太网帧的**目的 MAC 地址**对帧进行转发。
* **交换方式：**
  * **直通式：** 只检查帧的目的 MAC 地址（前 6 字节）就立即转发，延迟小，缺乏检错。
  * **存储转发式：** 将整个帧缓存并进行 CRC 校验，正确再转发，延迟大，可靠性高。
* **自学习算法（核心）：**
  1. 交换机收到一帧，首先提取**源 MAC 地址**和进入的端口，写入交换表（MAC 地址表）。
  2. 提取**目的 MAC 地址**，在交换表中查找：
     * 若找到对应端口：如果端口与源端口相同，丢弃；如果不同，转发到对应端口。
     * 若找不到对应端口：向除源端口外的**所有端口广播（泛洪 flood）**。

## 八、408 经典计算与概念辨析例题

### 题目 1：滑动窗口极限参数计算
主机甲和主机乙之间采用后退 N 帧协议 (GBN) 传输数据，帧序号占用 3 个比特。若发送窗口尺寸为 $W_T$，接收窗口尺寸为 $W_R$，求 $W_T$ 的最大可能值。
**解答：**
* 帧序号占 3 比特，故序号范围是 $0 \sim 2^3-1$ (即 $0 \sim 7$)。
* GBN 的规定是 $W_R = 1$，且 $W_T \le 2^n - 1$。
* 故 $W_T \le 2^3 - 1 = 7$。因此最大值为 **7**。
*(注：如果是 SR 协议，发送和接收窗口一般相等，且最大为 $2^{3-1} = 4$)*。

### 题目 2：最小帧长计算
在一个以太网中，传输介质长度为 $1000\text{ m}$，信号传播速率为 $2 \times 10^8\text{ m/s}$，网络数据传输速率为 $1\text{ Gbps}$，求该网络能支持的最小数据帧长度。
**解答步骤：**
1. **求单向传播时延 $\tau$：**
   $$\tau = \frac{1000\text{ m}}{2 \times 10^8\text{ m/s}} = 5 \times 10^{-6}\text{ s} = 5\text{ \mu s}$$
2. **求争用期 $2\tau$：**
   $$2\tau = 10\text{ \mu s}$$
3. **求最小帧长：**
   $$L_{min} = 2\tau \times \text{带宽} = (10 \times 10^{-6}\text{ s}) \times (10^9\text{ bps}) = 10^4\text{ bit}$$
4. **转换为字节：** $10000 / 8 = \mathbf{1250\text{ 字节}}$。

## 九、首轮复习高频考法与陷阱防范

1. **陷阱：物理层设备 vs 链路层设备 vs 网络层设备**
   * **集线器/中继器（物理层）：** 既不隔离冲突域，也不隔离广播域。
   * **网桥/交换机（链路层）：** 隔离**冲突域**，但**不隔离广播域**。（VLAN 是逻辑隔离广播域，而非交换机的硬件本能）。
   * **路由器（网络层）：** 隔离**冲突域**，也隔离**广播域**。
2. **概念辨析：CSMA/CD 的“检测碰撞”**
   * CSMA/CD 只能用于有线网。因为检测碰撞需要发送方监听信道上信号电压的异常变化，无线信道衰减过大无法实现。
3. **陷阱：GBN 和 SR 的确认机制区别**
   * GBN 是**累积确认**（捎带确认）。收到 ACK n，说明 n 及 n 以前的都收到了。
   * SR 是**单独确认**。收到 ACK n，仅代表 n 号帧收到了。
4. **细节：以太网帧的填充**
   * 计算最小帧长时，是以**MAC 帧的总长度（目的 MAC + 源 MAC + 类型 + 数据 + FCS）**为准的（即数据链路层 PDU）。前导码不算在内。最小 64B 是以太网的硬规定，遇到具体链路参数计算出来的可能大于 64B。

## 十、第三章核心结论清单总结

* **三大基本问题：** 封装成帧、透明传输、差错检测。
* **零比特填充法：** 见 5 个 1 就塞 0，保证透明传输。
* **差错检测不等于可靠传输：** 数据链路层主要只管检错丢弃，纠错和重传是可靠传输协议干的活。
* **滑动窗口三大协议：** 停止-等待（1,1），GBN（>1, 1，累积确认），SR（>1, >1，单独确认）。
* **CSMA/CD 铁律：** 最小帧长 $= 2\tau \times$ 带宽。争用期 $= 2\tau$。
* **交换机自学习：** 查源 MAC 建表，查目的 MAC 转发（找不到就泛洪）。
* **网络设备隔离原则：** 交换机切冲突域不切广播域，路由器切广播域。
