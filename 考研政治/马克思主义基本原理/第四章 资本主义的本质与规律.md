## 一、本章核心框架:从商品到剩余价值的演进
在进入细节前,先把政经的逻辑主线理顺:
- 主线推演:马克思是从最简单的商品经济一般规律开始剖析的,然后过渡到资本主义生产方式特殊规律,最后揭示出全书的核心--**剩余价值理论**｡
- 核心关键词:**商品二因素**､**劳动二重性**､**剩余价值**､**不变资本/可变资本**､**绝对/相对剩余价值**｡这些词在脑子里必须能形成条件反射｡
- 一句话抓总(大题定调句):**资本主义以雇佣劳动为基础,通过占有剩余价值实现资本增殖｡这就是资本主义发家致富的根本秘密｡**

## 二、商品与价值理论(万丈高楼平地起)
这是理解整个政经的基础,地基打不牢,后面看资本运行全抓瞎｡
### 1. 商品二因素(现象层)
商品是用来交换的劳动产品,它天生带有两个因素:
- **使用价值**:指商品满足人的某种需要的属性｡(大白话:这东西得有用,比如馒头能充饥,衣服能御寒｡使用价值是商品的自然属性)｡
- **价值**:指凝结在商品中的无差别人类劳动｡(大白话:不论是做馒头还是做衣服,都消耗了人的体力和脑力｡价值是商品的社会属性)｡
- 二者关系:二者统一于商品,缺一不可｡(有使用价值的不一定是商品,比如天然的空气;有价值的必然有使用价值)｡

### 2. 生产商品的劳动二重性(本质层)
为什么商品有二因素?因为生产商品的劳动具有二重性(马克思的伟大发现):
- **具体劳动**:创造使用价值｡(比如木匠做桌子､裁缝做衣服,劳动的形式是具体的)｡
- **抽象劳动**:形成价值｡(撇开劳动的具体形式,纯粹是人类体力和脑力的消耗)｡
- 考点地位:这是**理解政治经济学全部范畴的枢纽**!

### 3. 价值量与价值规律
- 价值量决定:商品价值量是由**社会必要劳动时间**决定的｡(注意陷阱:绝不是个别劳动时间!你手脚慢做个杯子花一天,不代表这个杯子价值极高,得看社会平均水平)｡
- 价值规律要求:商品交换要以价值量为基础,实行**等价交换**｡(这是商品经济的基本规律)｡

## 三、货币､资本与劳动力商品
### 1. 货币的基本职能(选择题常客)
货币有五大职能,必须分清:
- **价值尺度**:标价签上的数字,观念上的货币即可｡
- **流通手段**:一手交钱一手交货,必须是现实的货币｡
- **贮藏手段**:退出流通,被当作独立价值形态保存(得是足值的金银)｡
- **支付手段**:延期支付､清偿债务(比如交租金､发工资)｡
- **世界货币**:越出国内流通领域,在世界市场上发挥作用｡

### 2. 资本总公式及其矛盾
- 公式:资本运动公式是 **$G-W-G'$**｡($G$ 是钱,$W$ 是商品,$G'$ 是更多的钱)｡
- 矛盾点:关键问题在于,增殖额($G'−G$)究竟从哪里来?
- 结论破局:流通本身不创造剩余价值,剩余价值来源于生产过程中的雇佣劳动｡(资本家买到了一种特殊的商品,能在生产中创造出比自身价值更大的价值)｡

### 3. 劳动力成为商品的条件
劳动力能拿来卖,是有历史前提:
- 第一,劳动者拥有**“人身自由”**,能够自由出卖自己的劳动力｡
- 第二,劳动者丧失了生产资料,只能靠出卖劳动力维生｡(也就是除了自己的一身力气,一无所有)｡

## 四、剩余价值理论(本章绝对灵魂,难点所在)
### 1. 必要劳动与剩余劳动(时间的划分)
工人在工厂里的一天被劈成了两半:
- **必要劳动时间**:工人在必要劳动时间内再生产劳动力的价值｡(这段时间赚的刚好够发你的工资)｡
- **剩余劳动时间**:在剩余劳动时间内创造的价值,被资本家无偿占有,即**剩余价值**｡(这段时间纯纯是给老板免费打工,这就是剥削的秘密)｡

### 2. 资本划分(c与v)
资本家投钱买机器和雇工人,这两笔钱性质完全不同:
- **不变资本($c$)**:用来购买生产资料(如机器､原料)｡它的价值只是转移到新产品中,不发生增殖｡(棉花变成纱线,棉花的价值转移过去了,没有多出一分钱)｡
- **可变资本($v$)**:用来购买劳动力,能够带来价值增殖｡
- 灵魂结论(牢记):**剩余价值来自可变资本部分的活劳动**｡

### 3. 剩余价值率(剥削程度的量化)
- 它反映了资本家对工人的剥削程度｡
- 公式表达的是剩余劳动与必要劳动的比率关系(**$m' = \frac{m}{v}$**,即剩余劳动时间 / 必要劳动时间)｡

### 4. 剩余价值生产的两种基本方法
老板为了提高剥削率,通常有两招:
- **绝对剩余价值生产**:靠延长工作日､提高劳动强度｡(疯狂加班,强行拉长剩余劳动时间)｡
- **相对剩余价值生产**:靠提高劳动生产率,缩短必要劳动时间｡(工作日总长度不变,但社会生产力提高了,工人生活资料便宜了,必要劳动时间变短,剩下的剩余劳动时间自然变长了)｡

## 五、资本积累与资本主义基本矛盾(动态演进)
老板赚了钱不会都吃喝玩乐,他还要继续投入｡
### 1. 资本积累本质
- 资本积累就是把**剩余价值再转化为资本**,用于扩大再生产｡(钱生钱的循环)｡

### 2. 资本积累的必然后果(选择大题高频交叉点)
- 导致资本集中与积聚加深｡(大鱼吃小鱼,企业越来越大,垄断开始萌芽)｡
- 促使相对过剩人口(产业后备军)形成｡(机器排挤工人,失业人口增加,资本家借此压低在职工人工资)｡
- 造成贫富分化和两极分化趋势增强｡(一头是财富积累,一头是贫困积累)｡

### 3. 资本主义基本矛盾(万恶之源)
- 核心表现为**生产社会化与资本主义私人占有之间的矛盾**｡
- 它是资本主义周期性经济危机和制度性冲突的根源｡(大家一起生产的东西,利润全归老板一个人,导致普通人买不起,引发生产相对过剩的危机)｡

## 六、一轮复习:真题高频陷阱快判速查
政经的选择题坑特别多,这里结合原笔记做一次全面“排雷”:

| 易错陷阱 | 快判与正确认知 |
| --- | --- |
| 劳动 vs 劳动力 | 混淆“劳动”与“劳动力”是常考坑点｡资本家买的是劳动力(劳动能力),不是劳动本身;劳动是使用劳动力的过程,是不可能被买卖的｡ |
| 剩余价值来源 | 误以为“机器创造剩余价值”｡机器再先进,它也属于不变资本($c$),只能转移自身价值,只有活劳动(工人)才能创造剩余价值｡ |
| 不变资本的理解 | 把“不变资本”字面理解为“数量不变”｡“不变”指的是其在生产过程中价值量没有发生增殖,不代表物价或数量不波动｡ |
| 价值规律的表现 | 把“价值规律”机械理解为“价格永远等于价值”｡实际上,价格受供求关系影响,是围绕价值上下波动的｡ |
| 工资与利润的假象 | 工资看起来像劳动的价格,利润看起来像全部预付资本带来的收益,这掩盖了剥削的本质｡必须回到“活劳动”和“剩余劳动”来找根源｡ |
