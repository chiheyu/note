## 一、 本章核心框架：人生观与价值观的导航（一轮复习全景图）

本章是《思想道德与法治》的核心基础章，主要解决“人为什么活着、应该怎样活着”的根本问题。考研命题极爱结合感动中国人物、时代楷模的事迹，考查个人与社会的关系、人生价值的评价与实现。

* **理论起点**：马克思主义关于人的本质的认识（人的本质是一切社会关系的总和）。
* **核心内容（人生观三要素）**：人生目的（核心）、人生态度、人生价值。
* **基本关系**：个人与社会的辩证统一关系（这是评价人生价值的前提）。
* **实践落脚点**：在服务人民、奉献社会的实践中创造有意义的人生。

## 二、 理论起点：人的本质与个人与社会的关系

这是理解所有人生观问题的前提，必须从马克思主义的唯物史观出发。

### 1. 人的本质（极高频单选题）
* **错误观点**：认为人的本质是“自私的”或某种脱离社会的“自然属性”（生物学属性）。
* **马克思主义科学论断**：人的本质不是单个人所固有的抽象物，在其现实性上，它是一切**社会关系的总和**。
* **内涵解析**：人是社会的人，离开了社会和特定的社会关系，就谈不上人的本质。社会属性是人的**本质属性**。

### 2. 个人与社会的辩证统一关系（分析题理论基石）
* **关系定位**：个人与社会的关系，最根本的是**个人利益与社会利益**的关系。两者是对立统一的。
* **相互依存**：
    * **社会需要个人**：社会是由无数个人组成的，人的生存和发展是社会生存和发展的前提。
    * **个人离不开社会**：社会是个人生存和发展的基础，个人是社会大系统中的一个节点。
* **利益关系**：社会利益不是个人利益的简单相加，而是所有人利益的有机统一。社会利益体现了作为社会成员的个人的根本利益和长远利益，是个人利益得以实现的前提和基础，同时它也保障着个人利益的实现。

## 三、 人生观的主要内容及其内在逻辑（一轮复习必背重点）

人生观是人们在实践中形成的对于人生目的和意义的根本看法。它决定着人们实践活动的目标、人生道路的方向，以及对待生活的态度。

| 组成部分 | 核心回答的问题 | 地位与作用 | 内在关系 |
| :--- | :--- | :--- | :--- |
| **人生目的** | 人为什么活着？ | **核心地位**。决定人生道路；决定人生态度；决定人生价值选择。 | 目的决定态度，态度影响目标的实现。 |
| **人生态度** | 人应当怎样对待生活？ | 是人生观的重要内容，是人生观的**心理、情感和意志的集中体现**。 | 目的和态度共同影响价值的创造与实现。 |
| **人生价值** | 什么样的人生才有价值？ | 是人生观的**表现和评价标准**。 | 目的决定了你追求什么样的价值。 |

## 四、 人生价值的评价与实现（主观题核心考区）

### 1. 人生价值的双重属性（自我价值与社会价值）
* **自我价值**：是个体的人生活动对自己的生存和发展所具有的价值（表现为对自身物质和精神需要的满足程度）。
* **社会价值**：是个体的人生活动对社会、他人所具有的价值（表现为对社会的贡献）。
* **两者关系**：辩证统一。**社会价值是自我价值的前提和基础**（没有社会的提供，个人无法生存）；**自我价值是社会价值的目标和归宿**（社会的发展是为了每个人的发展）。

### 2. 评价人生价值的根本尺度（客观题易错点）
* **根本尺度**：看一个人的实践活动**是否符合社会发展的客观规律，是否促进了历史的进步**。
* **普遍标准（在今天）**：看他是否以自己的劳动和聪明才智为中国特色社会主义真诚奉献，为人民群众尽心尽力服务。
* **评价方法（四个坚持）**：
    1. 坚持能力有大小与贡献须尽力相统一。
    2. 坚持物质贡献与精神贡献相统一。
    3. 坚持完善自身与贡献社会相统一。
    4. 坚持动机与效果相统一。

### 3. 人生价值的实现条件
* **社会条件（客观因素）**：实现人生价值要从社会客观条件出发；人生价值目标要与社会主义核心价值观相一致。
* **个人条件（主观因素）**：
    1. 实现人生价值要从个体自身条件出发。
    2. 不断提高自身的能力，增强实现人生价值的本领。
    3. 立足于现实，坚守岗位作贡献。
    4. 实现人生价值要有**自强不息的精神**。

## 五、 创造有意义的人生：辩证对待矛盾与反对错误思潮

### 1. 辩证对待人生矛盾（心态调整）
树立正确的人生态度，必须正确认识和处理人生中的各种矛盾组合：
* **得与失**：不要患得患失，懂得多与少、得与失的辩证法。
* **苦与乐**：苦中有乐，乐中生苦。
* **顺与逆**：顺境不要骄傲，逆境不要气馁（逆境往往能磨炼人的意志）。
* **生与死**：有重于泰山，有轻于鸿毛。
* **荣与辱**：树立正确的荣辱观。

### 2. 坚决反对三种错误的人生观（了解其本质错误）
| 错误思潮 | 核心主张 | 理论谬误与本质局限 |
| :--- | :--- | :--- |
| **拜金主义** | 将金钱视为人生的唯一目的和最高价值。 | 混淆了目的和手段的关系，把金钱这种物化手段变成了人生的绝对目的，导致人性的物化和异化。 |
| **享乐主义** | 把物质感官享受作为人生的唯一目的。 | 把人的需要降低到了动物的生理本能层面，忽视了人的社会属性和精神追求，导致精神空虚。 |
| **极端个人主义** | 把个人利益凌驾于社会利益和他人利益之上。 | **剥削阶级人生观的核心**。它彻底割裂了个人与社会的辩证统一关系，妄图脱离社会孤立存在，必然导致损人利己。 |

## 六、 一轮复习高频易错点扫盲

1. **核心地位辨析**：人生观的**核心是人生目的**（不是人生价值）。世界观决定人生观。
2. **尺度辨析**：评价人生价值的**根本尺度**是看其是否促进了社会进步（即对社会的贡献）；**不是**看他赚钱多少或个人能力大小。
3. **“总和”概念辨析**：人的本质是“一切社会关系的总和”，意味着人的本质是具体的、历史的、随着社会关系的变化而变化的，**不存在永恒不变的普遍的人性**。
4. **价值的优先级**：在个人与社会的价值关系中，**社会价值排在第一位**，强调奉献是实现价值的根本途径，不能把“等价交换”作为评价人生价值的标准。

## 七、 分析题万能作答模板（楷模人物、奉献社会类材料）

遇到考查“时代楷模的事迹有何启示”、“如何评价某某的人生价值”、“当代青年应如何实现自我价值”等题目，采用以下逻辑作答：

1. **定性分析（点出人生观属性）**：材料中楷模人物的事迹，深刻体现了马克思主义关于个人与社会关系、人生价值实现的正确理念。人的本质是一切社会关系的总和，个人的成长和价值实现离不开社会。
2. **阐述原理（社会价值与自我价值的关系）**：人生价值包括自我价值和社会价值。其中，社会价值是评价人生价值的根本尺度。人的社会价值的实现，是自我价值实现的前提和基础。材料中的人物（结合具体事迹）正是通过将“小我”融入“大我”，在满足社会需要的同时，也实现了极高的人生自我价值。
3. **点明途径（实践与奉献）**：社会实践是实现人生价值的必由之路。评价一个人的人生价值，最根本的是看他是否符合社会发展规律，是否为社会和人民作出了贡献。
4. **青年使命（结合自身落脚）**：新时代青年应该树立正确的人生目的，保持积极向上的人生态度，坚决反对拜金主义、享乐主义和极端个人主义。我们要像楷模学习，立足本职岗位，自强不息，在服务人民、奉献社会的伟大实践中创造有意义的人生。
