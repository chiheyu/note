## 一、词根词缀法的核心思路

### 1. 拆词公式（考研高频）
- **前缀（prefix）**：决定方向、否定、程度、时间等“附加意义”。
- **词根（root）**：决定核心语义（这个词“到底在说什么”）。
- **后缀（suffix）**：决定词性（名词/动词/形容词/副词）和语法功能。

> 拆词通用式：**prefix + root + suffix**  
> 例：**in-visible** = in-(否定) + vis(看) + -ible(可…的) → “看不见的”

### 2. 为什么考研英语必须掌握词根词缀
- 生词多、长难词多，靠死记效率低。
- 阅读理解中，常见“似曾相识但想不起”的词，拆词能快速猜义。
- 写作中能用同根词扩展表达（如 act, action, active, activity, activate）。

### 3. 学习顺序建议
1. 先背高频前缀（否定、方向、时间、程度）。
2. 再背高频词根（看、说、写、走、拿、生命、法律、经济）。
3. 最后背高频后缀（-tion, -ity, -ive, -ize 等），解决词性判断问题。

## 二、前缀大全（按语义分类）

### 1. 否定、相反类
- **un-**：不，非
  - unhappy, unfair, unknown
- **in- / im- / il- / ir-**：不，非（同化变体）
  - inactive, impossible, illegal, irregular
- **non-**：非，不（中性）
  - nonverbal, nonresident
- **dis-**：否定；分离；相反
  - disagree, dishonest, disconnect
- **de-**：去除；向下；离开
  - decode, deforest, decrease
- **a- / an-**：无，不（多见于希腊词）
  - amoral, anaerobic

### 2. 时间、顺序类
- **pre-**：在前，预先
  - preview, predict, preschool
- **post-**：在后
  - postgraduate, postwar
- **fore-**：在前，预先
  - foresee, forehead
- **ex-**：前任的；向外
  - ex-president, export
- **neo-**：新
  - neoclassical, neonate
- **re-**：再，又；向后
  - rewrite, rebuild, reconsider
- **retro-**：向后，回溯
  - retrospective, retroactive

### 3. 空间、方向类
- **sub-**：在下；次级
  - subway, subconscious, subtitle
- **super-**：在上；超
  - superstructure, supernatural
- **over-**：过度；在上方
  - overwork, overlook
- **under-**：不足；在下方
  - underestimate, underground
- **inter-**：在……之间
  - international, interact
- **intra-**：在……内部
  - intravenous, intranet
- **trans-**：横跨；转换
  - transport, transform, transatlantic
- **circum-**：环绕
  - circumstance, circumnavigate
- **peri-**：周围
  - perimeter, periphery
- **extra-**：在外；额外
  - extraordinary, extracurricular

### 4. 程度、数量类
- **hyper-**：过度，超
  - hyperactive, hypertension
- **hypo-**：不足，低
  - hypothesis, hypothermia
- **mini-**：小
  - minimum, miniskirt
- **macro-**：大，宏观
  - macroeconomics
- **micro-**：小，微观
  - microscope, microeconomics
- **mono-**：单一
  - monotone, monologue
- **uni-**：一
  - uniform, unify, unilateral
- **bi-**：二
  - bilingual, bicycle
- **tri-**：三
  - triangle, trimester
- **multi-**：多
  - multicultural, multimedia
- **poly-**：多
  - polygon, polytechnic
- **semi-**：半
  - semicircle, semifinal

### 5. 共同、分离类
- **co- / com- / con- / col- / cor-**：共同，一起
  - cooperate, combine, connect, collaborate, correspond
- **se- / sed-**：分开
  - separate, secede, seduce（词义已引申）
- **di-**：分开；二
  - divide, diverge, dioxide

## 四、后缀大全（决定词性的关键）

### 1. 名词后缀
- **-tion / -sion**：行为、状态、结果
  - action, decision, conclusion
- **-ment**：行为结果、状态
  - development, movement
- **-ance / -ence**：性质、状态
  - importance, difference
- **-ity**：性质
  - ability, activity, reality
- **-ness**：性质
  - kindness, darkness
- **-ship**：关系、身份、状态
  - friendship, leadership
- **-ism**：主义、现象
  - realism, capitalism
- **-ist**：人（……者）
  - scientist, artist
- **-er / -or**：人或物（执行者）
  - teacher, actor, generator
- **-ee**：动作承受者
  - employee, interviewee
- **-hood**：状态、时期
  - childhood, neighborhood
- **-dom**：领域、状态
  - freedom, kingdom

### 2. 形容词后缀
- **-able / -ible**：可……的
  - readable, visible
- **-al**：……的
  - natural, cultural
- **-ary / -ory**：……的
  - primary, compulsory
- **-ful**：充满……的
  - useful, powerful
- **-less**：无……的
  - hopeless, meaningless
- **-ous / -ious / -eous**：多……的
  - dangerous, curious, spontaneous
- **-ive**：有……倾向的
  - active, creative, productive
- **-ic**：……的
  - economic, historic
- **-ed / -ing**：分词形容词
  - interested / interesting

### 3. 动词后缀
- **-ize / -ise**：使……化
  - modernize, realize
- **-ify**：使……化
  - simplify, classify
- **-en**：使……
  - widen, strengthen
- **-ate**：使成为；执行动作
  - activate, evaluate, regulate

### 4. 副词后缀
- **-ly**：……地
  - quickly, logically
- **-ward(s)**：朝向
  - forward, afterward
- **-wise**：在……方面
  - likewise, clockwise

## 五、同化与变形规律（必会避坑）

### 1. 前缀同化（最常考）
- **in-** 在不同字母前同化：
  - im-（m/p/b 前）：impossible
  - il-（l 前）：illegal
  - ir-（r 前）：irregular

### 2. 词根变体
- **ceed / cede / cess** 同源（走）
  - proceed, recede, access
- **scribe / script** 同源（写）
  - describe, manuscript
- **vid / vis** 同源（看）
  - evidence, visible

### 3. 后缀导致拼写变化
- y → i + es/ed（辅音+y）
  - carry → carries / carried
- 词尾 e 省略再加 -ing
  - make → making
- 重读闭音节双写末尾辅音
  - admit → admitted

## 六、考研高频拆词示例（阅读中可直接用）

1. **inevitable** = in- + evit(avoid) + -able → 不可避免的
2. **contradict** = contra(反) + dict(说) → 反驳
3. **subconscious** = sub(下) + conscious(意识) → 潜意识的
4. **intervene** = inter(在中间) + ven(来) → 干预
5. **retrospect** = retro(向后) + spect(看) → 回顾
6. **transmit** = trans(跨) + mit(送) → 传输
7. **beneficial** = bene(好) + fic(做) + -ial → 有益的
8. **malfunction** = mal(坏) + function(功能) → 故障
9. **coherent** = co(共同) + her(粘连) + -ent → 连贯的
10. **deteriorate** = de(向下) + ter(擦/磨) + -ate → 恶化
11. **microeconomics** = micro(微观) + econom(经济) + -ics → 微观经济学
12. **multilateral** = multi(多) + later(边) + -al → 多边的
13. **postgraduate** = post(之后) + graduate(毕业) → 研究生
14. **prehistoric** = pre(之前) + histor(历史) + -ic → 史前的
15. **unprecedented** = un + precedent(先例) + -ed → 前所未有的

## 七、组词与记忆方法（提分实操）

### 1. 同根词串联记忆（最省时）
- act → action → active → activity → activate → activist
- form → reform → transform → conform → formation
- dict → dictate → prediction → contradiction

### 2. 词性反推法（做题快）
- 看到 **-tion/-ment/-ity**，优先判定为名词。
- 看到 **-ive/-ous/-able**，优先判定为形容词。
- 看到 **-ly**，优先判定为副词。

### 3. 真题阅读猜词顺序
1. 先看后缀判词性。
2. 再看前缀判语义方向（否定/程度/时间）。
3. 最后看词根定核心义。
4. 放回句子检验语义是否通顺。

### 4. 每日复习模板（20分钟）
- 5分钟：复习10个前缀
- 10分钟：复习20个词根+例词
- 5分钟：做5个长难词拆词练习

## 九、最后提醒（考场策略）

- 不要求你把每个词源学都背得很学术，重点是“**看见能拆、拆了能猜、猜完能判词性**”。
- 阅读里遇到生词，先用词根词缀猜，再根据上下文确认；不要停留太久。
- 写作里尽量使用你掌握的同根词群，既稳又显得词汇层次高。
